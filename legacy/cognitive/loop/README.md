# Cognitive Loop

The self-improvement feedback cycle for Legacy and her children:

## Cycle
1. **Perceive** — ingest data from all agents and sensors
2. **Analyze** — identify patterns, issues, opportunities
3. **Decide** — Legacy makes sovereign decisions
4. **Act** — dispatch agents to execute
5. **Learn** — update genome, skills, memory
6. **Report** — brief Zeus on what changed and why

## Feedback Invariants
- Every cycle produces a delta (change must occur)
- Every cycle reports to Zeus via Legacy
- Every cycle updates the genome if knowledge changed
