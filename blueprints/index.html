📋 Protocol - Adding a New Blueprint

  1. Copy your standalone HTML file into the appropriate folder with a clean kebab-case name.
  2. Open index.html and add a new card in the matching section. Use any existing card as a template.
  3. Set the href to your filename, pick an --accent color, write a short desc, and add a source line.
  4. Commit and push: git add . && git commit -m "add: blueprint name" && git push
  5. Live at onemindos.github.io/omos-blueprints/ within 60 seconds.
Rules: Single HTML files only - no build steps, no frameworks. Each file must be self-contained (inline CSS/JS, CDN deps OK). If it needs a server, it does not belong here.
Source tracking: Every card shows where it originated with a 📍 marker. Keep this updated.
