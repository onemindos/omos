0KEYSTONE — NATS Bus Bridge · gates everything

The Mac NATS mesh (zeus-mac · localhost:4222) is the source of truth for the entire OneMind bus. DOKS NATS (nats.nats.svc:4222, leaf listener :7422) is a separate bus — only TAK is bridged today. All subjects (log.> metric.> evt.> voice.* agents.*) live only on the Mac.

Consequence: move any consumer/producer to DOKS without bridging first and it arrives dead — no data flows. This is step zero, not a "later" phase.

Action: configure a Mac-NATS leafnode remote → DOKS leaf listener :7422 over TLS (Tailscale/mTLS). Mac already has the leaf listener; only the remote is missing. Bridge the subject families, verify subjects appear on both buses, then migrations unlock.
