The Mission

OneMind is a Real-Life Operations OS

Every asset in the world is an entity on the bus. Every entity shows on the TAK map. Legacy watches all streams and acts on your orders. This is C4ISR infrastructure — not an app.

🔮 om-unity (ORP) has 5,938 entities RIGHT NOW — ships, aircraft, and more

om-unity is a 45MB Rust binary (Open Reality Protocol) with 39 protocol adapters, a live entity graph with 5,938 active entities (AIS ships live, ADS-B ready, MAVLink adapter built-in), ORP-QL query language, a unity-tak TAK wire codec, a CoT ingestion engine, and a built-in COP frontend. It's been running for 37+ hours. Its API is live at localhost:9090. The path to those 5,938 entities appearing on your ATAK map is: wire om-unity's NATS adapter → publish to tel.* subjects → fusion spine picks up → CoT → ATAK. No new code — just configuration.

⚡ One sentence: Everything is an entity. Every entity has state on the bus. TAK shows the state. Legacy acts on the state.

The om-overwatch pattern (sensor → fusion spine → CoT bridge → ATAK) is the universal template. Every new asset type follows the same path. The pipeline already works for drones and hostile air. The work is extending it to robots, servers, sensors, and AI agents — then wiring those assets in.

What Each Stream Is For

Streams are the operational journal of your OS. Each has a role. Hot = real data flowing. Partial = some data. Empty = placeholder, no publisher yet.

EVT
📋 The Operational Event Log
Everything that happens in the network. Detection events, drone maneuvers, mission milestones, agent actions. The audit trail. 90-day retention.
evt.{so·hp·le·ge·task·cloud·bio·robot·drone·sat}.>
2,112,028 msgs · 90 days · om-overwatch-* → om-hooks → ClickHouse
AGENTS
🤖 The Agent Roster
Heartbeats from every NEX workload and AI agent. The "who is alive" register. Detect dead services. NOT for AI prompt traffic (core NATS req/reply, can't be JetStream).
