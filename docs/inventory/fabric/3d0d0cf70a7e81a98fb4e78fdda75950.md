# OneTAK — Internal Features
> OneMind fork of CloudTAK — AI-native, NATS-fabric TAK COP platform. All features below are internal to the platform.
## 🗺️ Map & Visualization
- Basemaps — switchable tile layers (satellite, street, terrain, custom XYZ/TMS sources)
- Overlays — toggleable data layers on top of basemap (CoT markers, heatmaps, geo zones, intel feeds)
- 3D Globe — Cesium integration for photorealistic 3D terrain view
- Routes — draw, import, and share navigation routes on the map
- GeoFences — define operational zones, trigger alerts on entry/exit
- Drawing Tools — shapes, lines, polygons, range rings, threat markers
- Map Search — search for coordinates, addresses, and TAK callsigns
## 📦 Data
- Data Packages — import/export .zip bundles (KML, shapefiles, imagery, missions)
- Data Sync — real-time CoT sync with TAK Server over SSL/WebSocket
- File Manager — upload/download mission files, overlays, and media
- Import — KML, KMZ, GeoJSON, Shapefile, GPX, DRW, TAK data packages
- Export — export map data, tracks, and packages to share with other TAK clients
## 💬 Communications & Collaboration
- Channels — subscribe/unsubscribe to TAK Server data channels for scoped situational awareness
- Chat — geo-referenced messaging with individual users, groups, or all connected clients
- Voice (Mumble) — integrated push-to-talk via Murmur/Mumble server (murmur.takserver.svc:64738)
- Video — MediaMTX RTSP/HLS stream viewer, attach live feeds to map markers
- Tasks — assign, track, and complete field tasks tied to map locations
## 🔌 Connections
- TAK Server — SSL connection to 152.42.155.95:8089 (tcp) / :8443 (ssl)
- NATS — live fabric connection via AI Bridge for agent-driven map ops
- Plugin System — load/unload plugins at runtime (NATS, Hermes AI, Ops, Mumble, ClickHouse, Legacy AI)
- WebSocket — real-time CoT stream browser-native connection
- External Feeds — connect custom CoT/UDP/TCP feeds and third-party data sources
## 🧠 AI & Intelligence
- Legacy AI Panel — floating Hermes chat pane, ask questions about the live map
- CopilotKit Runtime — AI co-pilot embedded in the COP interface
- TAK-ML — machine learning model inference on live video/sensor feeds
- ClickHouse Time Machine — query historical CoT tracks, replay missions
- Intel Feeds — live OSINT overlays (EMSC, GDACS, EONET, USGS, AIS, ADS-B, satellites)
## ⚙️ User & Admin
- User Management — create, enroll, and manage TAK client certificates
- Groups — assign users to operational groups for scoped data visibility
- Missions — create named missions, attach tracks, files, and chat history
- Profiles — save and restore map configurations, overlay settings, and plugin layouts
- Audit Log — track all user actions and CoT events
