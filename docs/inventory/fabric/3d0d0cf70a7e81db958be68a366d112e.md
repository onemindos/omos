## What is VR-TAK
The VR-TAK development effort leverages virtual reality to create a virtual world capable of interacting with and manipulating data in the TAK ecosystem for mission planning and heads up augmented reality operation. The 3D content, created by FMVto3D, can be viewed using commercial virtual reality (VR) hardware, through a desktop using video game controllers/keyboard and mouse, or handheld on TAK devices.
## 📺 Viewing Modes
- Commercial VR headset (Meta Quest, etc.)
- Desktop — video game controllers, keyboard and mouse
- Handheld — on TAK-enabled Android/iOS devices
## 🎯 Use Cases
- Mission planning in immersive 3D environment
- Heads-up augmented reality operations
- 3D terrain and building visualization from FMV footage
- Interact with and manipulate live TAK ecosystem data in 3D

## 📁 Dataset Formats Supported
### Terrain Elevation
- DTED, Quantized Mesh, Mapbox
### 3D Tiles
- gltf, b3dm, glb, geojson (polygons only)
### Point Clouds
- xyz, pts, txt, las, lax, e57
### Raw Mesh Formats
- OBJ, FBX, DAE (Collada), 3DS, BLEND, etc.
### Geo-tagged Datasets
- BuckEye, Context Capture, FG3D, Hivemapper, CORE 3D, NearMap3D, PeARL
### Other
- KML/KMZ files
- Mapbox vector tiles
