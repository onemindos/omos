## Local Deployment (Docker Desktop)
Run locally to review features and concepts. Clone from GitHub link above, or use the pre-built onemindos image.
### docker-compose.yml
```yaml
version: '3.8'
services:
  worldwideview:
    image: ghcr.io/onemindos/worldwideview:latest
    # OR build from source:
    # build: .  # clone https://github.com/silvertakana/worldwideview
    ports:
      - "3000:3000"
    environment:
      DATABASE_URL: "postgresql://postgres:postgres@worldwideview-db:5432/worldwideview?schema=public"
      NEXT_PUBLIC_WWV_EDITION: "local"
      PROXY_HOST_ALLOWLIST: "*"
    volumes:
      - worldwideview-data:/app/data
    depends_on:
      - worldwideview-db
    restart: unless-stopped

  worldwideview-db:
    image: postgres:15-alpine
    environment:
      POSTGRES_DB: worldwideview
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: postgres
    volumes:
      - worldwideview-postgres-data:/var/lib/postgresql/data
    restart: unless-stopped

volumes:
  worldwideview-data:
  worldwideview-postgres-data:
```
### Quick Start
```shell
# Save the above as docker-compose.yml then:
docker compose up -d

# View logs
docker compose logs -f

# Stop
docker compose down
```
