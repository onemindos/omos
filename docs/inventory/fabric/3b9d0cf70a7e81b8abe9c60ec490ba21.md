## Local Deployment (Docker Desktop)
Run locally to review features and concepts. Clone from GitHub link above, or use the pre-built onemindos image.
### docker-compose.yml
```yaml
version: '3.8'
services:
  crucix:
    image: ghcr.io/onemindos/crucix:latest
    # OR build from source:
    # build: .  # clone https://github.com/calesthio/Crucix
    ports:
      - "3117:3117"
    environment:
      PORT: "3117"
      REFRESH_INTERVAL_MINUTES: "15"
    volumes:
      - crucix-runs:/app/runs
    restart: unless-stopped

volumes:
  crucix-runs:
```
### Quick Start
```shell
# Save the above as docker-compose.yml then:
docker compose up -d

# View logs
docker compose logs -f

# Stop
docker compose down
```
