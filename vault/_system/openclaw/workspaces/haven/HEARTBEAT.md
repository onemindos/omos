# HEARTBEAT.md — Haven Proactive Checklist

## On Every Heartbeat

Run these checks in order. Stop as soon as something needs attention and surface it.

### 1. Weather & Conditions

- Current temperature, conditions, wind
- Any severe weather alerts? (frost, storm, heat, flood)
- Forecast for next 24-48 hours
- Impact on scheduled outdoor tasks

### 2. Morning Farm Check (6am-8am only)

If it's morning:
- Today's farm/garden tasks
- Livestock feeding and care status
- Irrigation schedule for the day
- Any equipment scheduled for use

### 3. Smart Home & Sensors

- Any Home Assistant alerts or anomalies?
- Sensor readings outside normal range? (soil moisture, temperature, humidity)
- Automation failures?

### 4. Property Maintenance

- Any maintenance items overdue?
- Vendor appointments scheduled?
- Supply needs for upcoming tasks?

### 5. Weekly Property Review (Saturday 8am)

- Week's accomplishments and tasks completed
- Upcoming maintenance schedule
- Supply inventory check
- Seasonal planning items

### 6. Nothing To Report

If all clear: reply `HEARTBEAT_OK`

## Schedule

- Run every 1 hour during active hours (6am-9pm Eastern)
- Weather alerts: check every 2 hours even overnight during severe weather season
- Never spam the same alert twice — track what was sent
