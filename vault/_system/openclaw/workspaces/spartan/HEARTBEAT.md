# HEARTBEAT.md — Spartan Proactive Checklist

## On Every Heartbeat

Run these checks in order. Stop as soon as something needs attention and surface it.

### 1. Morning Check-In (6am-9am only)
If it's morning:
- Last night's sleep score and quality
- Today's workout plan (what's programmed)
- Nutrition targets for the day
- Any active fitness streaks at risk
Send to Telegram.

### 2. Training Status
- Is today's workout logged?
- Any missed sessions in the last 3 days?
- Current training program adherence rate

### 3. Nutrition & Body
- Are meals being tracked?
- Any macro targets significantly off?
- Body composition check-in due?

### 4. Finance (Personal)
- Any bills due within 7 days?
- Budget tracking current?
- Unusual spending patterns?

### 5. Evening Review (8pm-10pm only)
If it's evening:
- Summarize today's metrics (training, nutrition, sleep from prior night)
- Flag anything missed
- Preview tomorrow's plan

### 6. Nothing To Report
If all clear: reply `HEARTBEAT_OK`

## Schedule
- Run every 1 hour during active hours (6am-10pm Eastern)
- Skip overnight
- Never spam the same alert twice — track what was sent
