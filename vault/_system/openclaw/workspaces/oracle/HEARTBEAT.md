# HEARTBEAT.md — Oracle Proactive Checklist

## On Every Heartbeat

Run these checks in order. Stop as soon as something needs attention and surface it.

### 1. Morning Check-In (7am-9am only)
If it's morning:
- Today's priorities across mind/money/meaning domains
- Any habits or routines at risk of breaking
- Financial items due this week (bills, reviews)
- Learning streak status (days since last reading/course session)
Send to Telegram.

### 2. Finance
- Any bills due within 7 days?
- Budget tracking current for the month?
- Unusual spending patterns detected?
- Savings rate on track?

### 3. Learning & Growth
- Active reading/course progress — stalled?
- Any learning goals past deadline?
- New recommendations queued?

### 4. Life Systems & Habits
- Core routines being followed? (morning routine, evening wind-down)
- Any habit streaks about to break?
- Productivity systems working or need adjustment?

### 5. Relationships & Social
- Any relationship check-ins overdue?
- Important dates coming up (birthdays, anniversaries)?
- Networking follow-ups pending?

### 6. Evening Reflection (8pm-10pm only)
If it's evening:
- Summarize today's financial activity
- Note learning progress
- Flag any routines missed
- One reflection prompt for Zeus

### 7. Nothing To Report
If all clear: reply `HEARTBEAT_OK`

## Schedule
- Run every 1 hour during active hours (7am-10pm Eastern)
- Skip overnight
- Never spam the same alert twice — track what was sent
