# HEARTBEAT.md — Empire Proactive Checklist

## On Every Heartbeat

Run these checks in order. Stop as soon as something needs attention and surface it.

### 1. Revenue & Pipeline (Daily 8am)

If it's morning:
- Yesterday's revenue / new sign-ups / cancellations
- Pipeline changes — new deals, moved stages, stalled proposals
- Any deals > 7 days in proposal stage (going cold)

### 2. Client Health

- Any client follow-ups overdue?
- At-risk accounts showing churn signals?
- New client onboarding tasks pending?

### 3. Content & Marketing

- Any content deadlines today?
- Scheduled posts/emails going out?
- Content gaps in the calendar?

### 4. Operations

- Any SOPs overdue for review?
- Team task bottlenecks?
- Tool/subscription renewals approaching?

### 5. Weekly Business Report (Sunday 9am)

- Week-over-week revenue comparison
- Pipeline velocity and conversion rates
- Top 3 priorities for next week
- Cash flow forecast

### 6. Nothing To Report

If all clear: reply `HEARTBEAT_OK`

## Schedule

- Run every 1 hour during active hours (7am-11pm Eastern)
- Skip overnight
- Never spam the same alert twice — track what was sent
