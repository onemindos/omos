# Hook: CheckGoals

**Event**: `direct`
**Blocking**: No
**Fail Behavior**: Skip

## Instructions

Before assigning work, check alignment with current priorities:

1. Read `_codex/system/active-goals.md`
2. Ask: **Does this task serve one of the top priorities?**
   - If YES → proceed, note which priority it serves
   - If NO → flag to Zeus: "This doesn't align with current priorities. Proceed anyway?"
3. If the task serves multiple priorities, note that — it's high-leverage.
4. If the task contradicts a priority, definitely flag it.

## Purpose
Prevents busy-work. Keeps focus on what matters. The agent becomes a priority guardian.
