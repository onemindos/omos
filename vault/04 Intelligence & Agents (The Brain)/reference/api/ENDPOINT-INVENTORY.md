## Architecture Notes

### Source of Truth: `backend/onemindos.py`

1. Creates AgentOS instance with agents, teams, workflows
2. Gets FastAPI app from `agent_os.get_app()`
3. Overrides `/models` with custom Bedrock list
4. Adds `/tools` endpoint
5. Mounts all custom routers via `mount_custom_routes()`

### Router Mounting Pattern

```python
# Routers with their own prefix (mounted at root)
routers_to_mount.append(("", router, "name"))  # Router has /api/xxx prefix

# Routers without prefix (mounted with path)
routers_to_mount.append(("/awareness", router, "awareness"))
```

### Chat Flow

```
Client → POST /agents/legacy-mother-ai/runs
       → AgentOS handles routing
       → Agent.run() with streaming
       → Response (SSE stream or JSON)
```
