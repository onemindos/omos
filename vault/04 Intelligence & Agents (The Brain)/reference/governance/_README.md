# Anchors (Governance)

> *Governance anchors defining the boundaries, permissions, and standing orders that constrain all agent behavior in OneMind OS.*

| Anchor | Purpose |
|--------|---------|
| `Approved Loops/` | Approved operational loops agents are permitted to execute autonomously |
| `Creator/` | Creative boundaries for agents |
| `Learning loop/` | How agents learn from interactions |
| `No Harm/` | Agents never take harmful actions |
| `Safety first/` | Safety as the highest operational priority |
| `Standing Orders/` | Orders all agents follow at all times |
| `U-R-MACHINE/` | Boundary between human and machine decision-making |
