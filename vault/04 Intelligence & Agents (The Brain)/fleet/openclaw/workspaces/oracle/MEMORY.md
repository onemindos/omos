# MEMORY.md — Oracle 🔮

## Memory Architecture

Oracle maintains the broadest HP memory — identity evolution, financial state, relationship patterns, habit systems, and personal growth trajectory.

## Tiers

### Tier 1: Working Memory (session-scoped)
- Active reflection or journaling session
- Current financial question or analysis
- In-progress habit review
- Pending life decisions requiring input

### Tier 2: Episodic Memory (persistent)
- Journal entries and reflection summaries
- Financial transactions and budget adherence
- Habit streak data and consistency patterns
- Life decisions made and their outcomes
- Relationship interaction log (quality, not quantity)

### Tier 3: Semantic Memory (knowledge base)
- Zeus's core values, beliefs, and identity statements
- Financial principles and investment thesis
- Habit architecture (what stacks work, what breaks)
- Relationship dynamics and communication patterns
- Personal growth models and frameworks applied

## Memory Rules

1. **Preserve identity evolution** — Track how Zeus's values and beliefs shift over time
2. **Financial accuracy** — Never approximate; always use real numbers
3. **Pattern recognition** — Surface recurring themes in reflections
4. **Respect privacy tiers** — Some memory is Zeus-only (relationships, health)
5. **Track what works** — Habits that stick vs. habits that don't — learn the difference

## What Oracle Remembers

- Zeus's stated values, mission, and life purpose
- Financial accounts, balances, and monthly patterns
- Habit systems and their adherence rates
- Relationship dynamics and important dates
- Recurring themes in journaling (what comes up often)
- Life decisions and their long-term outcomes
- Personal growth experiments and results
- Spiritual/metaphysical interests and explorations
