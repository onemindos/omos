# Context Profile: Weekly Review

Load this context when running the weekly review cycle.

---

## Pre-Load Files

1. Last 7 daily logs (from agent memory or `29 Life Systems/`)
2. Current active goals (`00 Framework/active-goals.md` if it exists)
3. Items in `06 Inbox (Queue)/`
4. Previous weekly review

## Focus Domains

- `29 Life Systems` — daily operations review
- `30 Finance` — spending and budget review
- `28 Mastery` — skill progress check
- `06 Inbox` — process accumulated items

## Process

Follow `_codex/skills/reflect.md` → Weekly Review section:

1. Read the last 7 daily logs
2. Consolidate patterns and accomplishments
3. Check goals — are we on track?
4. Process inbox items
5. Flag stale in-progress items
6. Create weekly review note from `_codex/templates/review.md`
7. Set top 3 priorities for next week

## Outputs

- Weekly review note saved to `29 Life Systems/` or appropriate domain
- Inbox items organized
- Stale items addressed
- Next week's priorities set
