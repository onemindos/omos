# mistral-embed

| Model ID | Dims | Context | Best Use |
|----------|------|---------|---------|
| `mistral-embed-latest` | 1024 | 8K | Text semantic search |
| `codestral-embed-latest` | 1024 | — | Code semantic search |

**mistral-embed:** General-purpose text embeddings for pgvector RAG. Drop-in replacement for OpenAI text-embedding-3-small.

**codestral-embed:** Code-specific embeddings — higher recall for code search vs. generic embeddings.
