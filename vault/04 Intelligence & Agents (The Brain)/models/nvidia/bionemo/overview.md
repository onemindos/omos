# BioNeMo

NVIDIA's biological AI platform — generative AI for drug discovery and molecular biology.

## Platform Components

| Model | Type | Notes |
|-------|------|-------|
| `ESM2nv` | Protein LM | Protein sequence → structure/function embeddings |
| `MolMIM` | Small molecule | Molecular embedding and property prediction |
| `DiffDock` | Docking | Diffusion-based protein-ligand docking |
| `EquiDock` | Docking | Equivariant protein-protein docking |
| `AlphaFold2-Multimer` | Structure | Protein complex structure prediction |
| `Generative Chemistry` | Drug design | Molecule generation with property constraints |
| `DNABERT` | Genomics | DNA sequence understanding |

## What BioNeMo Is

AI framework for computational drug discovery — from protein structure prediction to de novo molecule generation. Used by pharma and biotech for lead optimization and target identification.

Access via: NVIDIA BioNeMo Service (`https://bionemo.ai`) or self-hosted via BioNeMo Framework (open source).

## Stack Use Cases

- Longevity track (Spartan/HP): protein folding analysis for health optimization
- Eden track: agricultural biology (plant protein engineering)
- Long-horizon R&D: drug repurposing discovery pipeline
- Research synthesis: combine with Oracle agent for biomedical literature review
