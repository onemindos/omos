# doubao

ByteDance's LLM family — OpenAI-compatible via the ARK platform.

| Model ID | Context | Best Use |
|----------|---------|---------|
| `doubao-pro-32k` | 32K | Flagship LLM |
| `doubao-lite-32k` | 32K | Cheap bulk text processing |
| `doubao-lite-128k` | 128K | Cheapest long-context option |

**API:** `https://ark.cn-beijing.volces.com/api/v3` — requires ARK API key + endpoint deployment ID from VolcEngine console.

> Note: Servers in Beijing — 300–700ms from US/EU, use for async/batch.
