### 💪 Capabilities

*   **Function calling**: Define and execute tools
*   **API integration**: REST API calls, database queries
*   **Structured outputs**: JSON schema validation
*   **Multi-tool**: Parallel function execution
*   **Open source**: First open-source function-calling model

### 🔧 Function Calling Format

```python
# Define tools
tools = [
    {
        "name": "get_weather",
        "description": "Get weather for location",
        "parameters": {
            "location": {"type": "string"},
            "unit": {"type": "string", "enum": ["celsius", "fahrenheit"]}
        }
    }
]

# Model generates function calls
response = model.generate(prompt, tools=tools)
# Output: {"name": "get_weather", "arguments": {"location": "San Francisco", "unit": "celsius"}}
```
