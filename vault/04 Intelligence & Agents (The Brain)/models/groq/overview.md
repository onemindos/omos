# Groq

**Type:** Cloud inference API (LPU — Language Processing Unit hardware)
**API base:** `https://api.groq.com/openai/v1` (OpenAI-compatible)
**Key var:** `GROQ_API_KEY`
**Free tier:** Yes — rate-limited but functional

## Why Groq

Groq's LPU delivers industry-leading token throughput — 500–1500 tokens/sec vs ~100–200 tok/s for GPU inference. Fastest available cloud inference for interactive agents.

## Stack Use Cases

- Real-time agent streaming (voice pipeline, live UI)
- Low-latency tool-calling loops where speed bottlenecks a pipeline
- Free-tier inference for dev/testing without burning OpenAI credits
