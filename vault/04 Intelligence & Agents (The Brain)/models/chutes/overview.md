# Chutes

**Type:** Decentralized AI inference marketplace (Bittensor-based)
**API base:** `https://llm.chutes.ai/v1` (OpenAI-compatible)
**Key var:** `CHUTES_API_TOKEN`
**Website:** chutes.ai

## What Chutes Is

Chutes.ai is a decentralized inference platform built on the Bittensor network (subnet 64). Miners compete to offer the best price and quality for GPU inference. Result: very cheap rates for open-weight models, with 100+ models available.

## Key Properties

- 100+ open models available (Llama, Qwen, DeepSeek, Mistral, etc.)
- OpenAI-compatible API — drop-in for most integrations
- Prices often cheaper than direct cloud APIs
- Models: constantly expanding — check chutes.ai for current list
- Decentralized — no single provider, quality can vary

## When to Use

- Budget inference when DO Gradient is unavailable
- Access to models not available on other providers
- Batch async tasks where quality variation is acceptable
- Exploring niche/fine-tuned models not on mainstream platforms

## Reliability Note

As a decentralized network, SLA is not guaranteed. Best used as a secondary/fallback provider rather than primary for production agent workloads.
