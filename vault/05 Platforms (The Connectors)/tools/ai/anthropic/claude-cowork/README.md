# Claude Co-Work — Collaborative AI Environment

Anthropic's collaborative work environment. Enables shared AI sessions, team projects, and multi-user context.

## Access

- Via `claude.ai` → Co-Work (when available on plan)
- Requires Claude.ai Team or Enterprise

## What It Is

Co-Work extends Claude beyond individual conversations into a shared team workspace:

- **Shared projects** — team members work in the same Claude context
- **Multi-user sessions** — multiple people interact with Claude simultaneously
- **Persistent team context** — knowledge and instructions shared across the team
- **Task delegation** — assign work across team + AI together

## How It Fits in One Mind

Co-Work is the human-AI collaboration layer. While agents (OpenClaw) handle autonomous background work, Co-Work is where Zeus and the team work *with* Claude together in real time.

- Agents (OpenClaw) → autonomous, background, scheduled
- Claude Code → individual developer sessions
- **Co-Work → team + AI, real-time collaboration**
- Claude.ai Projects → persistent individual context
