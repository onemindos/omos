## Protocols & Standards

> Technologies and protocols used across the stack — not tools you install, but standards you build on.

### Communication Protocols

| Protocol       | Purpose                                     | Used In                      |
| -------------- | ------------------------------------------- | ---------------------------- |
| **HTTP/HTTPS** | Web communication (request/response)        | All web services             |
| **REST**       | API architecture style (stateless, resource) | FastAPI, integrations        |
| **WebSocket**  | Full-duplex real-time connections            | onemind-web, LiveKit         |
| **WebRTC**     | Peer-to-peer video/audio/data               | LiveKit, voice agents        |
| **MQTT**       | Lightweight IoT messaging (pub/sub)         | Home Assistant, EMQX         |
| **NATS**       | Cloud-native messaging (JetStream)          | Agent coordination, events   |
| **RTSP**       | Video/audio streaming for cameras           | Frigate, surveillance        |

### Authentication & Security

| Standard  | Purpose                                  | Used In              |
| --------- | ---------------------------------------- | -------------------- |
| **JWT**   | Stateless auth tokens (signed claims)    | API auth, sessions   |
| **OAuth** | Delegated authorization                  | Composio, Zoho, etc. |

### Robotics & IoT

| Protocol | Purpose                                 | Used In           |
| -------- | --------------------------------------- | ----------------- |
| **ROS2** | Robot Operating System middleware       | OM1, Unitree      |
| **Zenoh** | Zero-overhead edge pub/sub (DDS alt)   | OM1 robotics      |
| **BLE**  | Bluetooth Low Energy (short-range)      | Wearables, sensors |
| **GPS**  | Location/navigation/timing              | Mobile, transport  |
| **5G**   | High bandwidth cellular (low latency)   | Mobile, IoT        |
