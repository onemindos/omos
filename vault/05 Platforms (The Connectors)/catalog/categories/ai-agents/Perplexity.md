# Perplexity

> **AI search engine with real-time web search and cited sources**

## Overview

Perplexity is an AI-powered answer engine that combines LLM reasoning with live web search. Unlike ChatGPT/Claude which have knowledge cutoffs, Perplexity retrieves current information and cites sources. Used as the primary research and real-time lookup tool.

## Use Cases in OneMind

1. **Research** — Deep dives on technology, competitors, frameworks
2. **Real-Time Info** — Current events, live data, recent releases
3. **Fact Verification** — Cite-backed answers for decision-making
4. **Competitive Analysis** — Market research for GE domain

## Key Features

- Real-time web search with citations
- Focused search (academic, news, social, video)
- File upload and analysis (Pro)
- API access for agent integration
- Spaces for persistent research threads
