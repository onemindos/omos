# HTML

> **HyperText Markup Language — structure layer of the web**

## Overview

HTML is the foundational markup language for all web content. Used in onemind-web templates, email templates (Resend), Webflow content, and Quartz-generated codex-live pages. Familiar to everyone; where all web rendering begins.

## Status

| Attribute   | Value                          |
| ----------- | ------------------------------ |
| Status      | ✅ Active                       |

| Type        | Markup Language                |
| Integration | Browser, Next.js, Webflow, JSX |

## Use Cases in OneMind

1. **onemind-web** — Underlying structure of React/JSX renders to HTML
2. **Email Templates** — Resend HTML emails for agent notifications
3. **codex-live** — Quartz converts Markdown → HTML pages
4. **Webflow** — CMS content editing in HTML/rich text
5. **React JSX** — JSX compiles to HTML via React.createElement

## Quick Reference

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>One Mind</title>
  </head>
  <body>
    <main>Content</main>
  </body>
</html>
```
