# Alibaba Cloud

> **Asia-Pacific cloud platform — largest cloud provider in China**

## Overview

Alibaba Cloud (Aliyun) is the leading cloud platform in Asia. Offers compute, storage, AI, databases, and CDN with strong Asia-Pacific coverage. Potential use for international deployments, Qwen model hosting, or cost optimization for specific workloads.

## Use Cases in OneMind

1. **Asia-Pacific Deployment** — Low-latency for Asia region traffic
2. **Qwen Hosting** — Native hosting for Alibaba's open-source LLMs
3. **Cost Optimization** — Compare pricing for specific compute workloads
4. **International Expansion** — If GE domain extends to Asia markets

## Key Features

- ECS (Elastic Compute Service)
- OSS (Object Storage, S3-compatible)
- PAI (Platform for AI) — Qwen model serving
- CDN across Asia
- DashScope API for Qwen models
