# Raycast

> **macOS launcher with AI, extensions, and script automation**

## Overview

Raycast is Zeus's primary macOS command center. Replaces Spotlight with instant app launching, AI queries, clipboard history, snippets, and an extension ecosystem of 1000+ integrations. Built-in AI (Claude, GPT-4) for inline queries without switching apps.

## Use Cases in OneMind

1. **App Launcher** — Primary keyboard-driven app and file access on Mac
2. **AI Queries** — Inline Claude/GPT-4 without browser context switching
3. **Clipboard History** — Recall anything copied in the last N days
4. **Snippets** — Expand text shortcuts into full templates
5. **Custom Scripts** — Shell/AppleScript extensions for codex operations

## Key Features

- Universal search (apps, files, commands)
- AI Chat (Claude 3.5, GPT-4o, Gemini)
- 1000+ community extensions
- Clipboard history and manager
- Floating Notes
- Window management
- Confetti (productivity dopamine)
