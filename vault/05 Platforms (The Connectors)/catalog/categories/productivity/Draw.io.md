# Draw.io (diagrams.net)

> **Diagramming & Visual Architecture Tool**

## Overview

Draw.io (also known as diagrams.net) is a free, open-source diagramming tool for creating flowcharts, architecture diagrams, network maps, org charts, and wireframes. Works in-browser, as a desktop app, or embedded in VS Code.

## Status

- **Active**: ✅ Yes (browser-based, no account required)
- **Plan**: Free (open source)
- **Last Updated**: 2026-05-01

## Use Cases

1. **System Architecture** — SO domain diagrams (infrastructure, agent flows)
2. **Framework Visualization** — 3+1 model diagrams for One Mind content
3. **Network Maps** — VPS topology, service connections
4. **Process Flows** — SOP visualization, CODEX method flowcharts
5. **Presentations** — Export diagrams for One Mind materials

## Key Features

- No login required for basic use
- Exports: PNG, SVG, PDF, XML
- VS Code extension: `hediet.vscode-drawio`
- Stores `.drawio` files locally (version-control friendly)
- Mermaid diagram import support
- Confluence / Notion integration

## Integration Notes

- `.drawio` files can live in `_codex/assets/diagrams/` alongside Mermaid files
- VS Code extension renders `.drawio` files inline
- Offline-capable when using desktop app
