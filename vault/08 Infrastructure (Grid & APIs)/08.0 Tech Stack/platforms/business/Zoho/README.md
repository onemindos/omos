## Authentication

- **Method**: OAuth 2.0
- **Scopes**: Per-app (CRM, Desk, etc.)
- **Token Storage**: 1Password
- **Refresh**: Automatic

## Cost

- **Plan**: Zoho One All-Employee
- **Monthly Cost**: Varies by user count
- **Current Users**: 1-5
- **Estimated**: ~$40-50/month

## Integration Points

- **Todoist**: Task sync via webhooks
- **Legacy AI**: API access to all apps
- **N8N**: Workflow automation
- **Home Assistant**: Notification routing

## API Documentation

- **Base URL**: `https://www.zohoapis.com/`
- **Rate Limits**: Varies by app (typically 5K-10K calls/day)
- **SDKs**: Python, JavaScript, Java
