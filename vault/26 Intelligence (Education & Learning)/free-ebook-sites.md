## 🔍 Searching by ISBN / Book ID

**Best options ranked:**

1. **LibGen** → paste ISBN directly in the main search bar. Returns immediately.
2. **Anna's Archive** → supports ISBN, DOI, MD5 hash. Most thorough.
3. **WeLib** → supports ISBN in search.
4. **Open Library** → search by ISBN: `openlibrary.org/isbn/9780743273565`

**Pro tip for ISBN searches:**
```
LibGen URL format:  https://libgen.is/search.php?req=9780743273565&column=identifier
Anna's Archive:     https://annas-archive.org/?q=9780743273565
Open Library:       https://openlibrary.org/isbn/9780743273565
```

## 🛡️ Safety Notes

- **Legal sites** (Gutenberg, Archive, Open Library) = zero risk, no VPN needed
- **Gray-zone sites** = sites themselves are malware-free; risk is legal (copyright), not technical
- Always use **uBlock Origin** when browsing gray-zone sites — some have aggressive ads
- Gray-zone sites do NOT need you to install anything — download the file, done
- Scan with [VirusTotal](https://www.virustotal.com) if ever unsure about a download
