# Cognitive Architecture – One Mind v0.1

## Inputs
- Physical: sensors, wearables, labs, photos, journaling
- Digital: emails, PDFs, RSS, socials, scraped pages
- Agent logs: Legacy AI agent outputs & decisions

## Memory Layers
- Short-term: 00-Command Center / Today's Mission Brief
- Medium-term: Mission Logs, Weekly War Room notes
- Long-term: Path protocols, frameworks, and archives in 01–04 Paths

## Processing
1. Capture → 00-Inbox
2. Classify → move to Path or Support Systems
3. Distill → notes become protocols or frameworks in Paths
4. Automate → Legacy AI + n8n workflows
5. Review → Metrics + Weekly War Room

## Outputs
- Tasks & Missions (Command Center / Launchpad)
- Protocol updates (Paths)
- Automations (Legacy AI + n8n)
- Community content (Circle)
