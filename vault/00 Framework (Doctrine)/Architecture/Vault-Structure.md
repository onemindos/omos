# Legacy Codex - Vault Architecture (v2.0)

**Version**: 2.0
**Last Updated**: December 1, 2025
**Purpose**: Master architecture and mind map of the entire Legacy Codex vault

---

## 🎯 Architecture Philosophy

### Core Principles
1. **Purpose-Driven Organization** - Content grouped by life purpose, not status
2. **Single Source of Truth** - Each piece of content has ONE authoritative location
3. **30+ Year Sustainability** - Built for generational knowledge transfer
4. **Intuitive Navigation** - Think in domains: Business → Self → Family → Systems
5. **Cross-Pillar Integration** - Clear linking strategy for initiatives spanning pillars

### The Four Layers Model

```
┌────────────────────────────────────────────────────────────┐
│  LAYER 0: CAPTURE & NAVIGATION (00-Inbox, 01-Atlas)       │
│  ↓ Process & route incoming information                    │
├────────────────────────────────────────────────────────────┤
│  LAYER 1: THE FOUR PILLARS (02-05)                        │
│  ↓ Purpose-driven life domains                             │
├────────────────────────────────────────────────────────────┤
│  LAYER 2: SUPPORT SYSTEMS (06-08)                         │
│  ↓ Cross-pillar infrastructure                             │
├────────────────────────────────────────────────────────────┤
│  LAYER 3: ARCHIVES & EXTERNAL (99, Organize)              │
│  ↓ Historical and unprocessed content                      │
└────────────────────────────────────────────────────────────┘
```

## 🔗 Cross-Pillar Integration Patterns

### Pattern 1: Single Source of Truth + Links

**Principle**: Content lives in ONE location, others link to it

**Example**: Legacy AI
- **Primary (IT)**: Technical implementation
- **Secondary (GE)**: Business strategy → Links to IT for technical details
- **Connection**: Bidirectional README files with clear links

**Principle**: Complex projects spanning pillars get central documentation

**Example**: Private Equity Fund Launch
- **MOI Location**: GE (primary pillar)

- **Integration**: Central MOI tracks all pillar activities

## 📏 Naming Conventions Summary

### Folder Naming Standards

| Pillar | Prefix | Example |
|--------|--------|---------|
| GE | Entity/Business name | `Legacy AI`, `Founder Ops` |
| HP | `Zeus -` | `Zeus - Finance`, `Zeus - Performance` |
| LE | `Delacruz -` | `Delacruz - Wealth`, `Delacruz - Estate` |
| IT | `##-[Name] Ops` | `01-Legacy AI Ops`, `03-Cybersecurity Ops` |

### File Naming Standards

**Good Naming**:
- Descriptive: `Business Credit Building Strategy.md`
- Contextualized: `GE - Legacy AI Product Roadmap 2025.md`
- Versioned: `Vault Architecture v2.0.md`

**Avoid**:
- Ambiguous: `Finance.md` (which pillar?)
- Duplicate: `Personal Credit.md` and `Personal Credit Repair.md`
- Special characters: `Finance:Funding!@#.md`

