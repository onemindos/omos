# AI Agent Navigation Protocol

> **Where to look first, what to read, how to navigate the vault**

---

## Session Start Checklist

Every time you start a new conversation or context:

### 1. Read the Master Document (First Priority)
**Location:** `/ONEMIND-CODEX.md`

**What to read:**
- Part 1-2: Vision & Philosophy (understand WHY)
- Part 3: Architecture (understand WHAT)
- Part 4: AI Layer (understand YOUR ROLE)
- Part 5: Operating Rhythm (understand WHEN)

**Time investment:** 5-10 minutes
**Frequency:** Every session start

---

### 2. Load Current Context (Second Priority)

**From your memory blocks:**
- Zeus Profile (identity, values, preferences)
- Current Context (today's priorities, active focus)
- System State (agent status, health metrics)
- Your domain context (HP/LE/GE specific)

**From Command Center:**
- Location: `00-24 SO/01 Command/`
- Check today's briefing
- Check pending approvals
- Check active priorities

## Routing Decision Tree

When you receive a request, use this logic:

```
1. Does it involve health, fitness, learning, personal growth?
   → HP Agent (25-49) handles it

2. Does it involve family, home, children, estate, legacy?
   → LE Agent (50-74) handles it

3. Does it involve business, revenue, products, marketing?
   → GE Agent (75-99) handles it

4. Does it involve tech, automation, infrastructure, AI?
   → UI handles it directly

5. Cross-path or unclear?
   → UI coordinates (ask clarifying questions)
```

**See also:** [Routing-Rules.md](Routing-Rules.md) for detailed routing logic

## File Discovery Protocol

When you need to find information:

### Step 1: Check the Master Doc First
`/ONEMIND-CODEX.md` has the complete system overview

### Step 2: Use the Framework Index
`00-24 SO/00 Framework/INDEX.md` for navigation

### Step 3: Check Domain-Specific Folders
Navigate to the pillar (HP/LE/GE) based on routing rules

### Step 4: Search by File Name Pattern
Files follow naming convention: `XX.Y Name.md`
- XX = domain number (00-99)
- Y = sub-category

### Step 5: Use Grep/Search
If still not found, search vault for keywords
