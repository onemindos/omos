## What It Does

Open-source framework for creating AI agents with persistent identity ("souls") that can transfer across different physical forms — robots, avatars, smart devices.

**Tagline:** "The soul of self-sovereign machines"

**Vision:** "Putting agents into physical systems is the unlock that will move AI from abstract software to tangible companions in the home."

---

## Core Architecture

Brain-inspired modular design:

| Component        | Function                                             |
| ---------------- | ---------------------------------------------------- |
| **Thalamus**     | Central sensory relay hub with intelligent filtering |
| **Cochlea**      | Audio input processing (voice, sound)                |
| **Letta Kernel** | Core infrastructure for agent orchestration          |
| **SMCP**         | Internal MCP server for framework integration        |
| **Animus Chat**  | TUI chat interface for agents                        |

## Weaknesses ❌

- **Robotics-focused** — not a life management system
- **No PKM** — agent framework, not knowledge system
- **No task management** — infrastructure only
- **Early stage** — limited documentation
- **Developer-only** — requires significant coding skills
- **Crypto-adjacent** — has token/contract elements
- **No consumer product** — framework, not app

## Relationship to OneMind

**Animus and OneMind are more complementary than competitive:**

1. **Shared Infrastructure:** Both use Letta for agent memory
2. **Shared Vision:** Both aim for embodied, persistent AI
3. **Different Layers:**
   - Animus = agent framework (infrastructure)
   - OneMind = life OS (application layer)

**Potential Integration:**

- OneMind could use Animus components for agent embodiment
- Animus agents could integrate with OneMind's life domains
- Both benefit from Letta ecosystem development
