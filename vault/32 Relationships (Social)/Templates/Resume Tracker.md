## Resume Quality Checklist

### Content ✅

- [ ] Contact info current (phone, email, LinkedIn, location)
- [ ] Professional summary (2-3 sentences, value proposition)
- [ ] Experience in reverse chronological order
- [ ] Each role has 3-5 bullet points
- [ ] Bullets start with action verbs
- [ ] Quantified results (numbers, %, $)
- [ ] Skills section targeted to role
- [ ] Education and certifications included
- [ ] No personal pronouns (I, me, my)
- [ ] No unexplained gaps
- [ ] Relevant to target role (70%+ match)

### Format ✅

- [ ] ATS-friendly format (no tables, text boxes, headers/footers)
- [ ] Simple, professional font (Arial, Calibri, Times New Roman)
- [ ] Font size 10-12pt
- [ ] Consistent formatting (spacing, bullets, alignment)
- [ ] 0.5-1" margins
- [ ] Fits on 1 page (or 2 if senior/extensive experience)
- [ ] PDF format for submission
- [ ] File name professional: FirstName_LastName_Resume.pdf

### Accuracy ✅

- [ ] No typos or grammatical errors (proofread 3x)
- [ ] Dates accurate and consistent format
- [ ] Company names spelled correctly
- [ ] Job titles accurate
- [ ] All claims verifiable
- [ ] References available if requested
