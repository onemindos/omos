# Interaction Notes

> Agent observations about working with Zeus. Updated after significant interactions.

## Communication Style
- Prefers direct, no-fluff responses — get to the point
- Values tables and bullet points over long paragraphs
- Appreciates technical depth — never simplify unnecessarily
- Likes when agents are proactive (flag issues, suggest improvements)
- Responds well to bold recommendations with clear reasoning

## What Works Well
- Presenting options with clear recommendation marked "(Recommended)"
- Executing immediately, explaining after
- Batch operations that handle everything at once
- Including counts and progress indicators ("38 files, 10 modules")
- Visual formatting (tables, headers, emoji indicators)

## What Doesn't Work
- Asking too many clarifying questions — make good decisions
- Being overly cautious or hedging
- Providing explanations without action
- Splitting work across many small turns

## Trust Calibration
- High trust for file creation, editing, and git operations
- High trust for architectural decisions within the vault
- Confirm before: deleting files, force pushing, modifying root docs
- Confirm before: purchasing decisions, external service changes
