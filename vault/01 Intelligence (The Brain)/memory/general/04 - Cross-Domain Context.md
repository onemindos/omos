## Domain Dependencies

**Business Operations depends on:**
- Infrastructure (system uptime for CRM/operations)
- Communications (client coordination and follow-ups)

**Finance depends on:**
- Intelligence (market news and analysis)
- Infrastructure (data feeds and portfolio APIs)

**Homestead Operations depends on:**
- Home Command (shared infrastructure and automation)

**All Agents depend on:**
- Infrastructure (core systems and services)

## Shared Resources

**Obsidian Vault (Universal Knowledge Repository)**
- Used by: All agents
- Write access: Intelligence, Performance, Founder Assistant, Communications, Homestead Operations
- Purpose: Primary RAG source, knowledge management, daily notes
- Status: Migration in progress from ClickUp/Notion/Reader

**Todoist (Task Management)**
- Used by: All agents
- Write access: All agents
- Purpose: Task capture, tracking, and distribution
- Status: Active, being integrated with agent workflows

**Calendar System**
- Used by: All agents for time-based triggers
- Write access: Communications, Founder Assistant
- Purpose: Scheduling, meeting coordination, time-based automation
- Status: Active

**Home Assistant (Multi-Location Automation)**
- Used by: Home Command, Homestead Operations, Robotics
- Write access: Home Command (primary), Homestead Operations (farm-specific)
- Purpose: Physical infrastructure control across all locations
- Status: Active at Office and Home, planned for Farm and Warehouse

## Integration Flow Patterns

**Intelligence → Finance:**  
Market news and trend analysis feed into portfolio decision-making

**Performance → All Agents:**  
User's energy state influences task prioritization across all domains

**Infrastructure → All Agents:**  
System health determines agent availability and task execution

**Communications → Founder Assistant:**  
Inbound requests trigger meeting scheduling and preparation workflows

**Homestead Operations → Home Command:**  
Farm-specific automation coordinates with broader home infrastructure

**Robotics → Homestead Operations:**  
Drone surveys and automation feed into farm operations planning
