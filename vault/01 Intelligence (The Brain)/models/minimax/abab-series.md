# abab series

MiniMax's faster, cheaper model family for shorter context tasks.

| Model ID | Context | Input | Output | Notes |
|----------|---------|-------|--------|-------|
| `abab6.5s-chat` | 245K | $0.10/1M | $0.10/1M | Fast, balanced quality |
| `abab6.5g-chat` | 8K | $0.005/1M | $0.005/1M | Cheapest, short tasks |
| `abab5.5-chat` | 16K | $0.015/1M | $0.015/1M | Legacy model |

**Best for:** High-volume cheap tasks when MiniMax-Text-01's 4M context isn't needed. `abab6.5g` is one of the cheapest models available at $0.005/1M.
