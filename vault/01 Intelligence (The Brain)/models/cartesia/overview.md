# Cartesia

**Type:** Ultra-low latency TTS (Text-to-Speech)
**API base:** `https://api.cartesia.ai`
**Key var:** `CARTESIA_API_KEY`
**Website:** cartesia.ai

## Why Cartesia

Built specifically for real-time voice agents — Sonic 2 achieves ~90ms time-to-first-audio, the lowest latency of any TTS provider. Designed as the TTS layer in LiveKit voice pipelines.

See model files in this folder.

## Stack Use Cases

- Legacy agent voice output (primary TTS)
- LiveKit pipeline TTS layer
- Any real-time conversational voice interaction
- Sub-100ms response — user can't perceive the delay
