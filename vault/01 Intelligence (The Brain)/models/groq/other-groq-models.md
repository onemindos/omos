# other-groq-models

Additional models on Groq LPU.

| Model ID | Context | Notes |
|----------|---------|-------|
| `mixtral-8x7b-32768` | 32K | MoE — good reasoning, fast |
| `gemma2-9b-it` | 8K | Google Gemma 2 9B |
| `deepseek-r1-distill-llama-70b` | 128K | DeepSeek R1 reasoning on Groq speed |
| `compound-beta` | 128K | Groq-native agentic model with tool use |
| `compound-beta-mini` | 128K | Lighter version of compound-beta |

**deepseek-r1 on Groq:** Chain-of-thought reasoning at LPU speed — best of both worlds.

**compound-beta:** Groq's own agent model — built-in web search + code execution. No extra plumbing needed.
