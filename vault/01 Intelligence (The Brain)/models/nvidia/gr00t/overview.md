# GR00T

NVIDIA's humanoid robot foundation models — the physical embodiment AI layer.

| Model | Notes |
|-------|-------|
| `gr00t-n1-2b` | 2B action model — maps perception to robot actions |
| `gr00t-n1.5` | Updated N1 with improved sim-to-real transfer |

## What GR00T Is

Project GR00T (Generalist Robot 00 Technology) — foundation model for humanoid robots. Takes multimodal input (vision + language instructions) and outputs robot motor actions. Trained with Isaac GR00T SDK in Isaac Sim.

## SDK

Isaac GR00T SDK — Python SDK for training and deploying GR00T models on physical robots or in simulation.

## Stack Use Cases

- Research track: Embodied AI for physical presence / robotics R&D
- Integration with Cosmos world models for synthetic training data pipeline
- Long-horizon use case: physical agent layer (10+ year horizon for OneMind OS)
