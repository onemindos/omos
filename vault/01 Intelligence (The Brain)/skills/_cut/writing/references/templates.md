# Writing Templates

## Email Templates

### Request Email
```
Subject: [Action Needed] Brief description

Hi [Name],

[One sentence context]

I'm reaching out because [specific request].

[Supporting details if needed]

Could you [specific action] by [date]?

Thanks,
[Your name]
```

### Update Email
```
Subject: Update: [Project/Topic]

Hi team,

Quick update on [topic]:

**Status:** [On track / Needs attention / Blocked]

**Progress:**
- Completed X
- In progress Y
- Next up Z

**Blockers:** [None / Description]

**Next steps:** [What's happening next]

Let me know if you have questions.
```

### Follow-up Email
```
Subject: Re: [Original subject]

Hi [Name],

Following up on [topic from date].

[Brief reminder of context]

[Restate request or question]

Let me know if you need anything from me.

Thanks!
```

## Documentation Templates

### README Structure
```markdown
# Project Name

One-line description of what this does.

## Quick Start

\`\`\`bash
npm install
npm start
\`\`\`

## Features

- Feature 1
- Feature 2

## Usage

[How to use it]

## Configuration

[Config options]

## Contributing

[How to contribute]

## License

MIT
```

### API Documentation
```markdown
## Endpoint Name

Brief description of what this endpoint does.

### Request

\`\`\`
POST /api/resource
\`\`\`

**Headers:**
- `Authorization: Bearer <token>`

**Body:**
\`\`\`json
{
  "field": "value"
}
\`\`\`

### Response

**Success (200):**
\`\`\`json
{
  "id": "123",
  "status": "created"
}
\`\`\`

**Error (400):**
\`\`\`json
{
  "error": "Invalid input"
}
\`\`\`
```
