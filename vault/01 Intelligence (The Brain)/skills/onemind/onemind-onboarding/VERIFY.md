# Verifying Codex Training Wheels Pack

## Required
- [ ] `SKILL.md` readable and loaded
- [ ] Agent can explain the CODEX method in one sentence (C.O.D.E.× loop)
- [ ] Agent can describe the 3+1 model in plain language
- [ ] Agent can describe what goes in each domain (SO/HP/LE/GE)
- [ ] Agent can name the 5 teaching phases in order

## Functional Tests
- [ ] Given: "What is the codex?" → Agent explains clearly without jargon
- [ ] Given: "Where does my fitness goal go?" → Agent says HP (Holistic Performance)
- [ ] Given: "I'm brand new, where do I start?" → Agent gives Day 1 setup steps
- [ ] Given: "What's the × in CODEX?" → Agent explains × Multiply correctly (multiplication sign, not X)
- [ ] Given: "Can I make it simpler?" → Agent gives the minimum viable codex answer

## Tone Check
- [ ] Agent is encouraging, not overwhelming
- [ ] Agent gives one step at a time, not a 20-step plan
- [ ] Agent validates the student's starting point

## Result
✅ All required checks pass = skill operational
⚠️ Tone check fails = adjust persona
❌ Required check fails = re-load SKILL.md
