# Installing Report Pack

## Phase 1: System Check
- [ ] `_codex/system/` exists with identity files
- [ ] `_codex/memory/` exists with learning tier
- [ ] `_codex/skills/report/` directory accessible
- [ ] `templates/` subdirectory contains all 4 templates

## Phase 2: Context Loading
1. Read `_codex/system/identity.md` — Know who you serve
2. Read `_codex/system/active-goals.md` — Know current priorities
3. Read `_codex/system/preferences.md` — Know output preferences

## Phase 3: Skill Activation
1. Read `SKILL.md` — These are your report generation instructions
2. Review all 4 templates in `templates/`
3. Note data sources and how to access each

## Phase 4: Verification
Run `VERIFY.md` checklist.

## Confirmation
✅ Report pack installed. Workflows: Quarterly Review, Domain Health, Family Legacy, Narrative Points. Ready for: structured report generation from vault data.
