# Opera

> Feature-rich browser with built-in AI (Aria), VPN, ad blocker, and crypto wallet.

## Key Features
| Feature | Notes |
|---------|-------|
| Aria AI | Built-in AI assistant |
| Free VPN | No-log, built-in |
| Ad blocker | Native, no extension needed |
| Workspaces | Tab grouping by context |
| Flow | Cross-device sync (phone ↔ desktop) |
| Crypto Wallet | Built-in Web3 wallet |
| Sidebar | Telegram, Messenger, WhatsApp, Discord |

## Variants
| Variant | Purpose |
|---------|---------|
| Opera | Standard desktop |
| Opera GX | Gaming-focused (CPU/RAM limiter) |
| Opera One | Tab Islands, modular UI |
