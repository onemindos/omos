# Safari

> Apple's native browser. Fast, energy efficient, deep macOS/iOS integration.

## Key Features
| Feature | Notes |
|---------|-------|
| Energy | Most efficient browser on Mac |
| Privacy | ITP (Intelligent Tracking Prevention) |
| Keychain | iCloud Keychain password sync |
| Handoff | Continue browsing on other Apple devices |
| Extensions | Safari Web Extension API |
| Reader | Distraction-free reading mode |
| Web Inspector | Built-in DevTools |

## Developer
```bash
# Enable Develop menu: Safari > Settings > Advanced > Show Develop menu
# Web Inspector: Develop > Show Web Inspector
# Allow JS from Apple Events (for automation)
```

## Integration
- 1Password extension
- Hermes CUA driver compatible
- Apple Pay native support
