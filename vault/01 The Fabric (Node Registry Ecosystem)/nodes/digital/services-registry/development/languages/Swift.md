# Swift

> **Apple's primary language for iOS, macOS, and cross-platform apps**

## Overview

Swift is Apple's modern programming language for building iOS and macOS applications. Used for onemind-mobile (iOS), Apple HealthKit integration, and native Apple platform features. Compiles to native code with strong performance and safety.

## Use Cases in OneMind

1. **onemind-mobile (iOS)** — Native iPhone app for vault access on mobile
2. **HealthKit** — Read Apple Health biometric data for HP domain
3. **SwiftUI** — Declarative UI for modern iOS apps
4. **Siri Shortcuts** — Voice-triggered codex actions
5. **Apple Watch** — WatchKit companion for HP wearable data
