# Cursor

> AI-powered code editor (VS Code fork). $20/mo. Deep AI integration for code completion, chat, and multi-file edits.

## Key Features
| Feature | Description |
|---------|-------------|
| Composer | Multi-file AI edits from natural language |
| Tab completion | Context-aware autocomplete |
| Chat | Inline AI assistant with codebase context |
| Rules | .cursorrules for project-specific AI behavior |

## Key Files

- **~/.cursor/settings.json** — Global config
