# Letta Desktop

> Desktop IDE for building and managing Letta AI agents. Visual interface for memory, tools, and conversations.

## Key Features
| Feature | Notes |
|---------|-------|
| Agent builder | Create/configure agents visually |
| Memory editor | View and edit agent memory blocks |
| Tool management | Add/remove/configure tools |
| Conversation view | Chat with agents, inspect reasoning |
| Local server | Connect to self-hosted Letta server |
| Deployment | Push agents to cloud or local |

## Use Cases
- Build custom agents with persistent memory
- Debug agent memory and tool calls
- Test agent behavior before deployment
- Manage multiple agents from one interface
