# Grok Build (xAI)

> xAI's autonomous coding agent. Browser-based, full-stack app generation from natural language.

## Use Case in OneMind OS
- Rapid prototyping and full-stack scaffolding
- Front-end + back-end generation in one shot
- Alternative coding agent alongside Claude Code, Codex, OpenCode

## Access
- Web: https://build.x.ai

## Key Features
| Feature | Notes |
|---------|-------|
| Full-stack generation | Front-end + back-end from a single prompt |
| Live preview | In-browser app preview |
| Grok-3 powered | xAI's flagship model under the hood |
| Iterative editing | Prompt-driven edits on generated code |
| Deploy | One-click deploy to web |

## Integration with OneMind OS
- Use for greenfield prototypes before handing off to Hermes/Claude Code
- Pair with xAI API (Grok models) for downstream agent workflows

## Cost
Included with xAI / X Premium+ subscription or pay-per-use API
