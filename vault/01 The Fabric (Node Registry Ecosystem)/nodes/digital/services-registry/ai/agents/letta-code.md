# Letta Code

> Letta's desktop IDE. Build and manage Letta AI agents with persistent memory, tool use, and multi-step reasoning.

## Key Features
| Feature | Notes |
|---------|-------|
| Agent builder | Visual agent creation |
| Memory management | Edit agent memory blocks |
| Tool configuration | Add/remove tools from agents |
| Conversation | Chat with agents directly |
| Deployment | Deploy agents to Letta Cloud or self-hosted |
