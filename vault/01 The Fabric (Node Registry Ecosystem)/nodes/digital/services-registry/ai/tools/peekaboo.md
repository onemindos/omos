# Peekaboo

> macOS vision tool — captures screenshots and analyzes screen content for AI agents.

## Role in OneMind OS
- Gives agents visual awareness of the Mac desktop
- Used by Legacy/OpenClaw to inspect UI state, read screens, verify visual output
- MCP-connected tool

## Config
- Location: `~/.peekaboo/`
- Interface: MCP tool

## Use Cases
- Screenshot capture for agent context
- Visual verification of UI actions
- Screen reading without OCR setup
