# ChatGPT

> OpenAI's desktop app. GPT-4o, o1, o3, canvas, code interpreter, DALL-E, browsing.

## Key Features
| Feature | Notes |
|---------|-------|
| Models | GPT-4o, o1, o3, o4-mini |
| Canvas | Collaborative writing/code editing |
| Code interpreter | Run Python in sandbox |
| DALL-E | Image generation |
| Browsing | Web search |
| Voice | Real-time voice conversation |
| Memory | Persistent user memory |
| GPTs | Custom assistants |
