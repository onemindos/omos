# Pipecloud

> **Cloud automation and workflow integration platform**

## Overview

Pipecloud is a serverless workflow automation and API integration platform. Enables event-driven workflows connecting services via triggers, actions, and custom code. Complements N8N for lightweight, cloud-hosted automation without VPS management.

## Use Cases in OneMind

1. **Cloud Automation** — Event-driven workflows without VPS hosting
2. **API Glue** — Connect services that lack native N8N nodes
3. **Serverless Functions** — Run code on webhook triggers
4. **Lightweight Pipelines** — Simple integrations outside the main N8N instance

## Key Features

- Event-driven workflows
- 500+ app connectors
- Custom code steps (Node.js / Python)
- Webhook triggers
- Scheduled workflows
- Free tier available
