# Grok (xAI)

> xAI's AI assistant. Real-time web search, code, image gen, and voice via X/Grok.com.

## Key Features
| Feature | Notes |
|---------|-------|
| Models | Grok-3, Grok-3 Mini, Grok-2 Vision |
| Real-time search | Live X/web data access |
| Image generation | Aurora image model |
| Voice | Real-time voice conversation |
| DeepSearch | Multi-step reasoning + web research |
| Think mode | Extended chain-of-thought reasoning |
| Code | In-chat code generation and execution |

## Access
- Web: https://grok.com
- X (Twitter) app: integrated sidebar
- API: https://api.x.ai

## Cost
Free tier available. X Premium+ includes full access (~$40/mo).
API: pay-per-token via xAI platform.
