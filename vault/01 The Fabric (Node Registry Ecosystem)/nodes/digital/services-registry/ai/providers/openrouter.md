# OpenRouter

> Model routing — fallback and alternative models. Single API key, multiple providers.

## Use Case
- Fallback when Anthropic/Azure rate-limited
- Access to niche models (Mistral, Llama, Gemini)
- Hermes provider config: `provider: openrouter`

## Cost
~$20/mo (usage-based)
