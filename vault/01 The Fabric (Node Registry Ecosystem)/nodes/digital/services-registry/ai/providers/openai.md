# Azure OpenAI

> GPT-5.x, GPT-4.1, o4-mini via Azure endpoint.

## Endpoint
- **Base URL:** https://onemind-openai.openai.azure.com/openai/v1
- **Models:** gpt-5.x, gpt-4.1, o4-mini, gpt-4o

## Important
- gpt-5.x and o4-mini require `max_completion_tokens` (not `max_tokens`)

## Cost
~$30/mo (usage-based)
