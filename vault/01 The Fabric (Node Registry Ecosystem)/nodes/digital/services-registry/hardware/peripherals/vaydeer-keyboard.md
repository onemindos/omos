# Vaydeer Keyboard

> Programmable keyboard/macro pad. Custom keys for shortcuts, automation, and workflow acceleration.

- Quick-launch applications
- Macro sequences (multi-key combos)
- Stream deck alternative
- Layer switching for different workflows
- OBS scene switching
- IDE shortcuts
