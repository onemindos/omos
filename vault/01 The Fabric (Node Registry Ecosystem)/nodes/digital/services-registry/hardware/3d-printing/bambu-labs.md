# Bambu Labs

> High-speed consumer 3D printers. Cloud-connected, multi-color, fast print speeds.

## Printers
| Model | Notes |
|-------|-------|
| X1 Carbon | Flagship — enclosed, multi-material (AMS), fast |
| P1S | Enclosed, fast, good value |
| A1 Mini | Budget, open-frame, beginner-friendly |
| A1 | Mid-range, bed-slinger, AMS Lite |

## Key Features
| Feature | Notes |
|---------|-------|
| Speed | 500mm/s+ |
| AMS | Automatic Material System (4-color) |
| LiDAR | First-layer inspection |
| Cloud | Remote monitoring, print farm management |
| Bambu Studio | Slicer (PrusaSlicer fork) |
| Camera | Built-in timelapse + monitoring |

## Software
- **Bambu Studio** — Slicer + printer management
- **Bambu Handy** — Mobile monitoring app
- **OrcaSlicer** — Open-source alternative slicer (recommended)

## Integration
- MQTT for printer status → NATS bridge
- Camera feed → surveillance/monitoring
- Print farm automation via API
