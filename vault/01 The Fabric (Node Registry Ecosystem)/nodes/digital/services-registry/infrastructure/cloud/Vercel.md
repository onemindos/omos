# Vercel

> **Frontend cloud platform for Next.js and modern web apps**

## Overview

Vercel is the company behind Next.js and a leading frontend cloud platform. Enables zero-config deployment of Next.js apps with edge functions, preview deployments, and a global CDN. Natural home for onemind-web deployments alongside the Docker-based VPS setup.

## Use Cases in OneMind

1. **onemind-web** — Potential cloud deployment target for the Next.js dashboard
2. **Edge Functions** — Serverless API routes at the edge
3. **Preview Deployments** — Auto-deploy PRs for review
4. **Static Sites** — Deploy codex-live or marketing pages

## Key Features

- Next.js-native (built by the Next.js team)
- Zero-config deployment from GitHub
- Edge Network (75+ regions)
- Serverless Functions + Edge Runtime
- Built-in analytics and monitoring
- Free tier for personal projects

## Quick Start

```bash
npm i -g vercel
vercel login
vercel deploy
```
