# GoHighLevel

> All-in-one marketing/CRM platform. Funnels, email, SMS, booking, reputation, white-label SaaS.

## Key Features
| Feature | Notes |
|---------|-------|
| CRM | Contact management, pipelines |
| Funnels | Landing pages, forms, surveys |
| Email/SMS | Campaigns, automation sequences |
| Booking | Calendar scheduling |
| Reputation | Review management |
| Automation | Workflows (triggers → actions) |
| White-label | Resell as your own SaaS |
| Membership | Course/membership sites |
| Phone | Built-in calling, voicemail drops |

$97-497/mo depending on tier

- API for custom integrations
