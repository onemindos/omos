# Skool.com

> Community + course platform. All-in-one for paid communities, gamification, and course delivery.

## Key Features
| Feature | Notes |
|---------|-------|
| Community | Forum-style discussions |
| Courses | Drip content, modules, lessons |
| Gamification | Points, levels, leaderboards |
| Membership | Paid groups (Stripe integration) |
| Calendar | Events, calls, workshops |
| Chat | Group messaging |
| Analytics | Member engagement tracking |

## Pricing
$99/mo per group (unlimited members)

## Use Cases
- Paid community for students/events
- Course delivery
- Mastermind groups
