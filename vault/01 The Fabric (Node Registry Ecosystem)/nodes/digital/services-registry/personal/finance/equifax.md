# Equifax

> **Credit bureau — credit reports and fraud monitoring**

## Overview

Equifax is one of the three major U.S. credit bureaus. Direct access via Equifax.com provides credit report access, score monitoring, and identity protection. Part of the HP/30 Finance credit monitoring stack.

## Use Cases in OneMind

1. **Credit Report** — Full Equifax credit report (free annually via AnnualCreditReport.com)
2. **Score Monitoring** — Equifax credit score tracking
3. **Credit Freeze** — Free security freeze to block new credit
4. **Dispute** — Contest inaccurate items on Equifax report
5. **Identity Monitoring** — Dark web scanning

## Key Features

- Free Equifax credit report (AnnualCreditReport.com)
- myEquifax account for ongoing monitoring
- Free security freeze
- ID theft protection (Lock & Alert)
- Equifax Complete (premium monitoring)

## Note

Equifax had a major data breach in 2017 exposing 147M records. Monitor for any unauthorized activity. A free security freeze is recommended.
