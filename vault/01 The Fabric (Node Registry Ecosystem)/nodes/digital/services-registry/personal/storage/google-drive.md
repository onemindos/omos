# Google Drive

> Cloud storage + collaboration. Docs, Sheets, Slides, file sync.

## Key Features
| Feature | Notes |
|---------|-------|
| Storage | 15GB free, 100GB/$2, 2TB/$10 |
| Collaboration | Real-time editing (Docs, Sheets, Slides) |
| Sync | Desktop app, selective sync |
| Shared drives | Team/org shared spaces |
| API | REST API for automation |
| Offline | Offline access for selected files |
