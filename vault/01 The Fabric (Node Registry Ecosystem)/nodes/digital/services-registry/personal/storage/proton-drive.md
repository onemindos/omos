# Proton Drive

> End-to-end encrypted cloud storage. Zero-access encryption — Proton can't read your files.

## Key Features
| Feature | Notes |
|---------|-------|
| E2E Encryption | Zero-access, zero-knowledge |
| Storage | Included with Proton plan (up to 500GB) |
| Sync | Desktop app (macOS, Windows, Linux) |
| Sharing | Encrypted links, password protection, expiry |
| Photos | Encrypted photo backup (mobile) |
| Swiss | Swiss privacy laws, no US jurisdiction |

## Integration
- Bundled with Proton Mail/VPN/Calendar
- No API (privacy-first — no programmatic access by design)
