# iCloud Drive

> Apple ecosystem cloud storage. Deep OS integration, seamless sync across all Apple devices.

## Key Features
| Feature | Notes |
|---------|-------|
| Storage | 50GB/$1, 200GB/$3, 2TB/$10, 6TB/$30, 12TB/$60 |
| Desktop/Documents | Auto-sync macOS folders |
| Universal Clipboard | Copy on Mac, paste on iPhone |
| Keychain | Password sync (via iCloud) |
| Photos | iCloud Photo Library |
| Handoff | Continue work across devices |
| Finder integration | Native — just a folder |

## Path
```
~/Library/Mobile Documents/com~apple~CloudDocs/
```

## Integration
- macOS native — no extra app needed
- Obsidian vault can live here for multi-device sync
- Shortcuts + Files app on iOS
