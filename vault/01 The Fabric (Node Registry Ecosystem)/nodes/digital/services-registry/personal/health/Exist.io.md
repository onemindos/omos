# Exist.io

> **Habit & Life Correlation Tracker**

## Overview

Exist.io is a personal analytics platform that aggregates data from connected apps (Todoist, Fitbit, RescueTime, GitHub, etc.) and surfaces correlations between habits, mood, productivity, and health. It answers questions like "what makes me more productive?" or "what affects my sleep?"

## Use Cases

1. **Habit Correlation** — Identify which habits improve productivity, mood, or sleep
2. **Life Data Aggregation** — Single view across Todoist, fitness, sleep, screen time
3. **Weekly Patterns** — Surface trends over time without manual tracking
4. **HP Domain Intelligence** — Feed into Holistic Performance scoring

## Key Features

- Connects to 40+ services (Todoist, Oura, Apple Health, GitHub, etc.)
- Automatic correlation discovery
- Daily mood + energy check-in
- Weekly and monthly reports
- REST API for custom integrations

## Integration Notes

- Todoist → Exist: tracks tasks completed per day
- Apple Health / Oura → Exist: sleep, steps, heart rate
- API endpoint: `https://exist.io/api/2/`
