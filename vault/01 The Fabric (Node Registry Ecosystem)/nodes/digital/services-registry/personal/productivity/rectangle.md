# Rectangle

> macOS window manager. Keyboard shortcuts for window snapping, resizing, tiling.

## Key Shortcuts
| Action | Shortcut |
|--------|----------|
| Left half | ⌃⌥ ← |
| Right half | ⌃⌥ → |
| Top half | ⌃⌥ ↑ |
| Bottom half | ⌃⌥ ↓ |
| Maximize | ⌃⌥ Return |
| Center | ⌃⌥ C |
| Thirds | ⌃⌥ D/F/G |

## Notes
- Free and open-source
- Alternative: Magnet (paid), Amethyst (tiling WM)
