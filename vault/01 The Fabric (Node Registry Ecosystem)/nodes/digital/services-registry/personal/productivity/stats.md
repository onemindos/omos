# Stats

> macOS system monitor in the menu bar. CPU, GPU, RAM, disk, network, battery, sensors.

## Features
| Metric | Notes |
|--------|-------|
| CPU | Usage per core, temperature |
| GPU | Usage, temperature |
| RAM | Used, free, pressure |
| Disk | Read/write speed, usage |
| Network | Upload/download speed |
| Battery | Cycle count, health, time remaining |
| Sensors | Fan speed, all temps |

## Notes
- Free and open-source
- Lightweight — minimal resource usage
- Customizable widgets in menu bar
