# iCloud

> **Apple's cloud storage and sync platform for the Apple ecosystem**

## Overview

iCloud is Apple's cloud storage and sync service tightly integrated with macOS and iOS. Provides seamless file sync across Mac and iPhone, app data backup, and iCloud Drive for document storage. Part of Apple One subscription.

## Use Cases in OneMind

1. **Mac → iPhone Sync** — Files, notes, reminders across Apple devices
2. **App Data** — Obsidian local files, Apple Health, Apple Notes backup
3. **Photos Library** — iPhone photos backed up and accessible on Mac
4. **iCloud Drive** — Quick file access folder shared across devices
5. **Keychain** — Non-critical passwords synced (1Password handles sensitive)
