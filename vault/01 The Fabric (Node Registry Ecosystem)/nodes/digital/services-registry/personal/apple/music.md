# Apple Music

> Music streaming — integrated with Apple ecosystem (HomePod, AirPods, Apple Watch, CarPlay).

## Features
| Feature | Notes |
|---------|-------|
| Lossless Audio | ALAC up to 24-bit/192kHz |
| Spatial Audio | Dolby Atmos |
| Library sync | iCloud Music Library |
| Siri integration | Voice control on all devices |
| Lyrics | Synced lyrics |

## Integration Points
- HomePod / HomePod Mini (Siri voice control)
- Home Assistant (media_player entity)
- Shortcuts / automation triggers
