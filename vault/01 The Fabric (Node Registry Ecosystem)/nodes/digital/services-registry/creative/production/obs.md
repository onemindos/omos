# OBS Studio

> Open-source streaming and recording software. Industry standard for live streaming and screen capture.

## Key Features
| Feature | Notes |
|---------|-------|
| Streaming | Twitch, YouTube, custom RTMP |
| Recording | Local recording (MKV, MP4, FLV) |
| Scenes | Switch between layouts |
| Sources | Camera, screen, window, browser, media |
| Filters | Audio/video filters, chroma key |
| Plugins | Extensive plugin ecosystem |
| Virtual camera | Use OBS output as webcam |
| NDI | Network video input/output |

## Use Cases
- Live streaming events/classes
- Screen recording for tutorials
- Multi-camera production
- Virtual camera for meetings
