# Screen Studio

> Beautiful screen recordings for macOS. Auto-zoom, cursor effects, smooth animations. Premium alternative to OBS for polished demos.

## Key Features
| Feature | Notes |
|---------|-------|
| Auto-zoom | Follows cursor intelligently |
| Cursor effects | Click animations, spotlight |
| Background | Custom wallpapers, gradients |
| Export | MP4, GIF, ProRes |
| Editing | Trim, cut, speed adjustments |
| Camera | Picture-in-picture webcam bubble |
| Resolution | Up to 4K |

## Use Cases
- Product demos
- Tutorial videos
- Social media clips
- Bug reports with context
