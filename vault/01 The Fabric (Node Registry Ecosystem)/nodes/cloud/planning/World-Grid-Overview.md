# World Grid — Overview

> *One Mind runs a city of one now. The World Grid is the map of all cities — present and future.*

---

## What Is the World Grid?

The World Grid is the network of physical locations (city nodes) that One Mind manages. Each node is a **sovereign operating location** — a place where Zeus or family members live, work, or operate, and where One Mind infrastructure is deployed.

Each node has:
- A **Profile** (who is there, what it is, what it serves)
- An **Environment** (devices, sensors, smart home, robotics)
- An **Ops Link** (tasks, calendars, dashboards tied to that location)
- A **Legacy AI instance** aware of its local context

## How Legacy AI Uses the Grid

Legacy maintains awareness of all active nodes at all times:
- Monitors environment sensors per node
- Routes tasks and communications to the correct node context
- Adjusts recommendations based on current active location
- Maintains node-specific memory (what happened at Haven vs. Paz-MX)
