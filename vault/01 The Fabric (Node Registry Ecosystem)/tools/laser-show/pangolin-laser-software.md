# Pangolin Laser Show Software

## Overview

Two Pangolin products for controlling laser projectors and DMX lighting rigs.

| Software | Level | Use Case |
|----------|-------|----------|
| **BEYOND** | Professional | Full laser show programming, ILDA output, timeline, advanced DMX |
| **QuickShow (QS)** | Entry-level | Quick cue-based laser control, simpler interface |

## Platform

**Windows only.** No native macOS build exists.

To run on Mac: requires **Parallels Desktop** or **VMware Fusion** (Windows VM).
