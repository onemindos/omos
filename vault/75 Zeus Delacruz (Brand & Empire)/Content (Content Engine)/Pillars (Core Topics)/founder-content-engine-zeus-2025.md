### 🛠️ Founder Content Engine - Zeus Delacruz (Unified System for Personal Brand + Legacy AI)

### 🎯 Objective

To create a scalable, streamlined content production system that:
- Powers both Founder Zeus Delacruz (Personal Brand) and Legacy AI (Company Brand)
- Allows single content pieces to feed multiple channels
- Maximizes reuse of ideas, saving time while expanding your reach
- Prepares future AI Agents or VAs to run content systems independently

### 🧠 Core Concept: Dual Output Content Streams

Every piece of content you produce should be routed into two lanes:
| Lane | Purpose | Example Content Types |
| --- | --- | --- |
| Founder Personal Brand | Build Zeus Delacruz public authority | Speaking clips, podcasts, daily lessons, entrepreneurial reflections |
| Legacy AI Company Brand | Build Legacy HQ brand authority | Company updates, business lessons, industry insights, case studies |

✅ **Single idea → Dual content expression.**

### 🔁 Founder Content Production Flow
| Step | Action | Tool | Output |
| --- | --- | --- | --- |
| 1. Capture Ideas | Quick Capture in ClickUp (or Raindrop Bookmarks) | ClickUp + AI Autopilot | Raw Ideas Task List |
| 2. Classify Purpose | Tag ideas by "Audience" (Founder, Legacy AI, Both) | ClickUp Custom Fields | Sorted Content Bank |
| 3. Create Drafts | AI-assisted draft generation (blog post, social post, video script) | ClickUp Docs + ClickUp AI | Draft-ready content |
| 4. Review & Personalize | Human review or slight personalization | ClickUp Status: "Needs Review" | Final polished drafts |
| 5. Schedule/Assign for Publication | Auto-schedule for Circle.so, Email, Social | ClickUp Automation / Zapier | Publishing Queue |
| 6. Repurpose Content | Clip, resize, rewrite for other channels | AI Autopilot + Templates | Microcontent & Variations |

### 📋 Tags & Metadata System (for Easy Search + Automation)
| Field Name | Values |
| --- | --- |
| Audience | Founder / Legacy AI / Both |
| Content Type | Blog / Email / Video / Social |
| Status | Idea / Draft / Needs Review / Approved / Published |
| Priority | High / Medium / Low |

### 🛠️ Automation Blueprint
| Trigger | Action |
| --- | --- |
| New Idea Captured | Auto-tag as "Idea", assign to "Review Content" list |
| Status changed to "Approved" | Auto-create a scheduled task to post in Circle.so |
| High Priority Tag applied | Notify Zeus (or future content manager) |
| Post Published | Auto-tag as "Repurpose Potential" |
