# Azure Credit Use

Owner: Zeus
Tags: Founder Ops & Venture Execution
Parent page: Technology (Technology%2025e809e2458780e49d9acf0a4e5ff02f.md)

Azure credits can be used for a variety of services and resources offered by Microsoft Azure. These include, but are not limited to:

1. **Virtual Machines**: Hosting servers or applications in the cloud.
2. **App Services**: Building, deploying, and scaling web apps.
3. **Storage Accounts**: Storing files, backups, and databases.
4. **SQL Databases**: Hosting and managing SQL databases.
5. **Machine Learning Services**: Building and deploying machine learning models.
6. **Azure Kubernetes Service (AKS)**: Managing containerized applications.
7. **Content Delivery Network (CDN)**: Distributing content globally.
8. **IoT Services**: Connecting and managing IoT devices.
9. **Azure Functions**: Running event-driven serverless compute functions.
10. **Networking Services**: Setting up virtual networks, VPNs, and more.

These credits are often used to explore, experiment, and prototype solutions without the initial cost barrier, making them particularly useful for startups, developers, and students.
