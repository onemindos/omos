# The 4 Pillars Cheatsheet

> One Mind organizes your entire life into 4 pillars. Everything has a home.

---

## The Architecture

```
┌─────────────────────────────────────────────────────┐
│         SO — Sovereign Operations (00–24)            │
│         The operating layer that runs everything     │
├──────────────────┬──────────────────┬───────────────┤
│   HP (25–49)     │   LE (50–74)     │  GE (75–99)   │
│   PERSONAL       │      HOME        │  BUSINESS     │
└──────────────────┴──────────────────┴───────────────┘
```

SO is the platform. HP, LE, GE are the three life pillars.

## The Routing Rule

When you capture something, ask: *"Which pillar does this belong in?"*

- **AI, tools, infrastructure, automation?** → SO
- **My health, habits, learning, money?** → HP
- **Family, home, relationships?** → LE
- **Business, brand, ventures, wealth?** → GE
- **Not sure yet?** → Inbox (99), route later

If it touches multiple pillars, pick the primary one. You can cross-link.
