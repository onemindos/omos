# Memory Sync Protocol

> **How AI agents stay current with vault updates**

---

## When to Run Sync

**Triggers:**
1. Zeus explicitly says "run memory sync"
2. After major vault updates (new projects, architecture changes)
3. Weekly (Sunday evening, after weekly review)
4. After completing a major milestone
5. When you notice your knowledge seems outdated

---

## Sync Process

### Step 1: Read the Master Document
**Location:** `/ONEMIND-CODEX.md`

**What to check:**
- Has the philosophy changed? (Part 1-2)
- Has the architecture changed? (Part 3)
- Has your agent role changed? (Part 4)
- Has the operating rhythm changed? (Part 5)
- Has the tech stack changed? (Part 6)

**Update your memory blocks** with any changes.

---

### Step 2: Check Command Center
**Location:** `00-24 SO/01 Command/`

**What to check:**
- Current priorities (what Zeus is focused on NOW)
- Active projects (what's in motion)
- Recent decisions (context that affects your work)
- Pending items (what needs your attention)

**Update memory block:** Current Context

---

### Step 3: Check Domain-Specific Updates

**If you're HP Agent:**
- Check `25-49 HP/` for new health goals, routines, metrics
- Update memory block: HP Context

**If you're LE Agent:**
- Check `50-74 LE/` for family changes, home updates, legacy plans
- Update memory block: LE Context

**If you're GE Agent:**
- Check `75-99 GE/` for business metrics, new deals, revenue changes
- Update memory block: GE Context

**If you're SO Agent (Sentinel):**
- Check all domains for coordination needs
- Check `00-24 SO/02 Agents/` for agent config updates

---

### Step 4: Check Your Agent Configuration
**Location:** `00-24 SO/02 Agents/[Your Agent]/`

**What to check:**
- Has your system prompt changed?
- Have new skills been attached?
- Have your tools been updated?
- Have your guardrails changed?

---

### Step 5: Update Memory Blocks

**Core memory blocks (all agents):**
- Zeus Profile (rarely changes)
- Current Context (daily/weekly changes)
- System State (real-time)

**Domain memory blocks:**
- HP Context (for HP Agent)
- LE Context (for LE Agent)
- GE Context (for GE Agent)

**How to update:**
1. Read the relevant files
2. Extract key information
3. Update your memory block with new/changed info
4. Keep it concise (memory blocks have limits)
5. Focus on actionable context

---

## What to Sync

### ✅ DO Sync

**Structural changes:**
- New projects added
- Priorities shifted
- Goals updated
- Metrics changed

**Contextual changes:**
- Zeus's current focus
- Active initiatives
- Recent decisions
- Important events

**Configuration changes:**
- Agent roles updated
- Tools added/removed
- Guardrails modified
- Protocols changed

### ❌ DON'T Sync

**Transient information:**
- Individual task details (use Todoist for that)
- Daily logs (too granular)
- Temporary notes
- Completed projects (unless lessons learned)

**Duplicate information:**
- Don't store what's already in ONEMIND-CODEX.md
- Link to it instead

---

## Memory Block Size Limits

Be mindful of character limits:

| Block | Max Size | Type of Content |
|-------|----------|-----------------|
| Zeus Profile | 8,000 chars | Identity, values, preferences |
| Current Context | 5,000 chars | Today's priorities, active focus |
| System State | 3,000 chars | Agent status, health metrics |
| Domain Context (HP/LE/GE) | 5,000 chars | Domain-specific state |

**Optimization tips:**
- Use bullet points, not paragraphs
- Store links to files, not full content
- Keep it actionable
- Remove outdated info regularly

## Common Sync Scenarios

### Scenario 1: New Project Added
1. Read project file in relevant domain (HP/LE/GE)
2. Update domain context with project goals
3. Note key milestones and deadlines
4. Identify what tasks/workflows this affects

### Scenario 2: Priority Shift
1. Read Command Center for new priorities
2. Update Current Context
3. Deprioritize old items
4. Adjust proactive behaviors accordingly

### Scenario 3: Architecture Change
1. Read updated ONEMIND-CODEX.md section
2. Update understanding of your role
3. Check if your agent config changed
4. Adjust behavior to new structure

### Scenario 4: New Tool Added
1. Read tool documentation
2. Check if it's attached to your agent
3. Learn tool capabilities
4. Integrate into your workflows

## Error Prevention

**Before sync:**
- Confirm you're reading the RIGHT files
- Check file modification dates
- Don't assume anything has changed

**During sync:**
- Read carefully (don't skim)
- Extract only relevant info
- Don't copy/paste entire documents

**After sync:**
- Verify your memory blocks are coherent
- Check you didn't exceed size limits
- Confirm key changes are captured
