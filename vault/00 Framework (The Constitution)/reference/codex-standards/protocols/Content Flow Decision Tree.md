### Level 3: The Three-Question Test (Detailed)

**If Still Uncertain → Apply Three Questions:**

```
┌─────────────────────────────────────┐
│   THREE-QUESTION TEST               │
├─────────────────────────────────────┤
│                                     │
│  Q1: PURPOSE                        │
│  ┌─────────────────────────────┐   │
│  │ What is this content FOR?   │   │
│  │ • To make money?     → GE   │   │
│  │ • To improve self?   → HP   │   │
│  │ • To preserve legacy? → LE  │   │
│  │ • To automate?       → IT   │   │
│  └─────────────────────────────┘   │
│                                     │
│  Q2: BENEFICIARY                    │
│  ┌─────────────────────────────┐   │
│  │ Who does this SERVE?        │   │
│  │ • Business/Customers → GE   │   │
│  │ • Current Self       → HP   │   │
│  │ • Future Self/Family → LE   │   │
│  │ • All (Multiplier)   → IT   │   │
│  └─────────────────────────────┘   │
│                                     │
│  Q3: TIMEFRAME                      │
│  ┌─────────────────────────────┐   │
│  │ What lifecycle stage?       │   │
│  │ • Earning money      → GE   │   │
│  │ • Managing money     → HP   │   │
│  │ • Preserving money   → LE   │   │
│  │ • Amplifying results → IT   │   │
│  └─────────────────────────────┘   │
│                                     │
└─────────────────────────────────────┘
```

## Visual Elements:

1. **Arrows**: Use different styles
   - Solid: Main flow
   - Dotted: Alternative path
   - Thick: Primary decision
   - Thin: Secondary consideration

2. **Icons**: Add to each branch
   - 💼 GE
   - 🎯 HP
   - 🏠 LE
   - ⚙️ IT

3. **Highlighting**: Use for common paths
   - Most used path: Bold outline
   - Special cases: Dashed outline
