## Autonomy Levels

| Level | Name | Trust | What Agents Can Do |
|-------|------|-------|-------------------|
| **L0** | None | None | Human only (legal, health, irreversible) |
| **L1** | Low | Medium | Ask first (HITL required) |
| **L2** | Medium | High | Act then notify |
| **L3** | High | Full | Act without asking |
| **L4** | Full | Complete | Autonomous (not currently used) |
