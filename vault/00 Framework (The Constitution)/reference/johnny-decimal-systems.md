# Johnny.Decimal Pre-Built Systems Analysis

## Competitive Intelligence Report for One Mind Framework

---

## Overview

Johnny.Decimal (JD) is a file organization system inspired by the Dewey Decimal System. It uses a hierarchical numbering scheme to organize digital files, notes, emails, and physical items. The core philosophy: **nothing is more than 3 clicks away**.

### Core Structure

| Level | Format | Limit | Example |
|-------|--------|-------|---------|
| **Area** | 10-19, 20-29, etc. | Max 10 areas | `10-19 Life Admin` |
| **Category** | 11, 12, 13, etc. | Max 10 per area | `13 Money` |
| **ID** | 11.01, 11.02, etc. | Max 99 per category | `13.22 Bank accounts` |

**Key Concept: The JDex** — A master index that tracks every ID in the system, serving as the single source of truth.

## System Mechanics

### The Standard Zeros (00-09)

Reserved for system management at each level:

| ID | Purpose |
|----|---------|
| X0.00 | JDex for that level |
| X0.01 | Inbox (temporary holding) |
| X0.02 | Task & project management |
| X0.03 | Templates |
| X0.04 | Links |
| X0.08 | Someday/maybe |
| X0.09 | Archive |

### Subheaders

Use the ■ symbol to create visual breaks in long category lists:
```
13.10 ■ Earned 🤑
13.11 Payslips...
13.12 Expenses...
13.20 ■ Saved 📈
13.21 Budgets...
```

### Date-Based Subfolder Pattern

For IDs containing many similar items (trips, receipts, projects):
```
ID.XX Name/
├── 2024-01-15 Item one/
├── 2024-03-22 Item two/
└── 2024-07-08 Item three/
```

### Extension Patterns (AC.ID+SUB)

For items that repeat or exceed 99 IDs:
- `11.24+JEM` — Jemima's medical visits
- `72.02+X01` — Data center with code X01

## Competitive Analysis for One Mind

### What JD Does Well
1. **Pre-built systems** — Eliminates decision fatigue for users
2. **Clear constraints** — 10×10×99 creates predictable structure
3. **Universal numbering** — "11.12" means the same thing for everyone
4. **Obsidian/Bear integration** — Notes app support built-in
5. **Community** — Forum + Discord for peer support
6. **Anti-AI positioning** — "Human made, the old-fashioned way"

### Gaps & Opportunities for One Mind

| JD Limitation | One Mind Opportunity |
|---------------|---------------------|
| Static system (no intelligence) | AI-powered capture, processing, organization |
| Rigid numerical limits | Flexible, context-aware structure |
| No life philosophy component | Legacy Codex framework (HP, LE, GE, IT) |
| Manual everything | Automated workflows via AI agents |
| No continuous capture | Letta/n8n integration for seamless flow |
| File-centric | Multi-modal (voice, vision, text) |
| Individual focus | Generational/legacy thinking |

### Testimonial Narrative (Their Story)
> "I tried PARA for 2 years, switched to JD, finally feel in control."

### One Mind Counter-Narrative
> "Your system should grow with you, learn from you, and serve generations — not just organize files."
