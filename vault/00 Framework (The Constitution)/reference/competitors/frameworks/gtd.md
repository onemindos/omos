## What It Does

GTD is a comprehensive task management methodology that helps you externalize all commitments from your mind into a trusted system. By capturing everything and processing it into actionable items, you achieve "mind like water" — a state of mental clarity where you can respond appropriately to any situation.

---

## The Five-Step Framework

```
1. CAPTURE     → Get everything out of your head
2. CLARIFY     → Process what each item means
3. ORGANIZE    → Put items where they belong
4. REFLECT     → Review your system regularly
5. ENGAGE      → Take action with confidence
```

### 1. Capture

Collect everything that has your attention into trusted inboxes:

- Physical inbox for papers
- Digital inbox for emails, notes
- Voice memos, quick capture apps
- **Rule:** Capture 100% — nothing stays only in your head

### 2. Clarify

Process each item with the key question: **"What is it?"**

Decision tree:

- Is it actionable? → No → Trash, Reference, or Someday/Maybe
- Is it actionable? → Yes → What's the next action?
  - Takes <2 minutes? → Do it now
  - Takes >2 minutes? → Delegate or Defer

### 3. Organize

Place items in appropriate buckets:

| Bucket            | Purpose                                            |
| ----------------- | -------------------------------------------------- |
| **Next Actions**  | Single next physical actions, organized by context |
| **Projects**      | Outcomes requiring >1 action                       |
| **Waiting For**   | Delegated items you're tracking                    |
| **Calendar**      | Date/time-specific commitments only                |
| **Someday/Maybe** | Ideas not ready for action                         |
| **Reference**     | Non-actionable information to keep                 |

### 4. Reflect

**Weekly Review** — the critical habit:

1. Get clear (process all inboxes)
2. Get current (review all lists)
3. Get creative (think bigger picture)

Without Weekly Review, the system decays.

### 5. Engage

Choose what to do based on:

1. **Context** — What can you do here/now?
2. **Time available** — How much time do you have?
3. **Energy** — What's your current capacity?
4. **Priority** — What matters most?

## Core Concepts

| Concept                    | Description                                                               |
| -------------------------- | ------------------------------------------------------------------------- |
| **Inbox Zero**             | Process all inputs to empty inbox (not zero emails, but zero unprocessed) |
| **Next Actions**           | Define the very next physical action (verb + object)                      |
| **Contexts**               | Group tasks by location/tool (@home, @computer, @calls, @errands)         |
| **Projects**               | Any desired outcome requiring more than one action                        |
| **Weekly Review**          | Regular reflection to keep system current and trusted                     |
| **Someday/Maybe**          | Holding pen for ideas not ready for action                                |
| **Waiting For**            | Tracking delegated items with date noted                                  |
| **Reference**              | Storage for non-actionable information                                    |
| **2-Minute Rule**          | If an action takes <2 minutes, do it immediately                          |
| **Natural Planning Model** | Purpose → Vision → Brainstorm → Organize → Next Actions                   |

## The Horizons of Focus

GTD includes perspective levels for bigger-picture thinking:

| Horizon       | Focus                             | Timeframe   |
| ------------- | --------------------------------- | ----------- |
| **Ground**    | Current actions                   | Now         |
| **Horizon 1** | Projects                          | 1-12 months |
| **Horizon 2** | Areas of focus and accountability | Ongoing     |
| **Horizon 3** | Goals and objectives              | 1-2 years   |
| **Horizon 4** | Vision                            | 3-5 years   |
| **Horizon 5** | Purpose and principles            | Lifetime    |

## Strengths ✅

- **Battle-tested for 20+ years** — millions of practitioners worldwide
- **Reduces cognitive load** — "mind like water" through externalization
- **Universal applicability** — works for any profession or lifestyle
- **Clear action orientation** — always know your next step
- **Stress reduction** — captured items don't weigh on memory
- **Context-switching efficiency** — batch similar tasks together
- **Tool-agnostic** — paper, apps, or hybrid systems all work
- **Complete framework** — handles everything from emails to life goals
- **Professional credibility** — widely adopted in business settings

---

## Weaknesses ❌

- **No knowledge management** — weak on learning and idea synthesis
- **No AI integration** — designed for humans working alone
- **High maintenance** — Weekly Review requires discipline (1-2 hours)
- **Can become bureaucratic** — rigid adherence adds overhead
- **No metrics or tracking** — success is qualitative, not measured
- **Individual focus** — not designed for teams or family coordination
- **Information storage is flat** — Reference folder becomes a dumping ground
- **Dated contexts** — @phone, @office less relevant in mobile/remote era
- **Overwhelming at first** — many concepts to internalize

---

## Best For

- Professionals with heavy task loads
- People feeling overwhelmed by commitments
- Those seeking stress reduction and mental clarity
- Knowledge workers with many projects
- Anyone who drops balls or forgets commitments
- People who think well in structured systems

## Relationship to OneMind

**GTD principles are embedded in OneMind:**

- Capture → OneMind's Inbox (06)
- Clarify/Organize → Processing workflows
- Reflect → Operating rhythm (daily, weekly, quarterly reviews)
- Engage → Agent-assisted execution

**Key difference:** GTD is human-only task management. OneMind adds AI agents, knowledge management, automation, and life-scope integration.

**Hybrid approach:** Use GTD methodology within OneMind's task layer (Todoist integration).
