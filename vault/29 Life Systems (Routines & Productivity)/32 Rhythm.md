# 32 Rhythm (Routines & Productivity)

> *This is where Zeus runs Zeus — the daily operating rhythm of a high performer.*

## The Loop

```
PLAN → INTEND → EXECUTE → RECOVER → REVIEW → COMPOUND
```

| Stage | Folder | What Happens |
|-------|--------|-------------|
| **PLAN** | `Time-Calendar` · `Quarterly-Annual` | Design your time, set long-horizon targets |
| **INTEND** | `Goals-Intentions` · `Pre-Performance` | Set daily intentions, prime for high-stakes moments |
| **EXECUTE** | `Routines-Habits` · `Productivity` · `Energy-Management` | Show up, do the work, manage your state |
| **RECOVER** | `Recovery` | Rest strategically — deloads, recharge rituals, burnout prevention |
| **REVIEW** | `Reviews-Reflection` | Close loops — daily, weekly, monthly, quarterly |
| **COMPOUND** | `Performance-Metrics` | Track yourself, spot trends, raise the baseline |
