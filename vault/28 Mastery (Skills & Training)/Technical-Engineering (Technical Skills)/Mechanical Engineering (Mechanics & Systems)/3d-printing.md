# 3D Printing

Everything needed to go from idea to physical object. File format, material selection, model libraries, and printer guide.

---

## File Format — STL

**STL (Standard Tessellation Language)** is the primary file format for 3D printing. Almost every printer, slicer, and model repository uses it.

| Format | What | When |
| ------ | ---- | ---- |
| **STL** | Mesh geometry only — no color, no material, no scale | **Default — use this** |
| **3MF** | Next-gen — includes color, material, scale, orientation | Better for multi-material/color |
| **OBJ** | Common in 3D modeling, works but less optimal | Import from design software |
| **GCODE** | Sliced output — machine instructions for a specific printer | Generated by slicer, not for sharing |

**Workflow:** Download STL → open in slicer → slicer generates GCODE → send GCODE to printer.

## Model Repositories

Where to find STL files. All free unless noted.

### Printables.com ⭐ Best Overall
- **URL:** `printables.com`
- **Owner:** Prusa (printer manufacturer — curated quality)
- **Best for:** High-quality, well-tested prints. Prusa community vets models.
- **Features:** Remixes, comments, print reviews, collections
- **Reward system:** Earn Prusameters for downloading/uploading
- **Quality signal:** Check print count + photos from community prints — higher print count = more validated

### MakerWorld ⭐ Best for Bambu Users
- **URL:** `makerworld.com/en`
- **Owner:** Bambu Lab (printer manufacturer)
- **Best for:** Bambu printer optimized profiles — models come with pre-tuned print settings
- **Features:** One-click print (sends directly to Bambu printer), maker rewards program
- **Quality signal:** "Certified" badge + download count + community prints
- **Note:** Best if using a Bambu printer. Still useful for anyone — good model library.

### Thingiverse — The Original
- **URL:** `thingiverse.com`
- **Owner:** MakerBot / UltiMaker
- **Best for:** Largest archive — has virtually everything, especially older/classic designs
- **Caveats:** Quality is inconsistent, site can be slow, some old models have errors
- **When to use:** When Printables and MakerWorld don't have what you need. Search Thingiverse as the fallback.

### Others Worth Knowing
| Site | Best For | Notes |
| ---- | -------- | ----- |
| `cults3d.com` | Designer originals, paid models | Good quality, some free |
| `myminifactory.com` | Miniatures, tabletop, collectibles | Licensed designs from IP holders |
| `thangs.com` | Geometric search (find similar shapes) | AI-powered model search |
| `grabcad.com` | Engineering/mechanical CAD files | STEP + IGES files for functional parts |

## Materials — The Most Important Decision

Material determines the final properties of the print: strength, flexibility, heat resistance, appearance, and printability difficulty.

### FDM (Filament) Materials

| Material | Difficulty | Strength | Flexibility | Heat Resistance | Best For |
| -------- | ---------- | -------- | ----------- | --------------- | -------- |
| **PLA** | ⭐ Easiest | Medium | Rigid/brittle | Low (60°C) | Prototypes, decorative, low-stress parts |
| **PETG** | ⭐⭐ Easy | Medium-High | Slight flex | Medium (80°C) | Functional parts, food-safe containers |
| **ABS** | ⭐⭐⭐ Medium | High | Rigid | High (100°C) | Engineering parts, auto parts, heat exposure |
| **ASA** | ⭐⭐⭐ Medium | High | Rigid | High (100°C) | Outdoor use (UV resistant — better than ABS outside) |
| **TPU** | ⭐⭐⭐ Medium | Medium | Flexible/rubber | Medium | Gaskets, phone cases, grips, wearables |
| **Nylon (PA)** | ⭐⭐⭐⭐ Hard | Very High | Slight flex | High | Mechanical parts, gears, load-bearing |
| **PLA+** | ⭐ Easy | Medium-High | Less brittle | Low-Medium | Better PLA — same ease, improved toughness |
| **Wood/Metal Fill** | ⭐⭐ Easy | Medium | Rigid | Low | Aesthetic/decorative — looks like wood/metal |
| **Carbon Fiber Fill** | ⭐⭐⭐ Medium | Very High | Rigid | Medium-High | Lightweight structural parts — abrasive to nozzle |

### Material Selection Decision Tree

```
Is it decorative or a prototype?
  → PLA or PLA+

Will it be outdoors or in sunlight?
  → ASA (not ABS — ABS yellows and degrades in UV)

Does it need to be flexible / rubbery?
  → TPU

Will it carry load or be mechanical (gears, brackets, clips)?
  → PETG (moderate) or Nylon (heavy duty)

Will it be near heat (engine bay, hot environment)?
  → ABS or ASA

Do you need food-safe?
  → PETG (food-safe filaments available — check brand)

Do you need lightweight + strong?
  → Carbon Fiber PLA or Carbon Fiber PETG
```

### Resin (SLA/MSLA) Materials
For detail-critical prints (miniatures, jewelry, dental, cosplay props):

| Resin Type | Best For | Notes |
| ---------- | -------- | ----- |
| **Standard resin** | Miniatures, prototypes, decorative | Brittle, not functional parts |
| **ABS-like resin** | Functional small parts | Less brittle than standard |
| **Flexible resin** | Gaskets, soft-touch parts | Shore hardness varies |
| **Water-washable** | Convenience | Wash with water instead of IPA |
| **Tough resin** | Engineering, load-bearing | Significantly less brittle |

## Slicer Software

Converts STL → GCODE. Required step before printing.

| Slicer | Best For | Cost |
| ------ | -------- | ---- |
| **Bambu Studio** | Bambu printers — best integration | Free |
| **PrusaSlicer** | Prusa printers, general use — best open source | Free |
| **Orca Slicer** | Fork of Bambu Studio — works with all printers | Free |
| **Cura** | Creality, generic printers — most popular | Free |
| **Simplify3D** | Advanced tuning | $199 |

**For One Mind:** Orca Slicer or PrusaSlicer — both open source, support all printers, active development.

## Printer Types

| Type | Technology | Best For | Price Range |
| ---- | ---------- | -------- | ----------- |
| **FDM (Filament)** | Melts plastic filament layer by layer | Functional parts, large prints, everyday use | $200–$2K |
| **MSLA/Resin** | UV light cures liquid resin | High detail — miniatures, jewelry, props | $150–$800 |
| **SLS (Powder)** | Laser sinters nylon powder | Professional, no supports needed | $5K+ |

| Printer | Price | Speed | Quality | Notes |
| ------- | ----- | ----- | ------- | ----- |
| **Bambu Lab A1 Mini** | ~$300 | Fast | ⭐⭐⭐⭐ | Best beginner/intermediate — multi-color capable |
| **Bambu Lab P1S** | ~$600 | Very fast | ⭐⭐⭐⭐⭐ | Enclosed — needed for ABS/ASA/Nylon |
| **Prusa MK4S** | ~$800 | Medium | ⭐⭐⭐⭐⭐ | Best open-source, most reliable long-term |

## Print Settings Fundamentals

| Setting | What It Controls | Notes |
| ------- | ---------------- | ----- |
| **Layer height** | Resolution / print speed | 0.2mm = standard; 0.1mm = fine detail; 0.3mm = fast |
| **Infill %** | Internal density / strength | 15% = decorative; 40% = functional; 80%+ = maximum strength |
| **Infill pattern** | Internal structure shape | Gyroid = best all-around; Grid = fast; Honeycomb = strong |
| **Print speed** | mm/s | Faster = rougher; PLA can push 200mm/s on modern printers |
| **Supports** | Scaffolding for overhangs | Enable for overhangs >45°; tree supports minimize waste |
| **Bed adhesion** | First layer sticks | Brim for thin/tall prints; Raft for tricky surfaces |
| **Wall count** | Shell thickness | 3 walls = standard; 4–5 walls = strong functional parts |
| **Top/bottom layers** | Surface closure | 4–5 layers standard |
