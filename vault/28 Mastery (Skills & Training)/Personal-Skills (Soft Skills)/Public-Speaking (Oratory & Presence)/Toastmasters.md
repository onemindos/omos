# Toastmasters

> Public speaking and leadership development organization. Weekly club meetings with structured speech projects, evaluations, and rotating roles.

---

## Overview

| Field | Detail |
|-------|--------|
| **URL** | https://www.toastmasters.org |
| **Find a Club** | https://www.toastmasters.org/find-a-club |
| **Focus** | Public speaking, communication, leadership |
| **Format** | Weekly club meetings (~1hr), speech projects, table topics, evaluations |
| **Cost** | ~$45-60 semi-annual dues + one-time joining fee |
| **Program** | Pathways (online learning with speech project tracks) |

## Meeting Roles

| Role | What You Do |
|------|------------|
| Toastmaster | Runs the meeting |
| Prepared Speaker | Delivers a speech project |
| Table Topics Master | Leads impromptu speaking segment |
| Evaluator | Gives structured feedback on a speech |
| Timer / Grammarian | Tracks time, notes language use |
