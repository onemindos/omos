# Universal Communications Protocol

## Overview

Every message in OneMind OS — whether typed as text, spoken as voice, captured from a camera, read from a sensor, or generated by an agent — flows through a single canonical format: **NexusMessage**.

This eliminates the contradictions that previously existed between `ChatRequest`, `CommandRequest`, raw NATS dicts, and robot command payloads.

## Architecture

```
┌─────────────────────────────────────────────────────────┐
│                    HUMAN INPUTS                         │
│  Text Chat │ Voice │ Camera │ Files │ Sensor Dashboard  │
└─────────┬───────┬────────┬──────┬────────┬──────────────┘
          │       │        │      │        │
          ▼       ▼        ▼      ▼        ▼
    ┌─────────────────────────────────────────────┐
    │           NexusMessage Envelope             │
    │  content + modality + attachments + routing  │
    └───────────────────┬─────────────────────────┘
                        │
              ┌─────────▼─────────┐
              │   NATS Bus        │
              │   comms.{mod}.    │
              │   {src_type}.     │
              │   {src_id}        │
              └─────────┬─────────┘
                        │
          ┌─────────────┼─────────────┐
          │             │             │
    ┌─────▼────┐  ┌─────▼────┐  ┌────▼─────┐
    │  Legacy  │  │ Socket.IO│  │  Agents  │
    │  Sees    │  │ Bridge   │  │  Aware   │
    │  ALL     │  │ Forwards │  │  Listen  │
    └──────────┘  └──────────┘  └──────────┘
```

## NexusMessage Format

```python
NexusMessage(
    id="uuid",
    content="What's in this image?",     # Text is always present
    modality="vision",                     # text|voice|vision|audio|sensor|command|multimodal
    source_id="human:zeus",               # Who sent it
    source_type="human",                  # human|agent|team|robot|sensor|system
    attachments=[                          # Binary/structured data
        Attachment(type="image", url="http://...", mime_type="image/jpeg"),
        Attachment(type="audio", data_base64="...", mime_type="audio/wav"),
    ],
    data={},                              # Structured payload (sensor readings, etc.)
    routing=Routing(                       # Where to send it
        target_ids=["researcher"],
        mode="direct",                     # auto|direct|broadcast
    ),
    session_id="conv-123",                # Conversation tracking
    correlation_id="msg-456",             # Links related messages
    priority="normal",                    # critical|high|normal|low|background
    timestamp="2025-01-15T...",
)
```

## NATS Subject Convention

```
comms.{modality}.{source_type}.{source_id}

Examples:
  comms.text.human.zeus           # Human text chat
  comms.voice.human.zeus          # Voice command (transcribed)
  comms.vision.sensor.garage-cam  # Camera snapshot
  comms.sensor.robot.arm-01       # Robot telemetry
  comms.text.agent.researcher     # Agent response
  comms.chat.direct.assistant     # Chat system bridge
  comms.chat.response.researcher  # Chat response bridge
```

## Modality-Aware Entities

Every entity now declares what it can handle:

```python
EntityDescriptor(
    id="researcher",
    input_modalities=["text", "image"],    # Can receive text + images
    output_modalities=["text"],             # Responds with text
    capabilities=["chat", "reasoning", "tool_use", "vision"],
)
```

Detection is automatic:
- **Voice**: Agents using Gemini models with `response_modalities=["AUDIO"]` get `audio` in both input/output
- **Vision**: Agents on GPT-4o/Gemini/Claude-3 models get `image` in input
- **Camera**: Agents with vision tools (HA LLM Vision, Frigate) get `camera_control` capability
- **Robots**: OpenMind entities get `sensor`, `command`, `video` modalities
- **Teams**: Inherit the best modalities from their members

## How Everything Connects

### Chat → Nexus Bridge
`UniversalChat` now publishes every interaction to NATS:
```
User types message → UniversalChat._publish_to_nexus() → NATS comms.chat.{mode}.{target}
Agent responds → UniversalChat._publish_response() → NATS comms.chat.response.{target}
```
Legacy sees ALL chat activity. Previously this was invisible.

### Nexus Command Endpoint
`POST /nexus/command` now accepts multimodal payloads:
```json
{
    "message": "What is this?",
    "modality": "vision",
    "images": [{"url": "http://camera/snapshot.jpg"}],
    "mode": "auto"
}
```
The endpoint:
1. Builds a `NexusMessage` from the request
2. Publishes to NATS for Legacy to observe
3. Legacy's brain sees modality info + entity input_modalities
4. Routes to entities that support the required modality
5. Dispatcher passes images/audio to agents via Agno's native APIs

### NATS → Socket.IO Bridge
Now forwards ALL event types:
```
system.>   → /system namespace
digital.>  → /events namespace
physical.> → /events namespace
human.>    → /approvals + /events
nexus.>    → /events namespace (NEW)
comms.>    → /chat namespace (NEW)
```

### Agent Awareness
Agents subscribe to modality-specific comms topics:
```
assistant → comms.text.human.>, comms.voice.human.>
analyst   → comms.sensor.>
```
Handlers extract multimodal data from NexusMessage payloads and pass images to Agno agents.

## JetStream Streams

| Stream | Subjects | Purpose |
|--------|----------|---------|
| DIGITAL | digital.> | Agent activity |
| PHYSICAL | physical.> | Robot/sensor events |
| HUMAN | human.> | Human-in-the-loop |
| SYSTEM | system.> | Health/heartbeats |
| EVENTS | events.> | Event gateway |
| NEXUS | nexus.> | Orchestration events |
| **COMMS** | **comms.>** | **Universal multimodal messages (NEW)** |

## NATS Switches

All comms modalities are individually toggleable:
```python
"comms.text": True,
"comms.voice": True,
"comms.vision": True,
"comms.audio": True,
"comms.sensor": True,
"comms.command": True,
"comms.chat": True,
```

## Frontend Support

### Entity Cards
Show modality badges (voice/vision/sensor icons) alongside capability chips.

### Command Bar
- Mode selector: AUTO / DIRECT / BROADCAST
- Text input field
- Voice input button (microphone icon)
- Image input button (camera icon)

### NexusService API
```dart
final result = await nexus.command(
  message: "Analyze this",
  modality: "vision",
  images: [{"url": "http://..."}],
  mode: "auto",
);

final modalities = await nexus.getModalities();
// Returns: { input_modalities: {text: {count: 8, entities: [...]}, image: {count: 5, ...}} }
```
