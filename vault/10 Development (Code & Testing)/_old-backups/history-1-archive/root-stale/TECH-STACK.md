#### Tool Access Method

Legacy AI runs in Letta Cloud, which uses **Python tools** (not MCP). Here's how she accesses each system:

| System | Access Method | Tool | Notes |
|--------|---------------|------|-------|
| Todoist | Python API | `todoist()` | Labels (@Legacy) for filtering |
| Zoho CRM | Python API | `zoho_crm()` | Leads, contacts, deals, accounts |
| Zoho Desk | Python API | `zoho_desk()` | Support tickets for onemindcodex.com |
| Zoho Calendar | Python API | `zoho_calendar()` | Shared calendar with Zeus |
| Home Assistant | REST API | Existing | Smart home control |
| GitHub | Collaborator | `github()` | Vault read/write |
| Telegram | Bot API | `comms()` | Notifications to Zeus |
| Circle.so | Python API | `circle()` | Community management (requires Business plan) |

**Why Python Tools vs MCP:**
- MCP (Model Context Protocol) is designed for LLM context injection (Claude Desktop, etc.)
- Letta uses Python functions as its tool interface
- Same functionality, different protocol

**Why Legacy Isn't Added as User in Todoist/Zoho:**
- She operates via API, not UI - no benefit from user account
- Labels/filters work for task assignment
- Adding users = extra cost ($6/user Todoist Business, $45/user Zoho)
- command@legacyhq.ai serves as her notification aggregator

**GitHub (Add as Collaborator):**
- Legacy should be added to repos she works on
- Notifications go to command@legacyhq.ai
- Can be assigned issues, review PRs
- Cost: $0 (GitHub Free supports unlimited collaborators)

## Decision Framework

### Guiding Principles

1. **Own Your Data** - Local-first, exportable formats
2. **API Access** - Everything automatable
3. **Exit Strategy** - Can migrate away from any service
4. **Consolidate** - Suites when cheaper (Zoho, Proton)
5. **Best-in-Class** - Pay for quality where it matters

### Tool Selection Rationale

| Choice | Alternatives Considered | Why Chosen |
|--------|------------------------|------------|
| Zoho One | Google Workspace, Microsoft 365 | Cost-effective, good CRM |
| Mercury | Chase, traditional banks | Modern UI, API, no fees |
| Proton | Gmail, iCloud Mail | Privacy, encryption |
| 1Password | LastPass, Bitwarden | Best UX, developer features |
| Monarch | YNAB, Copilot | Modern UI, Mint replacement |
| Obsidian | Notion, Roam | Local-first, markdown |
| Claude + GPT | One or the other | Different strengths |
| Letta | LangChain, raw APIs | Stateful memory |
| Home Assistant | SmartThings | Open source, local |
