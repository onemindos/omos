## Why One Mind?

Traditional productivity systems like **PARA** and **GTD** were designed for humans working alone. They lack:

- **AI Integration** — No native support for AI agents as collaborators
- **Memory Persistence** — Context resets with every session
- **Automation** — Manual processes that don't scale
- **Life Scope** — Business OR personal, rarely both unified
- **Generational Thinking** — Optimized for tasks, not legacy building

**One Mind solves this** by creating a Hive Mind architecture where:

- Humans and AI agents share persistent memory
- Three life paths operate in balance, not competition
- Automation handles the repeatable, humans handle the meaningful
- Every decision compounds toward multi-generational impact

## Getting Started

### Prerequisites

- Obsidian (desktop app)
- Todoist account
- Letta Cloud or self-hosted instance
- N8N instance (optional, for automation)

### Quick Start

```bash
# Clone the repository
git clone https://github.com/Zeus-Delacruz/OneMind-Codex.git
cd OneMind-Codex

# Open in Obsidian
# File → Open Vault → Select the cloned folder

# For infrastructure deployment

# Review server configs and deployment scripts
```

### Agent Setup

```bash

export LETTA_API_KEY=your-api-key
```
