## 10. The Hidden Pattern

**Every life framework addresses three fundamental dimensions:**

```
1. BEING (Who you are)        → Identity, Values, Spirit, Self      → HP
2. DOING (What you create)    → Actions, Projects, Work, Achievement → GE
3. RELATING (Who you're with) → Family, Community, Relationships     → LE
```

**One Mind adds a fourth:**
```
4. COORDINATING (How it connects) → Systems, AI, Automation         → UI
```

This is why One Mind uses **Three Paths + One Brain** — it covers the universal human dimensions plus the AI coordination layer that makes it an operating system.

## 12. Design Decisions

**What was kept vs. removed during framework evolution.**

| Keep | Why |
|------|-----|
| **L0-L4 Autonomy Levels** | Essential for AI governance — key differentiator |
| **Lead/Lag Metrics** | Simple, powerful concept for measuring progress |
| **HIVE Capture Workflow** | Memorable, actionable daily protocol |
| **A→Q→W→D Cadence** | Solid operating rhythm (Annual→Quarterly→Weekly→Daily) |

| Removed | Why |
|---------|-----|
| X0-X8 Universal Functions | Too rigid — not every pillar needs identical structure |
| PRT-MIS-RTN-RUN Work Types | Cognitive overhead — simplified to Project/Task |
| IT as 4th Pillar | Merged into UI — technology serves the brain layer |
