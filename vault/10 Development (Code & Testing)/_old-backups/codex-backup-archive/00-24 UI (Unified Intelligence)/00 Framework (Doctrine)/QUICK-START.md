## 2. Understand Your Three Paths + UI (10 min)

### UI (00-24): Unified Intelligence
**The Brain** - AI coordination + tech infrastructure

**Self Path** - Personal optimization → **PI Score**

### LE (50-74): Legacy Evolution
**Legacy Path** - Family & heritage → **LI Score**
- "Does this protect US?"
