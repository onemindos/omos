# Email Filter Category Mapping

**Created:** 2026-01-14
**Purpose:** Map email categories to OneMind Codex vault structure for automatic tagging
**System:** Zoho Mail filters with keyword-based category detection

---

## Overview

This document defines the **comprehensive filter system** that routes emails to pillar folders AND applies category tags matching the OneMind Codex vault structure.

**How it works:**
1. **Pillar routing** - Email goes to HP/LE/UI/GE folder based on alias
2. **Category tagging** - Keywords in subject/sender trigger category tags (e.g., `#30-finance`, `#27-body`)
3. **Search power** - Find all emails by category across all pillars
