## Area Index Structure

Each area follows this standard structure:

```
[##] [Area Name]/
├── [##.1] Index/
│   ├── _Index.md          ← Landing page (this is what you link to)
│   └── [topic files]
├── [##.2] References/
├── [##.3] Projects/
└── [##.4+] [Domain-specific]/
```

### Landing Page Template

Every `_Index.md` should contain:
1. Area overview
2. Todoist query block for that area
3. Quick links to sub-sections
4. Related areas
5. Agent context block
