# New Docs - Staging Area

This folder serves as a temporary staging area for documentation created during Todoist organization sessions.

## Purpose
- Quick capture of insights, processes, and documentation
- Temporary holding area before distribution to proper locations in the vault
- Prevents interruption of workflow while maintaining documentation quality

## Workflow
1. **Create** - Documents are created here during task organization
2. **Review** - Periodically review accumulated docs
3. **Distribute** - Move to appropriate pillar/project folders
4. **Clean** - Keep this folder lean and current

## Categories
Documents will be tagged/named by topic area:
- `task-*` - Task management and workflows
- `process-*` - Business processes and SOPs
- `system-*` - System configurations and setups
- `reference-*` - Reference materials and guides
