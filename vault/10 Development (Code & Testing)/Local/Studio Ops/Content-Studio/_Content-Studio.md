# Content-Studio — Content Creation

> *"Create once. Distribute everywhere."*

---

## Purpose

Content-Studio is the **content creation center**. This area houses media production, content creation tools, and the craft of making things that communicate.

---

## What Lives Here

- **Content Projects** — Active creation work
- **Asset Library** — Media files, graphics, templates
- **Production Workflows** — Creation processes, pipelines
- **Publishing** — Distribution, scheduling, channels
- **Brand Assets** — Logos, colors, guidelines

---

## Content Types

| Type | Tools |
|------|-------|
| Written | Obsidian, writing apps |
| Visual | Figma, Canva, Photoshop |
| Audio | Podcast tools, audio editors |
| Video | Video editors, screen recording |
| Interactive | Web tools, app builders |

---

## Creation Pipeline

1. **Ideation** — What to create?
2. **Planning** — Outline, structure
3. **Production** — Make the thing
4. **Editing** — Refine, polish
5. **Publishing** — Release to world
6. **Promotion** — Get it seen
