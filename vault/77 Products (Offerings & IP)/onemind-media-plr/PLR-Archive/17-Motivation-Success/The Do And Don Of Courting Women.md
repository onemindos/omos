| **The Do\'s And Don'ts Of Courting Women**                           |
+======================================================================+
|                                                                      |
+----------------------------------------------------------------------+
| **To get the first date**                                            |
|                                                                      |
| Smile and make eye contact. If she returns your smile, walk over and |
| introduce yourself. Avoid using cliché pickup lines such as "Don't I |
| know you from somewhere?" and "What's a girl like you doing in a     |
| place like this?". They are instant recipe for disaster, especially  |
| if u keep reusing it for every girl you meet. Being nervous is fine  |
| but work up your courage along the way. Drive the conversation. If   |
| you manage to get her number, don't wait for a week before calling   |
| her. There is nothing worse than waiting for a phone call. Call her  |
| and ask her for a date. Some girls prefer coffee dates to dinner,    |
| where all is serious. So, be casual and warm and you'll have a       |
| easier time.                                                         |
|                                                                      |
| **During the first date**                                            |
|                                                                      |
| Be a gentleman. Even now, women often still believe in old-fashioned |
| romance. This does not mean you have to hold her chair and open      |
| doors for her (an added bonus though) but just be polite, courteous  |
| and well-mannered. Don't go farting or belching around her.          |
|                                                                      |
| So, where do you go? Be it a coffee date or dinner, find a place     |
| that is decent and is convenient for both you or at least her. For   |
| meals, it is a good idea to find out if she is a vegetarian, so that |
| both of you have food options. If she is, it is best to ask her      |
| favourite restaurant and have your meal there. Just make sure        |
| beforehand the place is suitable for some quiet talking. There is    |
| nothing worse than having to shout to each other over loud music and |
| other diners. Watching a movie may seemed fun but is not recommended |
| as it does not allow you enough time for communication.              |
|                                                                      |
| Remember to dress appropriately according to the date location.      |
| Wearing a dress pants and shirt for a coffee date will be an         |
| overkill. Remember your first date is not an interrogation. Allow    |
| the conversation to flow by asking questions and making comments     |
| about the topic at hand. Refrain from talking too much about         |
| yourself. Pay attention to little details about her, and you will be |
| surprise at how much information you can learn about her this way.   |
| Sometimes, it is simply a matter of timing and patience.             |
|                                                                      |
| **Second date and beyond**                                           |
|                                                                      |
| Remember to call the following evening after the first date. You do  |
| not want her waiting too long for the phone to ring nor do you want  |
| to look too desperate. Tips have a meaningful relationship:          |
|                                                                      |
| 1.  Let yourself be vulnerable                                       |
|                                                                      |
| Honest, deep conversations where you let her see your weakness and   |
| insecurities are often what relationship, or potential relationship  |
| survive on. Get to know her and let her know you.                    |
|                                                                      |
| 2.  Be honest                                                        |
|                                                                      |
| > Be the person you were before you met her. Things may change but   |
| > if you feel, you are becoming a totally different person, take a   |
| > step back and re-evaluate. You have to learn how to express what   |
| > is and is not acceptable to you. Do not let issues build up and    |
| > then deal with them explosively.                                   |
|                                                                      |
| 3\. Be committed                                                     |
|                                                                      |
| It is a no-brainer that cheating destroys trust in a relationship.   |
| If you like the girl, let her know and tell her that you are in this |
| for real.                                                            |
