# Instructions_1

INSTALLATION INSTRUCTIONS
Download and unzip each file to a new folder.
Upload the site to your server, preserving the directory structure.
Set the file permissions specified below:
FILE PERMISSIONS  
You may need to set a number of file and folder permissions in order to be able to manage the site through the Control Panel. These are the minimum permissions required: 
 646 - Sitemap.XML (Write to the file) 
646 - RssFeed.XML (Write to the file) 757 – Articles and Content folder (Create new files)  646 – All files in the Content folder (Write to the file)  646 – All files in the Includes folder (Write to the file) 

All other files and folders may be left with the default permissions. 

On some unusual server configurations, you may need to set the file permissions differently then described above. Please contact your web host for assistance if those permissions do not work.
Once the Site uploaded, navigate to the Admin directory, i.e:
 HYPERLINK "http://www.mydomain.com/Admin" http://www.mydomain.com/Admin 
You will login using “admin” as the User Name and “password” as the Password.
Once you’ve logged in, simply navigate through each menu item, enter the information required by the various forms and click the save button each time. 

REBUILDING YOUR SITE
Once you’ve configured everything to suit your preferences, it’s time to rebuild your site. To do this, first click the Re-Build Site button. 
When the page reloads, you’re going to click the Re-Build Website button, which will have the effect of integrating all of your information with the site as well as generate the RSS Feed. 

GENERATING THE XML SITEMAP
The final step is to generate the XML Sitemap to submit to Google Sitemaps. Click the XML Sitemap button and then the Generate XML Sitemap button. This will create the XML Sitemap validated to Google’s requirements.
