1. Download and unzip the zip file to a new folder.

2. Upload the site to your server, preserving the directory structure.

3. Once the Site uploaded, navigate to the Admin directory, i.e: http://www.mydomain.com/Admin 

4. If the Admin display indicates an error, follow the instructions to correct it. This error simply means that you need to modify the file permissions for the Configure.php and Sitemap.xml files from 644 to 666 so that the Control Panel can write to them.

5. You will login using “admin” as the User Name and “password” as the Password (Don't forget to change this after logging in).

6. Once you’ve logged in, simply navigate through each menu item, enter the information required by the various forms and click the save button each time. 

7. After you’ve generated your XML Sitemap, you will need to submit it to Google for indexing.
