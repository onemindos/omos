In version 3.2, we've added a new feature to display relevant thumbnail images
adjacent to the large rectangle ad unit in the articles. By ticking the Thumbnail
Images checkbox on the Adsense Settings page, this feature is automatically
deployed.

The images are taken from Google, resized and cached on the server. They are
automatically updated (the cache is replenished) every 5 days.

because of this, there is a new folder named Cache - you'll need to set the file permissions for this folder to 757 in order for the script to work properly.
