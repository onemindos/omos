# We have made some changes to the sites.

When you unzip the zip file for the site you will notice 2 (SiteName-Domain and SiteName-Directory). Use the files in SiteName-Domain if you are uploading the site to it's own domain or sub-domain. Use the SiteName-Directory if you are uploading to a directory. Though this is not a perfect fix it is a way for those of you using a directory system to be able to make use of the sites.

You will also notice that we have added an Iframe in the right sidebar. The file used for this is Frame.html and must be edited prior to uploading the site. We recommend using it for your e-course opt-in form. How you use it is up to you and there are many other options as well. Just make sure whatever you put in here will fit in a 300x156 frame.

Lastly we have added an "add to favorites" script. This script does not work with FireFox and instead just gives them a reminder to bookmark the page.
