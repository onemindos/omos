| **[What women really want: Deciphering non-verbal signs]{.ul}**      |
+----------------------------------------------------------------------+
| Most men hate it when women rejects them. Egos are destroyed when    |
| request for dates are turned down. You may think she was interested  |
| but somehow her signals got lost in translation. How to avoid such   |
| situations? Well, here are a few signs that she probably wants you   |
| to ask her out:                                                      |
|                                                                      |
| ### She\'s Everywhere {#shes-everywhere}                             |
|                                                                      |
| Suddenly, she turns up everywhere you go; you pass her in the        |
| hallway at work or she "accidentally" bumps into you etc. What she's |
| trying to do is to let you notice her and gives you a chance to make |
| the first move. The problem with this move is that most guys are     |
| oblivious to it and thus throws away a lot of chances to hook up.    |
|                                                                      |
| ### She Has All The Right Moves {#she-has-all-the-right-moves}       |
|                                                                      |
| Body language will not lie. Nature has programmed humans with a      |
| complex set of non-verbal flirting signals that is subconsciously    |
| expressed when they are interested in someone. You can be almost     |
| sure that she flirting when:\                                        |
| • She points in your direction with her leg, foot or shoulders.\     |
| • She leans toward you while talking.\                               |
| • She plays with or tosses her hair.\                                |
| • She fidgets with a piece of jewelry (like an earring) or strokes   |
| the stem of her glass.\                                              |
| • She keeps her eyes locked on you while she talks or drinks.\       |
| • She mirrors your body movements (e.g if you put your hand on the   |
| table, she quickly does the same).\                                  |
| • She smiles when you check her out.\                                |
| \                                                                    |
| **3. She\'s always has time for you**                                |
|                                                                      |
| Rule of the thumb in the dating game: A woman will make herself      |
| available if she is interested in you. She will quickly answer your  |
| calls and willingly accepts your invitation to get together. If she  |
| is busy on that day, she will probably say something like, "Tonight  |
| I'm busy, but tomorrow night would great! "                          |
|                                                                      |
| ### 4- She\'s Curious About You {#shes-curious-about-you}            |
|                                                                      |
| A woman who\'s interested in you wants to know everything about you  |
| (so she can talk about you with her girlfriends). She will quiz you  |
| about your family, your background, and your tastes in things like   |
| food, music and movies. She may something like "Oh, you like         |
| swimming, too? We should do that some time." This is a clear signal  |
| to move forward.                                                     |
|                                                                      |
| ### 5. She\'s Jealous O                                              |
| f Other Women You Talk To {#shes-jealous-of-other-women-you-talk-to} |
|                                                                      |
| An interested woman will watch her competition like a hawk (and with |
| talons bared). So if you notice her fuming when you are joking       |
| around with other women, you can be sure that she wants you to be    |
| more than just her friend.                                           |
|                                                                      |
| The above are some of the most obvious signs that she wants you.     |
| Spotting just one may not be enough but if a lot of these signals    |
| are emitted your way, go forth and secure that date you always       |
| wanted.                                                              |
