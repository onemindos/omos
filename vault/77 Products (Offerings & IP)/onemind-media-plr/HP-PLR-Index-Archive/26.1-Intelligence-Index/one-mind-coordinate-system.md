# One Mind Coordinate System (OMCS)

## The Life API for Human-AI Symbiosis

---

## Overview

The One Mind Coordinate System is a universal addressing scheme that gives every element of your life a unique, speakable, machine-readable identifier. Unlike traditional file organization systems, OMCS is designed for **AI navigation** — enabling Legacy AI to find, link, execute, and reason across your entire life operating system.

### Core Principle

> Every file, note, protocol, habit, goal, contact, asset, and automation has an address. AI doesn't search. It **navigates**.

---

## Schema Structure

```
[PILLAR].[CATEGORY].[TYPE][ID]

Examples:
HP.10.P01      → Health Protocol #1
GE.20.G01      → Venture Goal #1  
LE.30.C.sarah  → Contact: Sarah (Relationships)
IT.10.AUTO.07  → Automation #7 (Infrastructure)
```

### Components

| Component | Format | Purpose |
|-----------|--------|---------|
| **Pillar** | HP, LE, GE, IT | Life domain (2 letters) |
| **Category** | 10-99 | Topic area within pillar |
| **Type** | .P, .H, .G, etc. | What kind of item |
| **ID** | 01-99 or name | Unique identifier |

---

# Principles

1. **Every item has one home.** No duplicates. No ambiguity.

2. **Numbers don't change.** Once assigned, a coordinate is permanent.

3. **AI navigates, humans decide.** The system serves both.

4. **Protocols > willpower.** Encode decisions into executable steps.

5. **Cross-link liberally.** The power is in connections.

6. **Archive, don't delete.** History has value.

7. **Start rough, refine always.** Perfect is the enemy of done.
