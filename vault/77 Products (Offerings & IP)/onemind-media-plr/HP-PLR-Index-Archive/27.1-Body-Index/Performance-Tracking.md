## Review Cadence

### Daily Check-in
```
Morning (2 min):
- [ ] Rate energy (1-10)
- [ ] Rate sleep quality (1-10)
- [ ] Set movement intention

Evening (2 min):
- [ ] Log workouts completed
- [ ] Rate focus/productivity (1-10)
- [ ] Note wins and blockers
```

### Weekly Review (Sundays)
```
- [ ] Review daily metrics trends
- [ ] Analyze workout completion rate
- [ ] Check sleep consistency
- [ ] Plan next week's training
- [ ] Adjust nutrition if needed
```

### Monthly Assessment
```
- [ ] Compare metrics to previous month
- [ ] Review body composition changes
- [ ] Assess energy/mood patterns
- [ ] Update goals if needed
- [ ] Schedule any health appointments
```

### Quarterly Deep Dive
```
- [ ] Full biometric assessment
- [ ] Blood work review
- [ ] Goal recalibration
- [ ] Protocol adjustments
- [ ] Equipment/supplement review
```
