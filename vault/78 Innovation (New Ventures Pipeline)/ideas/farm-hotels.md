# Farm Hotels

## Definition
Boutique hospitality properties set on working or lifestyle farms. Guests stay overnight in curated accommodations — barns converted to suites, cabins, container homes, or glamping structures — while experiencing farm life as the amenity.

## Market Context
Agritourism is a $9B+ industry in the US alone and growing. Farm hotels command premium rates ($300-800/night) by offering what city hotels cannot: land, quiet, animals, food provenance, and authentic experience.

## Property Formats
| Format | Notes |
|--------|-------|
| Converted barn suites | High-end, architectural, photogenic |
| Cabin clusters | Multiple revenue units per property |
| Glamping (yurts, Airstreams) | Lower build cost, fast to deploy |
| Container homes | Modular, modern, Instagram-friendly |
| Farmhouse B&B | Classic, owner-operated, intimate |

## Revenue Layers
- Nightly room rate (core)
- Farm-to-table dining / private dinners
- Experiences: horseback, foraging, cooking classes
- Wellness programming (connects to Farm Wellness concept)
- Events: micro-weddings, corporate retreats, workshops
