## What It Is

**ODG AI** is Zeus's AI services venture. We build **governed AI employees** for businesses — not just automations, but properly architected agent systems with human oversight built in.

## Core Differentiator: Governance

The market is full of "spin up an agent and throw tools at it." ODG AI is different because we architect for reliability and delegation:

| What others do | What ODG AI does |
|----------------|-----------------|
| Single agent, all tools | Main orchestrator + specialized subagents by function |
| No memory | Persistent memory + workspace rules |
| Send directly | Reviewed drafts before external sends |
| Full autonomy | Approval gates for risky actions |
| No routing logic | Clear routing: sales, ops, email, calendar, support |

**The goal:** Reliable delegation — not waking up to an agent that looped, spammed, broke context, or touched something it shouldn't have.

## Tech Stack

- **Runtime:** OpenClaw (agent gateway)
- **Architecture:** Orchestrator + subagents (function-specific)
- **Memory:** Persistent workspace + session memory
- **Approval layer:** Exec approvals via Telegram DM
- **Audit:** Tool call logs + event trail

## Positioning

> *"We don't just spin up OpenClaw and throw tools at it. We build governed AI employees."*

Target: Businesses that want AI doing real work (sales, ops, email, support) without the chaos of uncontrolled agents.
