# Eventbrite

> Event discovery and ticketing platform. Find and register for local events, workshops, conferences, networking meetups, and more. Also used for hosting/selling tickets to your own events.

---

## Overview

| Field | Detail |
|-------|--------|
| **URL** | https://www.eventbrite.com |
| **My Events** | https://www.eventbrite.com/myevents |
| **Organizer** | https://www.eventbrite.com/organizer |
| **Focus** | Event discovery, ticketing, RSVP management |
| **Cost** | Free to attend free events; paid events have service fees; hosting free: $0, paid: % fee |

---

## Use Cases

| Use | How |
|-----|-----|
| **Find events** | Search by category, location, date — workshops, networking, tech, health |
| **RSVP tracker** | All registered events in My Events dashboard |
| **Host events** | Create event pages, sell tickets, manage attendees |
| **Email updates** | Follow organizers to get notified of new events |
