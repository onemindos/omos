# 08 Environments (Locations)

> *"Where life happens — home, office, and beyond."*

---

## Purpose

Environments houses **physical location profiles** — your home, office, travel setups, and deployment configurations. Each environment has its own context, tools, and workflows.

---

## What Lives Here

- **Home (Haven)** — Home automation, household workflows, family operations
- **Office** — Work environment, professional setup
- **Mobile** — Travel configurations, remote work profiles
- **Deployments** — Location-specific system deployments

---

## Environment Template

```markdown
# [Location Name]

**Type:** Home | Office | Mobile | Remote
**Status:** Active | Standby

## Context
- Location details
- Network configuration
- Available hardware

## Workflows
- Location-specific automations
- Scheduled routines

## Integrations
- Home Assistant
- Local devices
- IoT sensors
```
