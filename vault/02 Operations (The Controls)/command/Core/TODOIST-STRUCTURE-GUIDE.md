## Todoist Hierarchy Rules

### Level 1: Pillars (Top-Level Projects)

Create 4 top-level projects:

```
📁 00-24 SO (Sovereign Operations)
📁 25-49 HP (Holistic Performance)
📁 50-74 LE (Legacy Evolution)
📁 75-99 GE (Generational Empire)
```

### Level 2: Areas (Sub-Projects)

Under each pillar, create sub-projects for each major area.

### Level 3: Sections

Within each sub-project, create sections for categories.

### Level 4: Tasks

Individual tasks with metadata linking to vault documents.

## Task Metadata Standard

Every task that relates to a vault document should include:

### Task Description Template

```
📄 [[Vault Path/Document.md]]
🎯 Goal: [What success looks like]
📊 Metrics: [How to measure]
🏷️ Tags: ##Pillar ##Area ##Category
```

### Example Task

**Task Title:** Review Q1 Marketing Plan

**Description:**
```
📄 [[76 Legacy Acadacom/76.7 Marketing/Q1-Marketing-Plan.md]]
🎯 Goal: Finalize Q1 campaign strategy
📊 Metrics: Budget approved, timeline confirmed
🏷️ Tags: ##GE ##76-Acadacom ##Marketing
```

**Labels:** `@ge`, `@marketing`, `@high-priority`

**Project:** `75-99 GE > 76 Legacy Acadacom`

**Section:** Marketing

## Label System

### Pillar Labels (Primary)

- `@ui` - Sovereign Operations tasks
- `@hp` - Holistic Performance tasks
- `@le` - Legacy Evolution tasks
- `@ge` - Generational Empire tasks

### Priority Labels

- `@critical` - Must do today
- `@high-priority` - Important, time-sensitive
- `@low-priority` - Nice to have

### Context Labels

- `@computer` - Requires computer
- `@phone` - Can do on phone
- `@home` - Must be at home
- `@office` - Must be at office
- `@errands` - Out and about
- `@waiting` - Waiting on someone/something

### Type Labels

- `@project` - Project-related
- `@routine` - Recurring task
- `@review` - Review/audit task
- `@research` - Research needed
- `@decision` - Requires decision

### Agent Labels

- `@agent-ready` - Can be delegated to Letta agent
- `@agent-review` - Needs agent review
- `@human-only` - Human decision required

## Quick Start Commands

### Create Task with Full Metadata

```
Task: [Task Title]
Project: [Pillar] > [Area]
Section: [Section]
Labels: @[pillar], @[context], @[type]
Description:
📄 [[Vault/Path/To/Doc.md]]
🎯 Goal: [Success criteria]
📊 Metrics: [Measurement]
🏷️ ##Pillar ##Area ##Category
```

### Add Task via Quick Add

```
[Task Title] ##Pillar ##Area @label1 @label2 today p1
```

Example:
```
Review marketing plan ##GE ##76-Acadacom ##Marketing @ge @review today p1
```

## Inbox Query Blocks (Obsidian)

### Standard Inbox Query

```todoist
name: "📥 Inbox"
filter: "#Inbox"
sorting:
  - date
  - priority
```

### Legacy Agent Tasks

```todoist
name: "🤖 Legacy Queue"
filter: "@legacy"
sorting:
  - priority
  - date
```

### Full Triage View

```todoist
name: "📥 Full Triage"
filter: "#Inbox | (no project)"
sorting:
  - date
  - priority
```

### Agent-Ready Tasks

```todoist
name: "🤖 Agent Ready"
filter: "@agent-ready"
sorting:
  - priority
  - date
```
