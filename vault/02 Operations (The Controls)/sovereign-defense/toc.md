# TOC — Tactical Operations Center

## Definition
The command and control hub of a military operation. All intelligence flows in, decisions are made, and orders are issued from the TOC. It is not where the fighting happens — it is where the operation is directed.

## Standard TOC Functions
- **Common Operating Picture (COP)** — real-time display of all friendly, enemy, and neutral forces
- **Battle Tracking** — monitoring mission execution against the operational plan
- **Intelligence Processing** — HUMINT, SIGINT, ISR feeds analyzed and distributed
- **Fire Support Coordination** — deconflicting fires, managing airspace
- **Logistics Coordination** — tracking supply, medevac, reinforcement
- **Communications Hub** — radio nets, comms discipline, message traffic

## TOC Composition (typical)
| Role | Function |
|------|----------|
| **Commander** | Decision authority |
| **XO (Executive Officer)** | Runs the TOC, manages staff |
| **S2 (Intelligence)** | Enemy situation, threat analysis |
| **S3 (Operations)** | Current operations, battle tracking |
| **S4 (Logistics)** | Supply, maintenance, medevac |
| **Fire Support Officer (FSO)** | Artillery, air support coordination |
| **Comms (S6)** | Radio nets, comms architecture |

## TOC Setup Considerations
- Physical security — hardened, concealed, dispersed from command
- Redundant comms — primary + alternate + contingency + emergency (PACE plan)
- Power — generator + battery backup
- Maps / displays — analog + digital (ATAK / WebTAK)
- SOPs — battle rhythm, reporting cycles, decision briefs

## Relationship to ATAK
[[atak]] feeds the TOC's digital display — blue force tracking, ISR overlays, and CoT messages populate the common operating picture the S3 and Commander use to make decisions.
