# Open-Source Drone Swarm Coordination Software

## Research Goals

- Multi-drone C2 platforms
- Swarm control engines
- Path deconfliction software
- Ground control stations (10+ drones)
- GPS-denied navigation stacks
- OTA fleet update systems
- Compatibility: PX4 / ArduPilot / Custom

## Projects to Investigate

| Project | Notes |
|---------|-------|
| **QGroundControl** | Multi-vehicle support — already in use |
| **MAVProxy** | Swarm extensions via Python |
| **Skybrush** | Commercial but has open components |
| **Crazyswarm** | Research platform (Crazyflie focus) |
| **ROS / ROS2** | Swarm packages ecosystem |
| **ROSMA** | Swarm management layer |
