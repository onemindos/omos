Legacy OS Feature Naming System for Circle.so
Platform
Introduction
The Legacy Platform is a unified ecosystem of business communities (Legacy Restore, Legacy Capital,
Legacy Acadacom, etc.) built on Circle.so. To create a seamless Legacy OS experience, we will establish a
branded naming system for Circle’s native features. This involves renaming and grouping Circle features
under simple, branded terms that reflect their function and align with the Legacy brand. By standardizing
feature names (e.g. renaming chat, DMs, and comments as Legacy Connect), members will intuitively
understand each tool’s purpose. This document outlines the naming strategy, the proposed Legacy-style
names for all key Circle features, and guidance on implementing these names in the platform’s navigation
for each business community space.


Legacy Naming Strategy
The naming strategy focuses on clarity, consistency, and brand identity. All feature names:


     • Use the “Legacy” prefix to reinforce the brand across the platform.
     • Are short and descriptive, so members immediately grasp their function.
     • Group related features under one umbrella term when possible (for example, all communication
       tools are under Legacy Connect).
     • Remain consistent across all Legacy business spaces (Legacy Capital, Legacy Restore, Legacy
       Acadacom), providing a uniform experience.

By following these principles, the Legacy OS will feel like one cohesive system, even though it consists of
multiple Circle communities.


Legacy-Branded Feature Categories and Names
Below is the complete set of Circle.so native features rebranded with Legacy-style names. Each entry
includes the Circle feature(s) it corresponds to and a brief description:


     • Legacy Connect – Communication tools (Chat, Direct Messages, Comments).
       Includes Circle’s real-time chat channels, private messaging (DMs), and commenting functionality. Legacy
       Connect is the hub for member-to-member communication. It encourages networking, quick
       exchanges, and community bonding. For example, a group chat or lounge space and the DM inbox
       would both fall under “Legacy Connect.” This name highlights the function (connecting people) and
       provides a single identity for all messaging features.

• Legacy Forum – Discussion boards and posts.
  Maps to Circle’s Discussions or forum feature (community posts, threads, and replies). The Legacy Forum
  is where longer-form discussions happen. Members can start topics, ask questions, and share
  knowledge in an organized, threaded format. This branded term conveys a dedicated space for
  community discourse. (Alternatively, Legacy Exchange could be used to emphasize exchanging
  ideas, but Legacy Forum is straightforward and familiar.)


• Legacy Learn – Online courses and educational content.
  Corresponds to Circle’s Courses feature. Legacy Learn houses all structured learning material across
  the Legacy platform. In this area, members enroll in courses, follow lesson plans, and track their
  progress. The name suggests learning and personal development, aligning with the Legacy
  Acadacom focus on education. (Each Legacy business can offer its own courses under the Legacy
  Learn banner if applicable.)


• Legacy Events – Events and live gatherings.
  Uses Circle’s Events feature for scheduling and hosting events. Legacy Events covers webinars, live
  streams, workshops, office hours, or any scheduled community gathering. Members can view
  upcoming event listings, RSVP, and join live sessions. The name is simple and directly indicates where
  to find events related to each Legacy community.


• Legacy Pay – Payments and monetization system.
  Encompasses Circle’s Payments feature (memberships, subscriptions, paid content). Legacy Pay is the
  branded name for all financial transactions on the platform. This includes purchasing memberships
  or access to premium areas, paying for courses, or any e-commerce element in Legacy communities.
  The term is short and suggests a secure, Legacy-branded payment portal. (For example, if Legacy
  Capital has a premium investor forum, it would be unlocked via Legacy Pay.)


• Legacy Insights – Analytics and community metrics.
  Reflects Circle’s Analytics dashboard. Legacy Insights provides administrators with data on
  community engagement, member activity, and growth metrics. The name implies actionable
  intelligence – owners and moderators can dive into Legacy Insights to make informed decisions.
  While primarily an admin-facing feature, the consistent branding reminds the team that analytics are
  part of the Legacy OS toolset.


• Legacy Rewards – Gamification features (points, badges, ranks, leaderboards).
  Tied to Circle’s Gamification elements. Legacy Rewards is the system that motivates and recognizes
  member engagement. It encompasses points for activities, achievement badges, leveling up/rank
  titles, and any leaderboards or “hall of fame” showcases. The name emphasizes the reward aspect of
  participation. For example, members might earn Legacy Rewards badges for contributions, and a
  space could highlight top contributors across Legacy Capital, Restore, etc. This branding makes the
  gamification program feel like an integral, fun part of the Legacy experience.


• Legacy Assist – AI-powered assistance and agents.
  Combines Circle’s AI Agents and Community AI features. Legacy Assist is the suite of AI tools that help
  members and admins. This includes AI chat agents (Legacy’s custom AI assistants trained on
  community knowledge) and other AI features (like smart search, AI-generated summaries or content
  suggestions). The name Assist conveys help and guidance. For instance, each community could offer

       Corresponds to Circle’s Workflows feature. Legacy Flow represents automated processes and routines
       that run in the background of the Legacy platform. Administrators can set up Legacy Flow rules to

       of Legacy’s built-in capabilities.

       Relates to Circle’s integration capabilities (e.g., Zapier, APIs, and third-party app connections). Legacy

       a CRM, connecting Slack/Discord, or enabling single sign-on, these integrations are framed as part of
       the Legacy ecosystem. The name assures users and admins that external tools are seamlessly
       integrated under the Legacy umbrella. (In settings, this might be a page listing connected apps,
       labeled with the Legacy term.)


     • Legacy Customization – Customization and design settings.
       Maps to Circle’s customization options (community appearance, branding, custom pages). Legacy
       Customization covers all configuration of the platform’s look and feel to match the Legacy brand.
       This includes theme colors, logos, domain mapping, and layout options. By calling it Legacy
       Customization, we reinforce that tailoring the user experience is an expected part of the Legacy OS.
       (Admins would find this in the settings; members might not see this term, but if custom pages or
       navigation sections are created, those are results of the Customization process.)


     • Legacy Reach – Marketing Hub (email and outreach tools).
       Represents Circle’s Marketing Hub features: email campaigns, newsletters, contact management, and CRM
       integrations. Legacy Reach is the marketing command center for the Legacy platform. It enables
       community managers to reach out to the audience via branded email updates, manage leads and
       contacts, and automate marketing funnels—all from within Legacy OS. The term “Reach” highlights
       extending the platform’s influence and engaging a broader audience. Inside Circle, this could be a
       section where admins compose newsletters or view email analytics, labeled as Legacy Reach to stay
       on-brand.

Implementing Legacy Names in Circle.so
To bring these names to life, we will incorporate them into the Circle.so interface and configuration. Below
are recommendations for how and where to use the new Legacy-branded names within the platform:


     • Space Group Headings: Use the Legacy names as headings in the Circle sidebar to group related
       spaces. For example, create a sidebar section titled “Legacy Connect” that contains chat channels or
       a Q&A space. This clearly signals that anything under that heading is meant for member
       communication. (Note: Circle allows adding text labels or dividers in the navigation – label those with
       Legacy terms.)


     • Space Names: Rename individual spaces to match the Legacy terminology. Within each business
       group (Legacy Capital, Restore, Acadacom), the spaces should use the consistent names: e.g., a




                                                     4
 discussion space named “Forum”, a course space named “Learn”, an event space named “Events”,
 etc. You might include the Legacy prefix if needed for clarity, but since the entire platform is Legacy-
 branded, just the feature name can suffice in context. The key is that a member in any Legacy
 community sees the same terms for the same functions. For instance, instead of a space called
 “General Discussion,” name it “Forum” under the Legacy scheme (or even “Legacy Forum” if you
 prefer the full branding in the UI).


• Group Tags or Descriptions: In Circle, you can add descriptions to space groups or use topics/tags
  for content. Leverage these to reinforce the Legacy names. For example, tag certain discussion posts
  with “Legacy Forum” or mention in the description “This is the Legacy Capital discussion forum.”
  Consistent wording in descriptions, welcome posts, and pinned messages will educate members on
  the new terminology. If a member clicks the Direct Messages icon, you might show a tooltip or
  welcome message that says “Legacy Connect: Your direct messages.”


• Navigation Menu Structure: Organize the left-hand navigation by the Legacy categories for each
  company space group. Typically, you will have a top-level heading for each business (as a space
  group in Circle), and within that, sub-spaces grouped by feature. We recommend ordering them in a
  logical flow (perhaps aligned with how members will use the platform): start with interactive
  communication (Connect, Forum), then content (Events, Learn), then any extras like Rewards or
  Assist. For example, within Legacy Acadacom, the menu might list Connect, Forum, Events, Learn
  in one section for member-facing features, and possibly an Assist Q&A bot link. Admin or behind-
  the-scenes sections (Integrations, Customization, Reach) would not appear for end-users, but
  admins would know those settings correspond to Legacy Integrations, Legacy Customization,
  etc., when configuring the platform.


• Custom Pages or Links: Circle.so allows creation of custom pages or external links in the navigation.
  You can use this to surface certain Legacy features. For example, if Legacy Rewards (gamification)
  doesn’t have an automatic page, you might create a custom page called “Rewards” that explains the
  points and badges system or shows a leaderboard of top contributors. Place that page under a
  Legacy Rewards heading or alongside the Forum and Events in the nav. Similarly, if Legacy Assist
  (the AI agent) is accessed via a chat link, you could create a prominent link in the menu like “Ask
  Legacy Assist” so users know where to get AI help.


• Consistent Terminology in Content: Ensure that in all community content (welcome emails,
  tutorials, onboarding guides, tooltips), you refer to features by their Legacy names. For instance,
  instruct new users to “Start a conversation in Legacy Connect” or “Check upcoming Legacy Events,”
  instead of using Circle’s default terms. This consistency between the interface labels and
  documentation will reinforce the branding and reduce confusion.


• Administrator View: Some features like Legacy Insights, Legacy Reach, Legacy Flow, Legacy
  Integrations, and Legacy Customization are primarily used by admins or moderators. In the Circle
  admin settings, use these terms informally among the team when discussing configurations. Where
  possible, set any customizable label or section name to the Legacy version. For example, if sending
  an email campaign via Circle’s Marketing Hub, you might title it Legacy Reach Newsletter so that
  even internal records carry the branding. The admin dashboard itself might not allow renaming the
  “Analytics” tab, but your internal training materials would call it Legacy Insights for consistency.

Navigation Structure for Legacy Business Communities
Each Legacy business (Capital, Restore, Acadacom, etc.) operates as a space group within the Circle
platform. We will apply the naming system uniformly across these groups so that a member moving from
one community to another finds a familiar layout. Below is a recommended navigation and naming setup
for each business space group:


     • Legacy Capital – Focused on finance and investment community.
       Spaces & Sections:
     • Connect: A community chat or networking lounge for Legacy Capital members (under the Legacy
       Connect umbrella). This could be a chat space named “Connect” where members discuss finance
       tips informally, and it’s also understood that direct messages are part of Connect.
     • Forum: The main discussion board for Legacy Capital (branded as Legacy Forum). Here members
       post investment strategies, Q&As, market analysis threads, etc. The space name would be “Forum” in
       the sidebar.
     • Events: A calendar or list of upcoming events (webinars on financial literacy, live Q&A sessions with
       experts, etc.) labeled Legacy Events. Members click “Events” to see what’s scheduled in the Legacy
       Capital community.
     • Learn: (If applicable) A courses section for financial education content under Legacy Learn. For
       example, if Legacy Capital offers a course like “Investing 101,” it would reside here. If no formal
       courses are offered, this space can be omitted for Legacy Capital.
     • Rewards: An optional space or page highlighting Legacy Rewards in the Capital community. For
       instance, a “Leaderboard” showing top contributors in Legacy Capital or a “Achievements” page
       listing badges (e.g. “Legacy Capital Guru” badge for top finance advisors). This reinforces
       gamification within that specific community.

     • Assist: If using an AI agent, provide access labeled with Legacy Assist. For example, a chat space
       named “Ask Legacy Assistant” where members can pose finance questions to the AI (trained on
       Legacy Capital content).
       (Administrators of Legacy Capital will also utilize Legacy Insights for community analytics, configure any
       Legacy Flows for automation (e.g., auto-tag a member after their first post in Forum), and manage Legacy
       Reach communications for this segment of the audience. These are back-end uses and don’t appear as
       member-facing menu items.)


     • Legacy Restore – Focused on wellness/restoration community.
       Spaces & Sections:


     • Connect: A chat channel or social space for Legacy Restore members to share quick updates,
       motivational quotes, or support each other (under Legacy Connect). This space fosters day-to-day
       engagement and personal connection.
     • Forum: The discussion space for in-depth conversations on wellness, recovery, and related topics
       (Legacy Forum branding). Members can start threads about their journeys, ask health questions, or
       discuss restoration techniques.

• Legacy Acadacom – Focused on education and academia community.
  Spaces & Sections:


• Connect: A student/alumni lounge or teacher-student chat area under Legacy Connect. Legacy
  Acadacom members (students, educators) can interact freely here outside of structured classes – for
  networking, introductions, or quick questions.
• Forum: The academic discussion forum for topics, research questions, peer support, etc. (Legacy
  Forum). For example, students might discuss course topics or share knowledge resources. This
  space can serve as a general Q&A outside of specific course contexts.
• Events: Legacy Events for Acadacom could include live study sessions, expert guest lectures, or
  community meetups. The “Events” menu will list any scheduled academic events or office hours.
• Learn: This is likely a centerpiece for Legacy Acadacom. Under Legacy Learn, all formal courses and
  lessons are organized. You might have multiple course spaces (one per course or program) grouped
  here. The sidebar might show a heading “Courses (Legacy Learn)” with each course listed, or just a
  single entry if using Circle’s course catalog page. The branding “Legacy Learn” assures users this is
  the official learning hub.
• Rewards: Gamification in an academic context (under Legacy Rewards) might include earning
  points for course completion, badges for quiz scores or community contributions (like a “Top
  Scholar” badge). A “Rewards” page can celebrate high achievers or provide incentives for course
  engagement.
• Assist: An educational AI tutor or assistant via Legacy Assist can be very useful here. A dedicated
  “Ask Legacy Assist” space could let students get help on coursework or ask questions about the
  Legacy Acadacom content. Since the AI agent can be trained on course materials and forum
  discussions, it becomes a 24/7 teaching assistant.
  (On the admin side, Legacy Acadacom leaders will use Legacy Insights to track student engagement and
  success rates, set up Legacy Flows (e.g., auto-enroll a student into an alumni group after finishing a
  course), manage Legacy Integrations like connecting to an LMS or webinar tool if needed, and use Legacy
  Reach to send academic newsletters or announcements.)

Consistency Across Groups: Each business space group follows the same naming conventions. A member
of any Legacy community will always find “Connect”, “Forum”, “Events”, “Learn” (if courses are offered),
etc., in that community’s menu. The Legacy prefix and concept for each feature remains the same, even if
the content differs. This consistent information architecture makes navigation intuitive. For example, after
using Legacy Acadacom, a member joining Legacy Restore will immediately know that “Events” means
upcoming events and “Forum” is where to post, without needing re-orientation.


Use of Legacy Branding in Navigation: You have some flexibility in how strongly to display the Legacy
brand in each label. Some communities might opt to display the full names (e.g., Legacy Connect, Legacy
Events in the sidebar for emphasis), whereas others might shorten them (just Connect, Events), since the
overall app itself is Legacy-branded. Either approach works as long as the naming is consistent. One
approach is to use the Legacy prefix for top-level or standalone sections that encompass multiple items
(like a top-level menu that leads to a page consolidating those features), and use short labels for individual
spaces within a group. For example, you might have a top-level sidebar heading “Legacy Connect” and
underneath it, a space called “Chat Lounge” and a link for “Direct Messages” – both falling under the
Connect umbrella. In another case, simply having a space named “Connect” can imply Legacy Connect if it’s
within the Legacy platform.


Conclusion
By implementing this Legacy OS branded naming system, we create a clear and unified experience across
all facets of the platform. Members engage through Legacy Connect, share knowledge on Legacy Forum,
learn via Legacy Learn, and so on – all within a familiar Legacy-branded context. Each feature’s name is
descriptive of its function, making the platform easy to navigate. Moreover, using these names consistently
in the Circle.so environment (spaces, headings, tags, and internal references) ties the independent Legacy
communities together under one cohesive umbrella. This approach strengthens the Legacy brand identity
and ensures that whether a user is interacting with Legacy Capital, Legacy Restore, or Legacy Acadacom,
they feel like they are using one integrated Legacy Operating System for community and business
engagement.
