## **Portal System: ZPortals**

ZPortals allows you to create customizable web portals for clients, vendors, and other stakeholders, integrating seamlessly with multiple Zoho applications.

Supported Zoho Applications:

- CRM: Sync all modules and fields to the client portal.
- Books: Enable clients to pay invoices, view quotes, and access financial information.
- Subscriptions: Manage active subscriptions and payment methods.
- Desk: Allow users to submit and view support tickets.
- Sign: Facilitate electronic document signing.
- Vault: Securely manage login credentials.
- WorkDrive: Access and upload documents directly from the portal.

### **Pricing:**

- Basic Plan: $49/month for up to 50 active users.
- Unlimited Users Plan: $399/month for unlimited users.
