# Inbox — Capture Zone

> *"Capture everything. Process ruthlessly."*

---

## Purpose

Inbox is the **universal capture zone**. Everything enters here first before being routed to its proper home. This is the gateway, not a destination.

---

## What Lives Here

- **Quick Captures** — Ideas, thoughts, fleeting notes
- **Unprocessed Inputs** — Emails to file, articles to read
- **Decision Queue** — Items needing routing decisions
- **Temporary Files** — Working documents pre-organization

---

## Processing Protocol

1. **Capture** — Get it in fast, worry about format later
2. **Clarify** — What is this? Is it actionable?
3. **Organize** — Route to proper pillar/area
4. **Review** — Weekly inbox zero sweep

---

## Routing Decision Tree

| Question | If Yes → |
|----------|----------|
| Is it about me/self-improvement? | HP (Holistic Performance) |
| Is it about family/home/legacy? | LE (Legacy Evolution) |
| Is it about business/money? | GE (Generational Endeavor) |
| Is it about tools/tech/systems? | IT (Innovative Technology) |
| Is it a project spanning multiple? | Atlas |
| Is it identity/vision related? | Zeus |
| Not sure? | Leave in Inbox, review later |

---

## Target: Inbox Zero

Process inbox at least weekly. Nothing should live here permanently.
