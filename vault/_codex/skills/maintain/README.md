# Maintain Pack

> Run recurring upkeep tasks — clear stale items, update statuses, and keep the vault current.

## CODEX Stage: Utility

## What It Does
Maintain handles the recurring housekeeping that keeps the vault healthy over time. It clears stale Inbox items, updates outdated statuses, archives completed work, refreshes time-sensitive content, and ensures nothing rots from neglect. It is the janitorial complement to Defrag's structural repairs.

## When to Use
- Scheduled daily or weekly maintenance window
- Vault has accumulated stale, outdated, or completed items needing cleanup
- Before a planning session to ensure the system reflects current reality
