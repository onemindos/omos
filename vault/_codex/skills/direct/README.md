# Direct Pack

> Prioritize organized items against active goals, assign to the right agent, and set execution order.

## CODEX Stage: D (Direct)

## What It Does
Direct is the planning and prioritization step. After content has been captured and organized, Direct evaluates each item against active goals, assigns it to the responsible agent (Sentinel, Coach, Haven, or Empire), and builds an execution queue so the most important work gets done first.

## When to Use
- Organized items need priority and agent assignment
- Active goals have changed and queues need re-ranking
- An agent asks "what should I work on next?"
