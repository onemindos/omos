# Reflect Pack

> Review completed work, extract lessons, score performance, and feed insights back into the system.

## CODEX Stage: × (Multiply)

## What It Does
Reflect closes the CODEX loop. It reviews what was executed, evaluates outcomes against goals, extracts lessons learned, and generates insights that feed back into future Capture and Direct stages. This is the eXamine/Multiply step — the compound growth engine of the system.

## When to Use
- End of a work session, day, or week
- After completing a significant task or project milestone
- When performance scores (PI, LI, WI) need updating
