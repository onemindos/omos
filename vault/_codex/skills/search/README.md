# Search Pack

> Find and retrieve information across the vault using keywords, tags, domains, and semantic queries.

## CODEX Stage: Utility

## What It Does
Search locates information anywhere in the vault. It handles keyword searches, tag-based filtering, domain-scoped queries, and cross-quadrant lookups. It returns relevant files with context so agents and users can find what they need without manually browsing the folder structure.

## When to Use
- Agent or user needs to find a specific file, note, or piece of information
- Cross-referencing content across multiple domains or quadrants
- Checking if something already exists before creating a duplicate
