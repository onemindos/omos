# Consolidate Pack

> Merge scattered notes, eliminate duplicates, and unify fragmented content into coherent documents.

## CODEX Stage: Utility

## What It Does
Consolidate finds related but scattered content across the vault and merges it into single, authoritative documents. It eliminates duplicates, resolves conflicting information, and ensures each topic has one canonical source of truth rather than fragments spread across multiple files.

## When to Use
- Multiple notes cover the same topic from different sessions
- A domain has accumulated redundant or overlapping content
- Preparing a comprehensive document from scattered research notes
