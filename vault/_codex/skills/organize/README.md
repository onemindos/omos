# Organize Pack

> Route Inbox items to the correct quadrant and domain, applying proper naming and metadata.

## CODEX Stage: O (Organize)

## What It Does
Organize takes raw captures from the Inbox and files them in the correct domain folder. It determines which quadrant the content belongs to, applies the right naming convention, adds frontmatter, and ensures nothing stays in the Inbox longer than necessary.

## When to Use
- Inbox has unprocessed items waiting to be routed
- A captured item needs to be classified into the correct domain
- Periodic Inbox sweep to clear accumulated captures
