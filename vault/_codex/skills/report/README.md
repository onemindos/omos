# Report Pack

> Generate structured reports from vault data — the × Multiply stage made tangible.

## CODEX Stage: × (Multiply) / Utility

## What It Does
Generates 4 types of reports by pulling data from domains, memory, git history, and frontmatter. Turns raw vault data into actionable intelligence.

## When to Use
- End of quarter → Quarterly Life Review
- Monthly check-in → Domain Health Report
- Annually → Family Legacy Report
- Preparing a pitch/presentation → Narrative Points

## Report Types

| Type | Frequency | Scope | Template |
|------|-----------|-------|----------|
| Quarterly Life Review | Every 3 months | All domain groups | `templates/quarterly-review.md` |
| Domain Health | Monthly / on-demand | Single domain or group | `templates/domain-health.md` |
| Family Legacy | Annually | LE + GE domains | `templates/family-legacy.md` |
| Narrative Points | On-demand | Any topic | `templates/narrative-points.md` |
