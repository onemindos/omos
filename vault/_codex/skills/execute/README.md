# Execute Pack

> Load context, perform the assigned work, file the output, and log the action.

## CODEX Stage: E (Execute)

## What It Does
Execute is the action step — where plans become results. It loads relevant context for a prioritized task, performs the work (create, update, research, communicate, or automate), saves the output to the correct domain with proper metadata, and logs what was done for the eXamine stage.

## When to Use
- A task has been prioritized and assigned by the Direct stage
- User explicitly requests an action to be performed
- A scheduled or unblocked task reaches its execution window
