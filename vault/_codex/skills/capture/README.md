# Capture Pack

> Ingest raw input from any source and save it to the Inbox for processing.

## CODEX Stage: C (Capture)

## What It Does
Capture is the entry point of the CODEX loop. It takes raw input — thoughts, messages, voice notes, links, clippings — and saves them as structured markdown in the Inbox (`24 Inbox (Queue)/`). Nothing enters the system without passing through Capture first.

## When to Use
- New information arrives from any source (conversation, research, notification)
- User says "save this", "note this", "remember that"
- An agent discovers something worth preserving during another task
