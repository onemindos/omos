# Defrag Pack

> Audit vault structure, fix misplaced files, repair broken links, and enforce naming conventions.

## CODEX Stage: Utility

## What It Does
Defrag is vault maintenance at the structural level. It scans for files in wrong domains, broken internal links, inconsistent naming, missing frontmatter, and other structural issues. Then it fixes them — moving files, renaming, updating links, and restoring consistency across the vault.

## When to Use
- Periodic vault health check (weekly or monthly)
- After a bulk import or migration that may have created inconsistencies
- When broken links or misplaced files are noticed during normal use
