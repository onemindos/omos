# Context Profile: Planning Mode

Load this context when doing strategic planning, goal setting, or project scoping.

---

## Pre-Load Files

1. `codex/00-24 SO/00 Framework/` — Core doctrine, active goals, principles
2. `codex/CODEX-FRAMEWORK.md` — The CODEX method for process reference
3. Any active project files tagged `type/project, status/active`
4. Most recent weekly or monthly review

## Focus Domains

- `00 Framework` — goals, doctrine, principles
- `10 Development` — technical planning
- `08 Infrastructure` — capacity and constraints
- Any domain relevant to the planning topic

## Approach

1. Start with current goals and priorities
2. Review recent reviews for context on what's working/not
3. Use `_codex/templates/project.md` for new project plans
4. Use `_codex/templates/decision.md` for decision records
5. Link new plans to existing codex notes

## Outputs

- Updated or new project files
- Decision records for key choices
- Updated active goals if priorities shifted
