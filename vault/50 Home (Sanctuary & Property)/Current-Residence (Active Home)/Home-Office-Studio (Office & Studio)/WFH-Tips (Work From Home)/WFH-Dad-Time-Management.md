# WFH Dad Time Management

> The core problem: family and business share the same physical space. There is no commute to create separation. You have to engineer the separation yourself.

---

## The Pre-Family Window

The most protected block of the day is the one that happens before anyone else is awake.

- Wake 60–90 min before the household
- First 10 min: nothing digital — just coffee, paper, orient
- Write today's 3 most important tasks (not urgent — *important*)
- If exercising: this is the slot. It will not happen later.
- Begin deep work immediately after

This is the only block that is guaranteed to be interruption-free. Protect it.

---

## Handling Kid Interruptions

Kids interrupt every 20–30 minutes on active days. That's not a problem to solve — it's a reality to design around.

**Teach one-at-a-time asking**: Before they can make a second request, the first one must be resolved. This reduces request volume significantly.

**The defer rule**: If it's not a safety issue and you're mid-task, it waits until you reach a stopping point. "I'll help you in 10 minutes" — set a timer so they trust it.

**Teach age-appropriate self-sufficiency**: Every task a kid can do themselves is one less interruption. This compounds over years.

**Interruption triage**: Some things need you now. Most don't. Train yourself to ask "does this require me right now?" before you stop what you're doing.

---

## The Capture System

When working in a high-interruption environment, the notebook-by-desk rule is non-negotiable:

- Keep a physical notebook open at the desk at all times
- Any thought, task, or idea that hits during family chaos → write it immediately → return to work
- Review the notebook at end of day — decide what's actionable
- This prevents the "I was thinking of something important and lost it" problem permanently

---

## Daily Structure (Zeus Reference)

| Block | Time | What |
|-------|------|------|
| Pre-family deep work | Before household wakes | Highest-priority creative/strategic work |
| Morning handoff | Kids up | Family mode — don't fight it |
| Mid-morning block | Kids occupied/school | Second deep work or admin batch |
| Afternoon | Variable | Calls, errands, content, light tasks |
| Hard cutoff | Set time daily | Work ends — not "when I finish" |

> The hard cutoff is not about doing less. It's about forcing prioritization. If everything must fit before a set time, you stop doing things that don't matter.
