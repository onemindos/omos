# Daily WFH Protocol

> A protocol is not a to-do list. It is a set of standing decisions made in advance so you don't have to make them under pressure every day.

---

## Morning Sequence (Before Anything Else)

- [ ] Wake before household
- [ ] No screens for first 10 minutes
- [ ] Write today's 3 most important tasks on paper
- [ ] Clear desk if it wasn't done last night
- [ ] Begin deep work block — **do not open email or messages first**

---

## Before Going Online Rule

Have a defined purpose every single time you open a browser or app:

> *"I am going online to ___________."*

If you can't finish that sentence, don't go online yet. Aimless online time is the single biggest time drain in remote work. Keep a notebook open with your daily task list. When the session is done, return to the list.

---

## Focus Block Rules

- Minimum 90 minutes, uninterrupted
- Phone on DND during focus block
- Email and messages closed — not minimized, closed
- One task at a time — finish before switching
- Timer running — visibility on how long you've been in the block

---

## Communication Windows

| Channel | When |
|---------|------|
| Email | Morning start / Mid-day / End of work |
| Messages (non-urgent) | Same as email windows |
| Calls | Batched afternoon block or by appointment |
| Urgent (actual emergency) | Always open |

Non-emergency calls during deep work → voicemail → call back in communication window.

---

## Mobility Advantage

Wireless + laptop setup enables location flexibility:
- Front porch or yard while kids play outside
- Coffee shop for change of environment on creative blocks
- Any room in the house based on noise level

Rule: wherever you set up, the protocol travels with you. Location flexibility is only an advantage if the discipline does too.

---

## Hard Cutoff

Set a specific end time. Work stops then — not "when the inbox is empty" and not "when I finish this one last thing."

The cutoff enforces prioritization. If everything must fit before a set time, you stop doing things that don't matter.

---

## Evening Reset (5 Minutes)

- [ ] Clear desk
- [ ] Open browser tabs → close or send to Todoist
- [ ] Tomorrow's 3 most important tasks written tonight
- [ ] Todoist checked — anything due tomorrow surfaced

---

## Weekly Reset (15 Minutes — Sunday or Monday AM)

- Review last week: what actually got done vs what kept getting pushed?
- If something keeps getting pushed — is it actually important, or just guilt?
- Run the urgent vs important audit (see `Urgent-vs-Important-Framework.md`)
- Set the week's 3–5 most important *outcomes* — not tasks, outcomes
