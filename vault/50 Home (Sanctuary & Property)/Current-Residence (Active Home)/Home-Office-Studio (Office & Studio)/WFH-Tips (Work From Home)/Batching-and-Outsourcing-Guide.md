# Batching and Outsourcing Guide

> Two of the highest-leverage productivity moves for a solo operator: stop scattering similar tasks across the day, and stop doing work that isn't worth your time.

---

## The Assembly-Line Principle

Group identical or similar tasks and run them together in a single block. Never scatter them through the day.

| Task Type | Wrong (scattered) | Right (batched) |
|-----------|------------------|----------------|
| Email / DMs | Check every 30 min | 2–3 fixed times per day, answer all at once |
| Admin / invoicing | Reactive, whenever | One session per week (Friday afternoon) |
| Content edits | One small change at a time | Queue all changes, one editing session |
| Calls / voice | Throughout the day | One afternoon call block |
| Errands | Single-purpose trips | One run, multiple stops |

**Why it works**: Every context switch costs 15–25 minutes of recovery time to return to deep focus. Batching collapses dozens of switches into a handful.

---

## Email / Message Batching (Rules)

- Check at 3 fixed times: morning start, mid-day, end of work
- No notifications between checks — disable them
- Process to zero each session — reply, archive, or add to Todoist
- Do not leave emails "to deal with later" — that's a pile in digital form

---

## The Outsourcing Threshold

Any task that meets all three criteria should be outsourced or automated:

1. **Repeatable** — it happens more than once
2. **Below your value floor** — costs less per hour than your effective rate
3. **Not judgment-heavy** — doesn't require your specific knowledge or relationships

**Zeus's effective rate reference**: At the level Zeus is building toward, time is worth a minimum of $50–100/hr. Any task doable by a $15–25/hr VA or tool should not be done by Zeus.

**Outsource candidates:**
- Formatting, file organization, data entry
- Social media scheduling (after strategy is set)
- Research that is time-intensive but not judgment-heavy
- Appointment coordination

**Keep in-house:**
- Strategy and direction
- Client relationships and negotiations
- Content that requires Zeus's voice and perspective
- Financial decisions

---

## Automation Priorities

Anything done repeatedly → document it → automate or systematize:

| Recurring Task | Automation Path |
|---------------|----------------|
| Same customer question 3+ times | FAQ doc, website page, or canned reply |
| Recurring payment / invoice | Auto-billing + template |
| Weekly report or summary | Template + reminder, not manual creation |
| File organization | Naming convention + one session/week |

---

## The Leverage Stack (In Order)

1. **Eliminate** — does this need to be done at all?
2. **Automate** — can a tool do this without me?
3. **Batch** — can I do this less frequently but all at once?
4. **Delegate** — can someone else do this?
5. **Do it** — if none of the above apply, then do it

Only reach step 5 after checking 1–4.
