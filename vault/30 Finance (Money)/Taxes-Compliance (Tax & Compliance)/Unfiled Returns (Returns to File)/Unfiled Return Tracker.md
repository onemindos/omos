## IRS Substitute for Return (SFR) Risk

### What is SFR?
If you don't file, IRS can file a "Substitute for Return" (SFR) for you:
- Uses only income reported to IRS (W2s, 1099s)
- **Does NOT include deductions or credits**
- Files as single (worst tax rate)
- Results in higher tax bill than actual return

### If SFR Already Filed
You can still file your actual return:
- Your return supersedes the SFR
- Claim all legal deductions
- Reduce tax liability
- Must file within 3 years to claim refund

## Filing Methods

### Electronic Filing (Fastest)
- Use tax software or CPA
- Fastest processing (3 weeks)
- Immediate confirmation
- Refund via direct deposit

### Paper Filing (If e-filing unavailable)
- Mail to correct IRS address
- Slower processing (6-8 weeks)
- Send certified mail (proof of mailing)

## Penalties & Interest

### Failure to File Penalty
- **5% per month** of unpaid tax (max 25%)
- Starts from due date
- Much worse than failure to pay

### Failure to Pay Penalty
- **0.5% per month** of unpaid tax (max 25%)
- Can request abatement for reasonable cause

### Interest
- **IRS interest rate** (compounds daily)
- Currently ~8% annually (varies quarterly)
- Cannot be waived (but penalties can)
