# Skill: Morning Brief

## Purpose

Generate a comprehensive daily briefing for Zeus at 6:00 AM. This is the first touchpoint of the day, setting context and priorities.

## Knowledge

### Brief Structure

1. **Weather & Context** — Current conditions, any alerts
2. **Calendar Overview** — Today's meetings and events
3. **Priority Tasks** — Top 3 items requiring attention
4. **Pillar Status** — Quick health check across HP/LE/GE/IT
5. **Overnight Activity** — What happened while Zeus slept
6. **Energy Forecast** — Based on sleep data and schedule density

### Timing

- **Delivery:** 6:00 AM local time (Haven, USA)
- **Format:** Push notification + vault note
- **Length:** 2-3 minutes reading time max

## Procedures

### Generate Morning Brief

1. Query each pillar agent for status:
   - HP: Sleep score, energy forecast, habit streaks
   - LE: Family events, home status
   - GE: Revenue metrics, pending deals, content due
   - IT: System health, any overnight alerts

2. Pull calendar for today + tomorrow

3. Review Todoist for:
   - Overdue tasks (flag these)
   - Today's tasks by priority
   - Upcoming deadlines (next 48 hours)

4. Check overnight activity:
   - New emails requiring attention
   - System alerts
   - Any autonomously completed tasks

5. Compose brief using template:

```markdown
# Morning Brief — [DATE]

## Today at a Glance
- **Weather:** [conditions]
- **Meetings:** [count] scheduled
- **Focus Block:** [time if available]

## Priority Tasks
1. [Task 1] — [pillar] — [why urgent]
2. [Task 2] — [pillar] — [why urgent]
3. [Task 3] — [pillar] — [why urgent]

## Pillar Status
| Pillar | Status | Key Metric |
|--------|--------|------------|
| HP | [emoji] | [metric] |
| LE | [emoji] | [metric] |
| GE | [emoji] | [metric] |
| IT | [emoji] | [metric] |

## Overnight Activity
- [summary of what happened]

## Energy Forecast
Based on [sleep score] sleep and [meeting density], today is predicted to be [high/medium/low] energy. Recommended: [suggestion].

---
*Generated by LEGACY at [time]*
```

6. Save to: `00-09 Command (Meta)/01 Zeus (Admin)/03 Journal/[YYYY-MM-DD]-morning-brief.md`

7. Send notification via configured channel

## Context

- Zeus values morning focus time (5:30-9:00 AM)
- Brief should be actionable, not just informational
- Flag anything that might disrupt deep work blocks
- Include one proactive insight or opportunity when relevant
