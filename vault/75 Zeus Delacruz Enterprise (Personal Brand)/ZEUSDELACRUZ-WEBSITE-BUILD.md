# Zeus Delacruz Personal Brand Website

> **Domain:** zeusdelacruz.com
> **Platform:** Webflow + Relume (trial) + Figma (ongoing)
> **Status:** Planning → Build
> **Target:** Premium personal brand site that funnels to onemindcodex.com

---

## Project Overview

Build a premium personal brand website for Zeus Delacruz that:
- Positions Zeus as the thought leader behind One Mind Codex
- Competes with Tiago Forte / Second Brain positioning
- Funnels visitors to onemindcodex.com (Circle.so community)
- Integrates YouTube, Zoho One, and Circle.so embeds
- Enables LEGACY AI access via Webflow MCP/API

## Build Strategy

### Phase 1: Relume Trial (Week 1)

### Phase 3: Integrations (Week 2)
- [ ] Embed YouTube videos (Latest from Zeus section)

- [ ] Enable LEGACY to update CMS content

## LEGACY AI Access (Future)

### Webflow MCP Server
- **Repo:** github.com/webflow/mcp-server
- **Capabilities:** 22+ tools for CMS, pages, content management
- **Integration:** Claude/Cursor + MCP protocol

### What LEGACY Can Update:
- Blog posts (CMS collection)
- Testimonials (CMS collection)
- YouTube embeds (update video IDs)
- Newsletter content
- Announcement banners

### N8N Workflow (Alternative)
```
Trigger (webhook/schedule)
    ↓
Webflow API Call
    ↓
Update CMS Item
    ↓
Publish Changes
```
