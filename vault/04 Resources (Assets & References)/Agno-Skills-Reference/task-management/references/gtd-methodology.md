# Getting Things Done (GTD) Reference

## The 5 Steps

### 1. Capture
Collect everything that has your attention into a trusted system.
- Inbox zero mentality
- Write it down immediately
- Don't try to organize yet

### 2. Clarify
Process what you've captured.
- Is it actionable?
- What's the next physical action?
- Can it be done in 2 minutes? Do it now.

### 3. Organize
Put things where they belong.
- **Projects**: Multi-step outcomes
- **Next Actions**: Single next steps
- **Waiting For**: Delegated items
- **Someday/Maybe**: Future possibilities
- **Reference**: Information to keep

### 4. Reflect
Review your system regularly.
- Daily: Check calendar + next actions
- Weekly: Full system review
- Monthly: Higher-level goals review

### 5. Engage
Choose what to work on.
- Context (where are you?)
- Time available
- Energy level
- Priority

## Two-Minute Rule

If an action takes less than 2 minutes, do it immediately.
The time to organize it > time to do it.

## Weekly Review Checklist

- [ ] Get inbox to zero
- [ ] Review next actions lists
- [ ] Review project list
- [ ] Review waiting for list
- [ ] Review someday/maybe
- [ ] Review calendar (past + future)
- [ ] Brainstorm new items
