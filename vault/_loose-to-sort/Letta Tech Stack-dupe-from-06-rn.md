## Architecture Vision

So this is currently my plan for the stack that I have for Legacy AI Legacy AI is mainly letta.com agents with a Postgress database for state with livekit being stateless for voice, etc

The goal is to combine massive amount of different open source platforms that give Legacy access to everything. For example I have dropbox which Silos everything to myself and doesn't give Legacy access. My goal is to create a unification of different open source products and services to be able to create a super intelligent, super capable AI, personal assistant with all things of my life, including all the topics that we spoke about before when it comes to farming, business, family, personal performance, etc..

The best thing about this is that I can use docker with portainer and edge to different devices and create a cloud structure that's deployed through throughout the world for latency and other specific things to allow my agent to become one of the best in the world.

I truly want massive access to a different types of open source based products for her to maintain and manage herself, and also be able to have unlimited potential when it comes to everything.

One of my goals is to use supabase as a unification of Postgress databases.

Right now, I have all my information and notes and everything silo and different places which gives Legacy fragmentation to be able to see the full picture

My goal is to give Legacy access to my whole life, mostly self hosted with specific things in the cloud that are made for redundancy and security.
