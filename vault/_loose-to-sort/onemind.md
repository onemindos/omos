**One Mind** is an AI-native human enhancement framework that bridges human cognition and artificial intelligence. Unlike productivity frameworks (GTD, PARA, Second Brain) that focus on individual task or information management, One Mind treats your **entire life as a cognitive system** — with explicit layers for knowledge, intelligence, action, and metrics that humans and AI agents share.

**The Hierarchy:**
```
ONE MIND (Framework) → YOUR MIND (Your Implementation) → LEGACY AI (Intelligence)
```

**The Equation:**
```
HUMAN (You) + AI (Legacy) = ONE MIND
```

## The Three Flows

### Flow 1: Knowledge Flow (PKM)

```
   CAPTURE          DISTILL          CONNECT          CODIFY
      │                │                │                │
      ▼                ▼                ▼                ▼
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  Inbox   │ →  │  Draft   │ →  │  Linked  │ →  │  Canon   │
│  Notes   │    │  Notes   │    │  Notes   │    │  (Codex) │
└──────────┘    └──────────┘    └──────────┘    └──────────┘
     ↑                                                │
     │                                                │
     └────────────── FEEDBACK LOOP ───────────────────┘
```

**Stages:**
1. **Capture**: Raw inputs into Inbox (ideas, links, voice memos)
2. **Distill**: Process into atomic Knowledge Nodes
3. **Connect**: Link to Areas, Projects, other nodes
4. **Codify**: Mature knowledge becomes canonical (Legacy Codex pages)

### Flow 2: Action Flow (Execution)

```
   INTAKE          DESIGN          DECOMPOSE         EXECUTE         REVIEW
      │               │                │                │               │
      ▼               ▼                ▼                ▼               ▼
┌──────────┐   ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  Intent  │ → │ Workflow │ →  │  Tasks   │ →  │  Action  │ →  │  Metric  │
│  (Goal)  │   │  Design  │    │  (Atomic)│    │ Execution│    │  Review  │
└──────────┘   └──────────┘    └──────────┘    └──────────┘    └──────────┘
                    ↑                                               │
                    │                                               │
                    └───────── UPDATE WORKFLOWS ────────────────────┘
```

**Stages:**
1. **Intake**: New intent enters (project goal, request)
2. **Design**: Human + AI design the workflow
3. **Decompose**: Workflow generates atomic tasks
4. **Execute**: Agents (human/AI/robot) complete actions
5. **Review**: Measure results, update workflows

## The CODE× Method

The CODE× Method is the engine that runs inside One Mind. It is a 5-step loop that compounds with every cycle.

```
  ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐
  │    C     │──▶│    O     │──▶│    D     │──▶│    E     │──▶│    ×     │
  │ CAPTURE  │   │ ORGANIZE │   │  DIRECT  │   │ EXECUTE  │   │ MULTIPLY │
  └──────────┘   └──────────┘   └──────────┘   └──────────┘   └──────────┘
       ▲                                                              │
       └──────────────────── compounds ─────────────────────────────┘
```

| Step | Question | What Happens |
|------|----------|-------------|
| **C — Capture** | *What came in?* | Everything enters the system — notes, voice memos, tasks, ideas, AI insights |
| **O — Organize** | *Where does it live?* | Route to the right pillar (Personal, Home, Business, Operations) |
| **D — Direct** | *What matters most?* | Set goals, priorities, and agent guardrails |
| **E — Execute** | *Who does the work?* | Deploy humans and AI agents with clear scope |
| **× — Multiply** | *Did it compound?* | Measure results, review, and evolve the system |

The × is not just "review." It is multiplication — every cycle makes the system smarter, the agents more capable, and the outcomes bigger.

## The 11 Entity Types

One Mind classifies everything into 11 entity types. This is what separates it from PARA's 4 folders — PARA tells you WHERE to file things, One Mind tells you WHAT everything is, who owns it, and how AI acts on it.

| Entity | Symbol | What It Is |
|--------|--------|-----------|
| Goal | 🎯 | Desired future state with deadline + metric |
| Project | 📁 | Time-bound effort with defined outcome |
| Task | ✅ | Smallest executable unit of work |
| Metric | 📊 | Measurable signal — lead or lag |
| Skill | ⚡ | Portable capability any agent can follow |
| Tool | 🔧 | System, app, or API that does work |
| Human | 👤 | A person — self, contact, collaborator |
| Agent | 🤖 | AI actor with role, domain, permissions |
| Calendar | 📅 | Time block, event, or recurring rhythm |
| Knowledge | 📖 | Atomic unit of information |
| Asset | 💎 | Owned thing with measurable value |

Every file in One Mind is one of these types. Every type has a standard frontmatter spec. Every type has a home in one of the 4 pillars.
