## What Is One Mind?

## The 4 Pillars

One Mind is built on 4 pillars — one operating layer and three life domains.

```
┌───────────────────────────────────────────────────────┐
│                    OPERATIONS (SO)                     │
│            The layer that runs everything              │
│         AI agents · infrastructure · protocols        │
├─────────────────┬──────────────────┬──────────────────┤
│    PERSONAL     │      HOME        │    BUSINESS      │
│      (HP)       │      (LE)        │      (GE)        │
│                 │                  │                  │
│ Health · Mind   │ Relationships    │ Career · Ventures│
│ Skills · Money  │ Community · Home │ Brand · Wealth   │
│ Identity · Body │ Family · Legacy  │ Products · Impact│
└─────────────────┴──────────────────┴──────────────────┘
```

| Pillar | Full Name | Beginner Label | What Lives Here |
|--------|-----------|----------------|-----------------|
| **SO** | Sovereign Operations | **Operations** | AI agents, tech, automation, protocols |
| **HP** | Holistic Performance | **Personal** | Health, mind, skills, money, identity |
| **LE** | Legacy Evolution | **Home** | Relationships, community, home, family |
| **GE** | Generational Endeavor | **Business** | Career, ventures, brand, wealth, impact |

**SO is the platform. HP, LE, GE are the three pillars of life.**

The key insight: *Operations* doesn't mean boring admin. It means the intelligence layer — your agents, your systems, your automation — that runs the other three pillars silently in the background.

## The CODE× Method

The CODE× Method is the engine that runs inside One Mind. It is a 5-step loop that compounds with every cycle.

```
  ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐
  │    C     │──▶│    O     │──▶│    D     │──▶│    E     │──▶│    ×     │
  │ CAPTURE  │   │ ORGANIZE │   │  DIRECT  │   │ EXECUTE  │   │ MULTIPLY │
  └──────────┘   └──────────┘   └──────────┘   └──────────┘   └──────────┘
       ▲                                                              │
       └──────────────────── compounds ─────────────────────────────┘
```

| Step | Question | What Happens |
|------|----------|-------------|
| **C — Capture** | *What came in?* | Everything enters the system — notes, voice memos, tasks, ideas, AI insights |
| **O — Organize** | *Where does it live?* | Route to the right pillar (Personal, Home, Business, Operations) |
| **D — Direct** | *What matters most?* | Set goals, priorities, and agent guardrails |
| **E — Execute** | *Who does the work?* | Deploy humans and AI agents with clear scope |
| **× — Multiply** | *Did it compound?* | Measure results, review, and evolve the system |

The × is not just "review." It is multiplication — every cycle makes the system smarter, the agents more capable, and the outcomes bigger.

## Why One Mind Is Built for the AI Era

Every previous framework was designed for **humans working alone**:
- GTD assumes you do all the tasks
- PARA assumes you find your own files
- Second Brain assumes you write and recall all the notes

One Mind assumes **AI handles the routine** so you handle the meaningful.

As agents become more capable, One Mind becomes *more* powerful — not less. The framework is the governance layer for your AI. Domain separation keeps your fitness agent out of your finances. Autonomy levels keep humans in the loop for high-stakes decisions. Review cadences ensure the system stays aligned with your values.

## For Beginners: Start Here

You don't need to build all 4 pillars on day one. Start with the loop:

1. **Pick one pillar** — Personal is usually the best start
2. **Run one CODE× cycle** — Capture this week's chaos, Organize it, pick one Direction, Execute one thing, Multiply by reviewing Friday
3. **Add agents over time** — Start with reminders. Graduate to autonomous execution.
4. **Build the other pillars** — Each one you add compounds with the others

One Mind scales from a single Obsidian folder to a full multi-agent system. You grow into it.

## The 11 Entity Types

One Mind classifies everything into 11 entity types. This is what separates it from PARA's 4 folders — PARA tells you WHERE to file things, One Mind tells you WHAT everything is, who owns it, and how AI acts on it.

| Entity | Symbol | What It Is |
|--------|--------|-----------|
| Goal | 🎯 | Desired future state with deadline + metric |
| Project | 📁 | Time-bound effort with defined outcome |
| Task | ✅ | Smallest executable unit of work |
| Metric | 📊 | Measurable signal — lead or lag |
| Skill | ⚡ | Portable capability any agent can follow |
| Tool | 🔧 | System, app, or API that does work |
| Human | 👤 | A person — self, contact, collaborator |
| Agent | 🤖 | AI actor with role, domain, permissions |
| Calendar | 📅 | Time block, event, or recurring rhythm |
| Knowledge | 📖 | Atomic unit of information |
| Asset | 💎 | Owned thing with measurable value |

Every file in One Mind is one of these types. Every type has a standard frontmatter spec. Every type has a home in one of the 4 pillars.
