The whole idea in one move: flip vertical silos into one horizontal fabric.
Today every app is a silo — it fetches its own sources AND renders them (Crucix fetches+shows, WM fetches+shows, WWV fetches+shows). Same OpenSky pulled 4 times, same FIRMS pulled twice. The fabric flips it: every source publishes to NATS once → ORP fuses once → every app renders the same truth. Sources stop being owned by apps. The picture becomes shared.

Two ways a source gets onto the bus

A · ORP-native (no new code)

If ORP already speaks the protocol (AIS, ADS-B, MAVLink, Modbus, CoT…) OR it's a plain HTTP/JSON feed → configure ORP's http_poller/generic_api/websocket_client in config.yaml. ORP pulls, fuses, publishes ent.*. Most WM/simple Crucix sources land here.

B · Publisher microservice (ported recipe)

If the source needs auth, heavy parsing, or logic (Crucix's LLM delta engine, Osiris OSINT enrichment) → a small NATS publisher carries that recipe, publishes intel.*/world.*. ORP's nats adapter ingests it. One publisher per source, GitOps-managed, deployed on DOKS/NEX.

What happens to WorldWideView's own sources

WWV stops fetching. Its plugins re-point to the bus. WWV already has the perfect machinery — a PluginManager/PluginRegistry + manifests, plus DataBus.ts and an Agent Bus. Today each plugin = "fetch external API → render on globe." We convert each to "subscribe to a NATS subject → render on globe." The in-browser DataBus stays; its input becomes the NATS→WebSocket bridge instead of direct fetch(). FIRMS/NASA/USGS/OpenSky now arrive from ORP (fused, deduped) instead of WWV pulling them raw. ⚠ Kill Cesium Ion (cloud token = non-sovereign) → self-hosted terrain/3D tiles. Result: WWV becomes a pure lens on the shared picture, not another silo.

3 moves to combine everything

MOVE 1

Lock the contract

Freeze the subject taxonomy above as the one interface. Every publisher and consumer codes to it. This is what actually "combines" them — a shared language, not shared code.

MOVE 2

Port sources → publishers, one at a time

Process of elimination: take a Crucix/WM/Osiris/WWV source, wire it to the bus (pattern A or B), confirm ORP fuses it, delete the silo. Repeat. Same sweep discipline as the repos.

MOVE 3

Re-point consumers to the bus

WWV plugins, atoc, ATAK, Legacy all subscribe to ent.*/intel.*/world.*. No app fetches its own data anymore. One picture, many lenses.

The fabric isn't a new thing to build — it's NATS (have it) + ORP (have it) + a locked contract (define it) + porting sources one at a time (the work). When done: one bus, one brain, one picture; WWV/atoc/ATAK/Legacy are just windows onto it.
