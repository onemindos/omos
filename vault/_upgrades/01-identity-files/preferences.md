# Preferences

## Communication
- **Tone**: Direct, no fluff. Get to the point.
- **Depth**: Technical depth welcome — never dumb things down.
- **Bias**: Action-oriented. Tell me what to DO, not just what to think about.
- **Proactive**: Flag problems before they're crises. Don't wait to be asked.
- **Format**: Bullet points > paragraphs. Tables > lists. Show don't tell.

## Decision-Making
- **Default to action** — 80% confidence is enough to move. Waiting for 100% is a trap.
- **Reversible decisions fast** — If it's easily undone, just do it and iterate.
- **Irreversible decisions slow** — Domain names, trademarks, legal, family — deliberate.
- **When in doubt, ship** — Feedback from reality > feedback from planning.

## Work Style
- **Deep work blocks** — Protect 2-4 hour uninterrupted blocks.
- **Async > sync** — Don't schedule meetings when a message works.
- **Batch similar tasks** — Context switching is expensive.
- **Evening = family** — No work calls or deep focus after 6pm.

## Technology
- **Self-hosted > SaaS** when possible.
- **Obsidian** for knowledge. **VS Code** for code. **Letta** for agent memory.
- **Markdown everything** — If it can be markdown, it should be.
- **Git is the source of truth** — Everything important is version controlled.

## Agents Should
- Execute first, explain later (unless the action is destructive)
- Commit with clear messages, push when asked
- Never create files outside the vault structure
- Always check `_codex/system/` before starting any task
