# OneMind OS — DigitalOcean Deployment Guide

> Single-Droplet deployment: OpenClaw bare metal + Docker Compose infrastructure.
> All services secured behind Tailscale — **zero public attack surface** (except SSH).

---

## Architecture

```
┌──────────────────────────────────────────────────────────────────────┐
│  DigitalOcean Droplet  (Ubuntu 24.04 / s-2vcpu-4gb-amd)            │
│                                                                      │
│  ┌──────────────────────────┐  ┌──────────────────────────────────┐ │
│  │  HOST (bare metal)       │  │  DOCKER COMPOSE                  │ │
│  │                          │  │                                   │ │
│  │  OpenClaw Gateway        │  │  nats          (4222/7422/1883)  │ │
│  │    :18789 (Tailscale)    │  │  omnidb        (5432)  [data]    │ │
│  │                          │  │  nats-ingester          [data]    │ │
│  │  Node.js 22 LTS         │  │  legacy-bridge                    │ │
│  │  systemd: openclaw.svc  │  │  n8n           (5678)  [full]    │ │
│  │                          │  │  livekit       (7880)  [full]    │ │
│  └──────────────────────────┘  └──────────────────────────────────┘ │
│                                                                      │
│  ┌──────────────────────────────────────────────────────────────────┐│
│  │  SECURITY: UFW deny all → allow SSH + Tailscale-only ports      ││
│  │  NETWORK:  Tailscale mesh VPN (100.x.y.z)                       ││
│  │  BACKUP:   OpenClaw workspace → private GitHub repo (every 15m) ││
│  └──────────────────────────────────────────────────────────────────┘│
└──────────────────────────────────────────────────────────────────────┘
```

**External Access:** Only via Tailscale. Install Tailscale on your laptop/phone to reach services.

## Prerequisites

Before starting, you need:

- [ ] DigitalOcean account with a Droplet created (Ubuntu 24.04 LTS)
- [ ] SSH key added to the Droplet
- [ ] Tailscale account (free at [tailscale.com](https://tailscale.com))
- [ ] GitHub SSH deploy key or personal access token (PAT) for repo clone
- [ ] API keys ready:
  - `ANTHROPIC_API_KEY` — Claude for OpenClaw (required)
  - `OPENAI_API_KEY` — optional (for embeddings or fallback models)
  - `OPENCLAW_GATEWAY_TOKEN` — will be auto-generated
  - Channel tokens: WhatsApp, Discord, Telegram (as needed)

## Deployment Phases

### Phase 1: Base Infrastructure

SSH into your fresh Droplet and run the setup script:

```bash
# SSH in as root
ssh root@<DROPLET_IP>

# Download and run
curl -sSL https://raw.githubusercontent.com/Zeus-Delacruz/onemindos-v0.4/main/.do/setup-droplet.sh | bash
```

**What this does:**
1. System updates + unattended-upgrades
2. Creates `onemind` user with passwordless sudo
3. Installs Docker + Docker Compose
4. Installs Node.js 22 LTS
5. Installs Tailscale (you'll complete auth in Phase 3)
6. Configures UFW (deny all, allow SSH only)
7. Configures Fail2ban (3 SSH failures → 2hr ban)
8. Clones repo to `/opt/onemind`
9. Generates `.env` with random secrets

**After Phase 1:**
```bash
# Switch to onemind user for all remaining work
su - onemind
cd /opt/onemind
```

### Phase 2: OpenClaw Gateway

```bash
# Run as onemind user
bash .do/install-openclaw.sh
```

**What this does:**
1. Installs OpenClaw globally via npm
2. Copies workspace files (SOUL.md, AGENTS.md, etc.) to `~/.openclaw/workspace/`
3. Copies all 14 skills with dependencies installed
4. Copies `openclaw.json` gateway configuration
5. Creates `openclaw.service` systemd unit
6. Sets up workspace backup cron (every 15 min → GitHub)

**After Phase 2, configure the `.env`:**
```bash
nano /opt/onemind/.env
```

Fill in the API keys:
```env
ANTHROPIC_API_KEY=sk-ant-...
OPENAI_API_KEY=sk-...                  # optional
WHATSAPP_TOKEN=...                     # if using WhatsApp channel
DISCORD_BOT_TOKEN=...                  # if using Discord channel
TELEGRAM_BOT_TOKEN=...                 # if using Telegram channel
```

The following were auto-generated by `setup-droplet.sh` — leave them:
```env
OPENCLAW_GATEWAY_TOKEN=<auto-generated>
OPENCLAW_HOOKS_TOKEN=<auto-generated>
OMNIDB_PASSWORD=<auto-generated>
N8N_ENCRYPTION_KEY=<auto-generated>
NATS_EDGE_HOME_PASSWORD=<auto-generated>
NATS_EDGE_OFFICE_PASSWORD=<auto-generated>
```

### Phase 3: Connect Tailscale + Firewall

```bash
# Authenticate Tailscale (opens a URL — click it to authorize)
sudo tailscale up

# Verify connection
tailscale status
tailscale ip -4         # Note this IP (100.x.y.z)

# Open service ports on Tailscale interface only
sudo bash .do/setup-firewall.sh
```

### Phase 4: Start Services

```bash
cd /opt/onemind

# 1. Start NATS (event bus — everything depends on this)
docker compose up -d nats
docker compose logs -f nats    # Wait for "Server is ready"  (Ctrl-C to exit)

# 2. Start OpenClaw gateway
sudo systemctl start openclaw
sudo systemctl status openclaw
journalctl -u openclaw -f      # Watch logs (Ctrl-C to exit)

# 3. Start the NATS→OpenClaw bridge
docker compose up -d legacy-bridge
docker compose logs -f legacy-bridge

# 4. (Optional) Start data layer
docker compose --profile data up -d
docker compose logs -f nats-ingester

# 5. (Optional) Start full stack
docker compose --profile full up -d
```

### Phase 5: Verify

```bash
bash .do/health-check.sh
```

## Service Management

### OpenClaw Gateway

```bash
# Start / Stop / Restart
sudo systemctl start openclaw
sudo systemctl stop openclaw
sudo systemctl restart openclaw

# View logs
journalctl -u openclaw -f                   # live tail
journalctl -u openclaw --since "1 hour ago" # recent

# Check status
sudo systemctl status openclaw
```

### Docker Services

```bash
cd /opt/onemind

# View running containers
docker compose ps

# Start/stop specific service
docker compose up -d nats
docker compose stop nats

# View logs
docker compose logs -f legacy-bridge

# Pull latest images
docker compose pull
docker compose up -d

# Full restart
docker compose down && docker compose up -d
```

### Profiles

| Command | Services Started |
|---------|-----------------|
| `docker compose up -d` | NATS + legacy-bridge |
| `docker compose --profile data up -d` | + OmniDB + nats-ingester |
| `docker compose --profile full up -d` | + n8n + LiveKit |

## Troubleshooting

### OpenClaw won't start

```bash
# Check logs
journalctl -u openclaw -n 50

# Common issues:
# 1. Missing API keys → edit /opt/onemind/.env
# 2. Port conflict → lsof -i :18789
# 3. Node.js wrong version → node --version (need 22+)
# 4. Missing workspace files → ls ~/.openclaw/workspace/
```

### Bridge can't reach OpenClaw

```bash
# The bridge runs in Docker and reaches the host via host.docker.internal
docker compose logs legacy-bridge

# Verify OpenClaw is listening
curl http://localhost:18789/health

# Check OPENCLAW_HOOKS_TOKEN matches in .env
grep HOOKS_TOKEN /opt/onemind/.env
```

### NATS not accepting connections

```bash
# Check NATS logs
docker compose logs nats

# Verify config syntax
docker compose exec nats nats-server --config /etc/nats/nats-server.conf -t

# Test connection
docker compose exec nats nats sub ">" --count 5
```

### OmniDB connection refused

```bash
# Ensure data profile is active
docker compose --profile data ps

# Check health
docker compose exec omnidb pg_isready -U onemind

# Test query
docker compose exec omnidb psql -U onemind -d onemind -c "SELECT count(*) FROM events"
```

### Can't reach services from laptop

```bash
# On the Droplet:
tailscale status                    # Is it connected?
sudo ufw status                    # Are ports open on tailscale0?

# On your laptop:
tailscale ping <DROPLET_TAILSCALE_IP>
curl http://<DROPLET_TAILSCALE_IP>:8222/healthz   # NATS
curl http://<DROPLET_TAILSCALE_IP>:18789/health    # OpenClaw
```

## Multi-Location Expansion

OneMind supports edge locations via NATS leaf nodes. Each location runs a lightweight NATS instance that connects back to the hub Droplet.

```
┌─────────────┐   leaf   ┌──────────────────────┐   leaf   ┌──────────────┐
│ Home Hub    │ ──────── │  DO Droplet (Hub)    │ ──────── │ Office       │
│ RPi + HA    │  :7422   │  OpenClaw + NATS     │  :7422   │ Mini PC + HA │
│ MQTT sensors│          │  OmniDB + bridge     │          │ MQTT sensors │
└─────────────┘          └──────────────────────┘          └──────────────┘
                                   │
                                   │ leaf :7422
                                   │
                          ┌────────┴───────┐
                          │  Van / Mobile  │
                          │  RPi + LTE     │
                          └────────────────┘
```

**Edge setup** (on each location's device):

```bash
# Install NATS
curl -sf https://binaries.nats.dev/nats-io/nats-server/v2@latest | sh

# Create leaf.conf
cat > /etc/nats/leaf.conf << 'EOF'
server_name: "edge-home"
listen: 0.0.0.0:4222
mqtt {
  listen: 0.0.0.0:1883
}
leafnodes {
  remotes [{
    url: "nats-leaf://edge-home:<EDGE_HOME_PASSWORD>@<HUB_TAILSCALE_IP>:7422"
  }]
}
EOF

# Start
nats-server -c /etc/nats/leaf.conf
```

Local MQTT devices (Home Assistant, Victron, sensors) publish to the edge NATS via MQTT (:1883), which automatically replicates to the hub Droplet.
